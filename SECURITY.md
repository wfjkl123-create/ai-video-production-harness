# Security policy

Do not open an issue with a credential, private media, project export, session token, or reproduction steps that expose another party's data.

For a suspected vulnerability, contact the repository owner privately through GitHub and include only the minimum redacted evidence needed to reproduce it. Do not test live paid-generation routes against accounts or projects you do not control.

The public release intentionally omits operational data. If you find such data in this repository, report the exact path privately and avoid redistributing it.
