# Weekly Report Standard

Use this structure for the weekly material direction report.

## Header

- Week
- Main category
- Source platforms
- Generated time
- Data limitations

## Direction Sections

Each direction must include:

- Direction ID and title
- Confidence
- Evidence-backed direction judgment
- Cause hypothesis
- Data evidence IDs with metric names and values
- Material evidence IDs with saved material or video paths
- Next shooting actions
- Directions to avoid

## Labeling

Use these labels inside the report:

- `[COMPUTED]`: validation counts, metric transformations, or summaries calculated from the evidence table.
- `[INFERRED]`: strategic interpretation, cause hypothesis, consumer-interest reading, or material direction.
- `[KNOWN]`: facts directly read from provided files or visible account data.
- `[GUESS]`: any unsupported hypothesis that the user still wants recorded.

Do not upgrade a `[GUESS]` or `[INFERRED]` claim into `[KNOWN]` without new evidence.
