# 视频问题到修复面的映射

只在审片或归因时读取。表中是诊断启发，不是自动定罪；最终根因必须由本次视频、提示词、素材和参数共同支持。

| 看见的问题 | 优先检查 | 常见根因 | 优先修法 |
|---|---|---|---|
| 低分辨率下脸、手、产品糊 | 首帧主体占比、景别、实际输出尺寸 | 主体太远；关键细节低于可用像素量 | 重做首帧构图或推近；不能只追加“高清” |
| 人物忽大忽小 | 运镜、站位、参考图姿势污染 | 景别或距离未锁；多参考源带入不同构图 | 锁主体画框占比和机位；禁止迁移参考图构图 |
| 背景人物或建筑突然消失 | 问题前后帧、切镜或推近、背景描述生效区间 | 场景只在开头被描述；模型重建世界 | 全段锁定可见背景锚和光向；必要时拆最小窗口重做 |
| 人物身份、发型、服装变化 | canonical 人物板、每张参考职责 | 身份图不清；参考污染；人物重新生成 | 换身份资产或收窄素材职责；继续绑定 canonical 基准 |
| 产品颜色、结构、长度变化 | 产品基准、遮挡、动作强度、素材顺序 | 产品没有独立权威；穿戴动作导致结构重建 | 强化产品资产和不可变结构；降低遮挡或穿脱复杂度 |
| 错的人执行动作 | 原提示词的主语、接触顺序、人物站位 | 动作主体含糊或被省略；同一时间多人动作冲突 | 明写“谁先做什么、接触谁、谁被动反应、动作终点” |
| 人凭空出现或瞬移 | 入画路线、前一秒可见空间、声音提示 | 没写进入路径和到达过程 | 增加可见或可听触发、入画路径和连续脚步，不只写“随后出现” |
| 全程保持同一笑脸或表情 | 首帧表情、情绪触发、反应过程 | 首帧强表情被模型延续；只写情绪结果 | 用视线、嘴角、呼吸、肩背、重心写出变化过程；必要时换中性首帧 |
| 表演像念指令、没有活人感 | 触发、停顿、对方反应、环境反馈 | 动作清单没有因果；每拍没有可感知证据 | 按“触发→反应→选择→对方反应→新状态”重写 |
| 多手、多指、手臂来源不明 | 接触动作窗口、遮挡、多人同时用手 | 高复杂接触；提示词没锁手臂来源；偶发生成畸形 | 简化接触动作，锁每只手来源；若合同正确则归为执行波动 |
| 布料穿过身体、产品瞬间穿好 | 穿戴动作起点、过程、终点和遮挡 | 物理过程太复杂或时间不足 | 拆动作、增加接触与受力过程，或改用编辑或分段路线 |
| 人物左右互换、越轴 | Frame Map、机位、转身与切镜 | 空间锚不足；切镜后未重锚定 | 用画面左或右、朝向、视线目标和轴线重锚定 |
| 台词由错误人物说出 | 说话人、声线、口型、时间段 | 台词未逐句绑定；多人同框时声源混淆 | 逐句绑定说话人和反应者；必要时后期配音 |
| 口型、声音、动作不同步 | 原生音频模式、台词密度、动作时长 | 台词塞太满；生成音频不稳定 | 减台词、留反应时间；能后期修就不重做画面 |
| 画面像 PPT | 环境变化、呼吸、重心、摄影机响应 | 只有静态姿势和抽象氛围词 | 加入由当前事件触发的一项身体、环境或声音反馈，避免堆微动作 |
| 段间明显跳一下 | 前段尾帧、后段首帧、曝光、站位、音频接点 | image2video 首帧非像素锁定；尾帧被当身份权威 | 用 canonical 基准加尾帧状态共同约束；本地过渡或重做最小接缝窗口 |
| 故事看不懂但单个动作都对 | 锁定剧情、触发、关系变化、产品功能 | 动作并列，没有因果和结果 | 回到故事脊柱重写，不做顶部追加式解释 |

## 归因反例

- “DeepSeek 写的，所以提示词一定差”不是证据。要指出正文中哪个主语、因果、空间或素材职责导致了画面错误。
- “模型没听话”不能覆盖上游错误。先检查提示词是否真的写清楚正确动作。
- “加更多负面词”不能修复错误首帧、错误素材职责或错误动作主体。
- “换成 720P”不能修复人物在构图里过小；分辨率和主体占比要一起检查。
- “再抽一次可能就好”只适用于输入合同已验证正确的偶发执行失败，并且仍需要新的付费授权。
