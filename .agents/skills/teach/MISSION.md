# Mission template

Use this file only for the learner's own goal. It is deliberately empty of any
previous operator, project, course progress, account or machine details.

## Goal

Describe the practical capability the learner wants to gain.

## Why

Describe the real task that makes this learning useful.

## Background and constraints

- Starting level
- Preferred language and pace
- Tools the learner may use
- Accessibility, time or privacy constraints

## Success criteria

State an observable outcome the learner can perform independently.
