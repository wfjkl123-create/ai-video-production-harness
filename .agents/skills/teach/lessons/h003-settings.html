Settings & Permissions：为 Harness 建立安全边界

第 3 课，共 7 课 · 预计 12 分钟

你的 settings.json 现在长这样

你目前的 ~/.claude/settings.json：

~/.claude/settings.json（当前）
{
  "env": {},
  "statusLine": { ← claude-hud 插件加的
    "type": "command",
    "command": "..."
  },
  "skipDangerousModePermissionPrompt": true ← 跳过危险操作提示
}

目前没有任何权限规则——Claude 基本上可以做任何事。 这节课教你如何用 permissions 字段给它装上"护栏"。

三层 settings.json

settings.json 和 CLAUDE.md 一样，也有层级：

文件位置 作用范围 是否提交到 Git 用途
~/.claude/settings.json 所有项目 否（个人机器） 个人全局偏好、全局 Hooks
.claude/settings.json 当前项目 是（团队共享） 项目权限规则、项目 Hooks
.claude/settings.local.json 当前项目 否（.gitignore） 个人的项目级配置（不想提交的）
重要
项目的 .claude/settings.json 会提交到 Git，团队所有人共享同一套规则。 个人的 API Key、本地路径等敏感信息写在 settings.local.json 里，加入 .gitignore。

权限系统：allow 和 deny

permissions 字段有两个列表，逻辑很简单： deny 永远优先于 allow。

✅ allow（白名单）

  • 明确允许的操作
  • Claude 可以不经询问直接执行
  • 减少权限确认弹窗的摩擦

🚫 deny（黑名单）

  • 明确禁止的操作
  • Claude 尝试执行时会被阻止
  • 优先级高于 allow
{
  "permissions": {
    "allow": [
      "Read",
      "Edit",
      "Write",
      "Bash(npm run test)",
      "Bash(npm run lint)"
    ],
    "deny": [
      "Bash(git push --force:*)",
      "Bash(rm -rf:*)",
      "Bash(DROP TABLE:*)"
    ]
  }
}

权限规则的写法

规则支持精确匹配和通配符，从宽到窄：

"Read"
允许读取所有文件，不限路径
"Bash(npm run test)"
只允许这一条精确命令
"Bash(npm run:*)"
允许所有 npm run 开头的命令
"Bash(git:*)"
允许所有 git 命令
"Bash(rm -rf:*)"
禁止所有 rm -rf（放在 deny 里）

常用的工具名称：Read、Edit、Write、Bash、WebFetch、WebSearch

正确的权限哲学

关于权限管控，有两个常见的错误极端：

❌ 过度限制

"拒绝一切，只允许最小权限"——听起来安全，但 Claude 无法调查问题、查看日志、运行测试，彻底瘫痪。

❌ 完全放开

不设任何 deny，Claude 可能意外执行 force push、删除文件、修改生产配置。

✅ 精准防护（推荐）

只 deny 真正危险的、不可逆的操作（force push、rm -rf、生产数据库写入）。 其余保持开放，让 Claude 能自由探索和解决问题。

一套实用的起点配置

这是一个适合大多数个人项目的 .claude/settings.json 起点：

{
  "permissions": {
    "allow": [
      "Read",
      "Edit",
      "Write",
      "Bash(npm run:*)",
      "Bash(git status)",
      "Bash(git diff:*)",
      "Bash(git log:*)",
      "Bash(git add:*)",
      "Bash(git commit:*)"
    ],
    "deny": [
      "Bash(git push --force:*)",
      "Bash(rm -rf:*)",
      "Bash(git reset --hard:*)",
      "Bash(DROP:*)",
      "Bash(DELETE FROM:*)"
    ]
  }
}

这个配置让 Claude 可以自由读写代码、跑测试、做 Git 提交， 但阻止它做任何不可逆的危险操作。
