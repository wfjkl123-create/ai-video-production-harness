cmux 实战：让通知替你盯屏

上一课你学会了"分栏 ≠ 协同"的心智模型；这一课学会真正的操作循环：派活 → 切走 → 等通知 → 跳回来。约 12 分钟。

多智能体高效的秘密不是"同时盯着 6 个屏幕"，而是一次只看一个屏幕，其余的交给通知系统。 人眼盯屏是最贵的资源；cmux（一款专为 AI 编程智能体设计的 macOS 原生终端）的全部设计，都是为了把你从"轮流查岗"里解放出来。

cmux 的 GitHub 身份证

先确认我们学的是"哪一个 cmux"——GitHub（全球最大代码托管平台）上叫 cmux 的项目有 700 多个，星数（stars，相当于收藏/点赞数）最高、也是我们要学的这个是：

24,624 ★GitHub 星数（截至 2026-07-17），同名项目中断层第一
manaflow-ai/cmux仓库地址，基于 Ghostty（高性能终端内核）的 macOS 原生应用，Swift 语言编写，非网页套壳，启动快、省内存
开源免费GPL 协议（开源许可证），官网 cmux.com，自带简体中文说明文档

作者自述造它的原因：同时跑很多个 Claude Code 会话时，系统通知只会说"Claude 正在等待你的输入"，根本不知道是哪一个在等——于是他做了侧边栏 + 通知系统。这正是你现在遇到的问题。

核心工作循环：四步

这是本课唯一需要练成肌肉记忆的东西。你和多个智能体协作的每一轮，都是这四步：

1派活给某个 pane（分栏窗格）里的智能体下达一条带成功标准的指令
2切走立刻切到别的工作区干别的事，不要守着它跑
3等通知智能体需要你时，它的 pane 出现蓝色圆环，侧边栏标签点亮
4跳回来按 ⌘⇧U 直接跳到最新未读，处理完回到第 1 步

对照你的实际工作：工作区 1 让智能体爬竞品视频数据，工作区 2 让另一个写脚本初稿，你自己在工作区 3 看蝉妈妈——谁需要你，谁亮灯，你才过去。

通知系统三件套

看到什么 / 按什么意思
pane 边缘出现蓝色圆环、侧边栏标签点亮这个智能体在等你（要你确认权限、回答问题或验收结果）
⌘I 打开通知面板一处看到所有待办通知，不怕漏掉谁
⌘⇧U 跳到最新未读不用找，一键传送到最需要你的那个 pane
前提：先接好"传感器"。通知不是魔法，靠的是钩子（hooks，智能体状态变化时自动触发的小程序）。 Claude Code 的集成在 cmux 的 Settings（设置）里开启开关即可；其他智能体（如 Codex、OpenCode）在终端里运行一次 cmux hooks setup（自动检测并安装所有支持的智能体钩子）。装好后，会话还能在重启 cmux 后自动恢复（session restore，恢复布局和智能体对话进度）。

肌肉记忆最小集：7 个快捷键

cmux 有几十个快捷键，但小白只需要这 7 个就能高效运转（⌘ 是 Command 键，⇧ 是 Shift 键，⌥ 是 Option 键，⌃ 是 Control 键）：

快捷键作用什么时候用
⌘N新建工作区（workspace）开一个新项目 / 新任务线
⌘1–8跳到第 1–8 个工作区在项目之间瞬移，代替鼠标点侧边栏
⌘D / ⌘⇧D向右 / 向下分栏在同一工作区里给编队加一个成员
⌥⌘←→↑↓按方向移动焦点在分栏之间移动光标，给不同智能体输入
⌘⇧U跳到最新未读通知灯亮了就按它，核心循环第 4 步
⌘I通知面板感觉可能漏了谁时，总览一遍
⌘B收起 / 展开侧边栏需要大屏专注时收起，要看全局时展开

一条命令组队：claude-teams

上一课我们说过，手动开三个 pane 时，派工、同步、整合都得你自己做。cmux 提供了一条捷径：

cmux claude-teams

这条命令启动 Claude Code 的队友模式（teammate mode，一个主智能体自动招募多个队友协作）。在普通终端里用这个模式需要先配置 tmux（老式终端复用工具，配置繁琐）；在 cmux 里则是：每个队友自动变成一个原生分栏，自带侧边栏信息和通知。也就是说——上一课的 Lead（队长）/ Builder（执行者）/ Verifier（验收员）编队，从"你手动开三个栏、来回复制粘贴"变成"一条命令，队长自己招人，你只管看通知"。

怎么选：任务能一句话说清成功标准、步骤可以并行 → 用 claude-teams 让队长去拆； 任务需要你边看边调方向（比如脚本文案的口味把控）→ 手动分栏，你自己当队长。

进阶效率技巧（用到再学，先混个眼熟）

  • 侧边栏是仪表盘：每个工作区标签自动显示 Git 分支（代码版本线）、PR 状态（Pull Request，代码合并请求）、监听端口和最新一条通知文字——扫一眼侧边栏 = 巡视全部工地。
  • 浏览器分栏（⌘⇧L）：在终端旁边开一个内置浏览器，智能体可以自己操作它——点击、填表、截图。比如让智能体自查它爬取的页面长什么样。
  • 会话恢复（⌘⇧O）：cmux 退出时保存全部布局和智能体会话，重开后各智能体从上次的对话继续，不用重新交代任务。
  • 智能体休眠（agent hibernation，自动挂起闲置的后台智能体省内存）：同时跑超过 12 个智能体才需要开，现在不用管。

今日实操任务（15 分钟）

  1. 安装：官网 cmux.com 下载 DMG（macOS 安装包），或用 Homebrew（macOS 软件包管理器）：brew install --cask cmux。已装的跳过。
  2. 接传感器：打开 cmux 的 Settings 开启 Claude Code 集成；再运行 cmux hooks setup。
  3. 建编队：⌘N 新建工作区，⌘D 分出第二栏，在两个栏里各启动一个 claude。
  4. 派活：给左边的下达一个 3 分钟量级的小任务（比如"把桌面上的截图按日期整理进文件夹，完成后报告清单"）。
  5. 切走：⌘N 再开一个工作区，随便干点别的。忍住，不要切回去看。
  6. 等灯亮：侧边栏点亮后按 ⌘⇧U 跳回去处理。恭喜，你完成了第一个完整的通知驱动循环。
