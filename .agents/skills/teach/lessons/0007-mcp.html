MCP：给 Claude 装上新手臂

Claude 原本能做什么，不能做什么

原生的 Claude 只能做一件事：处理文字。 它不能主动查数据库、不能打开浏览器、不能发邮件、不能访问你公司的内部系统。

MCP（Model Context Protocol，模型上下文协议） 打破了这个限制。 它是一套标准协议，让 Claude 能够调用外部工具——就像给它装上了新的手臂。

MCP 的工作原理

MCP 的架构由三部分组成：

Claude Code
MCP 客户端
⟷
MCP Server
中间层（工具暴露者）
⟷
外部系统
数据库 / API / 浏览器…
  1. MCP Server：一个小程序，把外部能力包装成 Claude 能调用的"工具"
  2. Claude 在对话里识别到需要用外部能力，就调用对应的工具
  3. MCP Server 执行真实操作，把结果返回给 Claude
  4. Claude 把结果整合进对话，继续回答你
和 Hook 的区别
Hook 是 Claude 做完事之后触发你的脚本（Claude → 你的脚本）。
MCP 是 Claude 在做事过程中调用外部工具来获取能力（Claude → 外部系统）。
Hook 是自动化反应，MCP 是能力扩展。

如何添加 MCP Server

有两种方式：

方式一：命令行添加（最简单）

claude mcp add <server-name> -- <启动命令>

例如，添加官方的文件系统 MCP Server：

claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem /你的目录

方式二：在 settings.json 里配置

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/你的用户名/Documents"
      ]
    }
  }
}

添加后重启 Claude Code，新工具就可用了。

查看已安装的 MCP Server

在 Claude Code 里输入：

claude mcp list

或者在对话里直接问 Claude："你现在有哪些可用的工具？"，它会列出所有通过 MCP 获得的能力。

哪里找现成的 MCP Server

不需要自己写——已经有大量现成的 MCP Server 可以直接安装：

  • 官方列表：github.com/modelcontextprotocol/servers
  • Claude Code 插件市场：在 Claude Code 里输入 /plugins 浏览
  • 常见的有：GitHub、Postgres、Brave Search、Playwright（浏览器自动化）、Slack 等
