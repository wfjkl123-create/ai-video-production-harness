Hooks 是 Harness 里最强大的部分——它们把 Claude 的每一个动作都变成了自动化流程的触发器。

完整的 Hook 配置结构

一个 Hook 配置里的每个字段都有作用：

字段
示例值
含义
"matcher"
"Edit|Write"
匹配哪些工具，| 分隔多个，留空=全部
"type"
"command"
目前只有 command 类型
"command"
"npm run test"
要执行的 Shell 命令
"timeout"
10000
超时毫秒数，防止脚本挂死
"onFailure"
"warn"
脚本失败时的行为（见下方）

Hook 脚本能读到什么

Claude 执行工具时，会把上下文通过环境变量传给你的 Hook 脚本：

环境变量内容用途
CLAUDE_FILE_PATH 被操作的文件路径 判断哪个文件被改了，针对性处理
CLAUDE_TOOL 工具名称（Edit / Write / Bash…） 在一个 Hook 里处理多种工具时区分
CLAUDE_TOOL_INPUT Claude 传给工具的完整参数（JSON） 检查 Claude 具体要做什么，用于 PreToolUse 拦截
CLAUDE_SESSION_ID 当前会话 ID 日志记录、跨 Hook 关联

onFailure：失败了怎么办

"fail"
阻止工具执行
（仅 PreToolUse 有效）
"warn"
显示警告，继续执行
（推荐默认值）
"ignore"
静默忽略错误
适合非关键 Hook

注意：退出码 2（上一门课学的）只在 onFailure: "fail" 时才有意义。 onFailure: "warn" 时，即使退出码是 2，工具也会继续执行。

三个真实可用的 Hook 配方

🎨 配方 1：写完代码自动格式化 PostToolUse 
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "npx prettier --write \"$CLAUDE_FILE_PATH\"",
        "timeout": 10000,
        "onFailure": "warn"
      }]
    }]
  }
}
每次 Claude 写完文件，自动跑 Prettier 格式化。超时 10 秒，失败只警告不中断。
🧪 配方 2：修改源码后自动跑测试 PostToolUse 
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "bash -c 'if [[ \"$CLAUDE_FILE_PATH\" == src/*.ts && \"$CLAUDE_FILE_PATH\" != *.test.ts ]]; then npm run test; fi'",
        "timeout": 60000,
        "onFailure": "warn"
      }]
    }]
  }
}
只在修改 src/ 下的 .ts 文件（非测试文件）时跑测试。避免改测试文件时递归触发。
🛡️ 配方 3：PreToolUse 保护重要文件 PreToolUse 
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "bash -c 'case \"$CLAUDE_FILE_PATH\" in *.env|*config.prod.*|*secrets.*) echo \"禁止修改敏感文件：$CLAUDE_FILE_PATH\"; exit 2;; esac'",
        "timeout": 5000,
        "onFailure": "fail"
      }]
    }]
  }
}
在 Claude 写文件之前检查路径。匹配到 .env、config.prod、secrets 等文件时，输出原因并退出码 2 阻断操作。onFailure 必须是 "fail" 才能阻断。

把多个 Hook 组合进一个 settings.json

实际使用时，多个 Hook 可以写在同一个文件里：

{
  "permissions": {
    "deny": ["Bash(rm -rf:*)", "Bash(git push --force:*)"]
  },
  "hooks": {
    "PreToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{ "type": "command",
        "command": "bash -c 'if [[ \"$CLAUDE_FILE_PATH\" == *.env ]]; then echo \"禁止修改 .env\"; exit 2; fi'",
        "onFailure": "fail", "timeout": 5000 }]
    }],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command",
          "command": "npx prettier --write \"$CLAUDE_FILE_PATH\"",
          "onFailure": "warn", "timeout": 10000 }]
      },
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command",
          "command": "npm run test --passWithNoTests",
          "onFailure": "warn", "timeout": 60000 }]
      }
    ]
  }
}
