你已经安装过一个 Plugin 了

还记得你安装的 claude-hud 吗？那就是一个 Plugin。 它被安装在： 

~/.claude/plugins/cache/jarrodwatts-claude-hud/

安装插件的命令：

claude plugin add <marketplace-name>    ← 从市场安装
claude plugin add github:用户名/仓库名  ← 从 GitHub 安装
claude plugin list                       ← 查看已安装的插件
claude plugin remove <name>             ← 卸载插件

Plugin 的目录结构

一个 Plugin 本质上是一个有特定结构的目录：

my-plugin/
├── .claude-plugin/
│ └── plugin.json ← 插件元信息（名称、版本、描述）
├── commands/ ← 斜杠命令
│ └── review.md
├── skills/ ← Skill 定义
│ └── code-reviewer/
│ └── SKILL.md
├── hooks/ ← Hook 脚本
│ └── hooks.json
└── README.md ← 使用说明

plugin.json 是插件的身份证：

{
  "name": "code-review-suite",
  "version": "1.0.0",
  "description": "完整的代码审查工具套装",
  "author": "你的名字"
}

Plugin 市场

Anthropic 维护着一个官方 Plugin 市场，里面有大量现成的插件：

  • code-review：代码审查套装
  • feature-dev：功能开发工作流
  • claude-md-management：CLAUDE.md 管理
  • math-olympiad：数学竞赛解题
  • plugin-dev：开发自己的插件（套娃！）

在 Claude Code 里输入 /plugins 可以浏览市场，一键安装。

Plugin 的本质
Plugin 不是什么神秘的东西——它就是把你学过的所有功能（命令、技能、钩子……） 放进一个规范的目录结构里，再加一个 plugin.json 做身份证。 你现在已经有能力自己创建一个 Plugin 了。
