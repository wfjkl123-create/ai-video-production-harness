Memory：让 Claude 记住你

第 2 课，共 10 模块 · 预计 12 分钟

默认情况下，Claude 是失忆的

每次你新开一个对话，Claude 对你一无所知。你不得不重新解释： "我在做一个 Python 项目，我喜欢用中文，不要加注释……"

Memory 系统解决的就是这个问题：让 Claude 在会话之间保留上下文。

核心概念
Claude Code 的记忆本质上是文本文件——Claude 在每次对话开始时会自动读取这些文件，就好像你每次都把它们粘贴到了对话开头。

记忆的三个层级

Claude Code 的记忆分三层，范围从小到大：

层级 文件位置 作用范围
🌍 全局 ~/.claude/CLAUDE.md 所有项目都生效
📁 项目 项目根目录/CLAUDE.md 只在该项目生效
🧠 AI 记忆 ~/.claude/memory/ Claude 自动写入的长期记忆

最重要、最常用的是 CLAUDE.md——无论是全局的还是项目级的。

CLAUDE.md：最重要的记忆文件

CLAUDE.md 是一个普通的 Markdown 文件，你写什么，Claude 就会"记住"什么。 每次你在某个项目目录里打开 Claude Code，它都会自动读取该目录下的 CLAUDE.md。

一个典型的项目 CLAUDE.md 长这样：

# 我的项目

## 项目简介
这是一个 Python 数据处理脚本，用来清洗销售报表。

## 偏好
- 用中文回复
- 代码注释也用中文
- 变量名用英文，函数名用下划线命名法

## 重要文件
- main.py：入口文件
- data/：原始数据目录
- output/：处理结果输出目录

## 注意事项
- 不要修改 config.json，它是手动管理的

有了这个文件，你每次打开项目，Claude 就已经知道这些背景知识了。

你已经在用它了
你现在的 Claude Code 里已经有全局 CLAUDE.md 的效果——你的语言偏好（中文）、角色背景就是通过类似机制加载进来的。 输入 /memory 可以查看和编辑你的记忆文件。

AI 自动写入的记忆

除了你手动写的 CLAUDE.md，Claude 自己也会主动把重要信息存到 ~/.claude/memory/ 目录下（你现在学的这门课就是这样运作的）。

当你说"帮我记住……"，或者 Claude 判断某件事很重要时，它会：

  1. 在 ~/.claude/memory/ 创建或更新一个 .md 文件
  2. 在 MEMORY.md 索引文件里添加一行指针
  3. 下次对话开始时，自动把这些文件内容加载进上下文

这意味着：你告诉 Claude 一次的事情，它可以永远记住。

动手：用 /memory 查看记忆

现在在 Claude Code 里输入 /memory，看看 Claude 目前记住了什么关于你的信息。

你会看到它已经记住了：你想学 claude-howto 项目，你是零基础，你偏好中文。这些都是上一课自动保存下来的。
