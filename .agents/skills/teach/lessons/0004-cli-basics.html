Claude Code 的三种启动方式

你目前用的是交互模式——打开终端，和 Claude 来回对话。 但 Claude Code 还支持另外两种模式，在不同场景下非常有用。

🗨️ 交互模式（你现在用的）

claude

打开对话界面，可以来回多轮交流。适合需要探索、调试、或复杂任务。

⚡ 单次模式（One-shot）

claude "帮我解释一下这段代码"

直接把问题写在命令后面，Claude 回答完就退出。适合快速的单次任务。

🔁 管道模式（Pipeline）

cat error.log | claude -p "总结这些错误"

把文件或命令的输出通过管道传给 Claude，结果打印到终端。适合脚本和自动化。

最常用的启动参数

命令 作用
claude 启动交互模式（开新对话）
claude -c 继续上一次的对话（continue）
claude -r 从历史会话列表中选一个恢复（resume）
claude -p "问题" 非交互模式，直接打印结果后退出（print）
claude --model sonnet 指定使用的模型
claude --help 查看所有可用参数
最实用的一个
claude -c 是日常最高频的参数。关掉终端再重新打开，用 -c 就能无缝接上昨天的对话，不用从头解释背景。

对话中的键盘快捷键

进入交互模式后，这些快捷键会大幅提升效率：

快捷键 作用
Esc 中断 Claude 当前正在执行的任务（上节课学过）
Esc Esc（双击） 清空你正在输入的内容
↑ / ↓ 浏览历史输入记录
Shift + Enter 换行（不发送），写多行消息时用
Ctrl + C 强制退出 Claude Code

两个实用技巧

技巧 1：用 ! 直接运行 Shell 命令

在对话框里输入 ! 开头，后面跟任何终端命令，就可以直接执行，结果会出现在对话里。 

! ls -la          ← 列出当前目录文件
! git status      ← 查看 git 状态
! npm run build   ← 构建项目

你不需要切出去开另一个终端窗口。

技巧 2：用 @ 引用文件内容

输入 @ 后跟文件路径，可以把文件内容直接引入对话： 

帮我解释 @src/main.py 里的 login 函数

Claude 会自动读取该文件并在回答中引用它，不需要你手动粘贴代码。
