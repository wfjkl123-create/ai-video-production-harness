斜杠命令：你的第一个超能力

第 1 课，共 10 模块 · 预计 10 分钟

你已经用过它了

你学这门课的方式，就是通过一个斜杠命令：/teach。 在 Claude Code 的输入框里输入 /，就会弹出一个命令菜单——这些就是斜杠命令（Slash Commands）。

核心概念
斜杠命令是你给 Claude 发出的快捷指令。一个命令背后，可能藏着几百行复杂的行为说明——你只需要输入几个字，就能触发它。

想象它是一个咖啡馆的点单系统。你不需要每次都说"帮我做一杯意式浓缩，加两份奶泡，温度 70 度……"，你只需要说"一杯拿铁"——背后的复杂流程已经被预先定义好了。

斜杠命令在哪里

斜杠命令有两个来源：

1. 内置命令（Claude Code 自带）

这些命令安装 Claude Code 就有，不需要任何配置。常见的有：

/help          查看帮助
/clear         清空当前对话
/config        打开设置
/review        审查当前代码变更
/init          为当前项目生成 CLAUDE.md 文档
/memory        查看和编辑 Claude 的记忆

2. 自定义命令（放在 commands/ 目录里）

你可以自己写命令，或者安装插件获得新命令。命令的本质是一个 .md 文件，放在特定路径下： 

~/.claude/commands/        ← 全局命令（任何项目都能用）
.claude/commands/          ← 项目命令（只在当前项目有效）

你现在用的 /teach 就是一个自定义命令，它的定义文件在 ~/.claude/skills/teach/SKILL.md。

命令文件长什么样

每个命令其实就是一个 Markdown 文件，里面写的是给 Claude 的指令。比如一个简单的命令：

# /hello

向用户用中文打招呼，并问他们今天想学什么。

把这个文件保存为 ~/.claude/commands/hello.md，重启 Claude Code 后，你就可以在任何地方输入 /hello 来触发它。

关键规律
文件名 = 命令名。文件 hello.md → 命令 /hello。文件里的内容 = Claude 收到这个命令后要做的事。

动手：查看你有哪些命令

现在，在 Claude Code 的输入框里输入 /（不要按回车），看看弹出的命令列表。

你会看到：

  • 一些带 🔧 图标的内置命令
  • 你安装的斜杠技能，比如 /teach

这就是你目前拥有的"工具箱"。
