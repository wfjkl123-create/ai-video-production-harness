🪝 支柱三：Hooks ❌ 现在来添加

你做爬虫，一定有 .env、API Key 等敏感文件。 现在添加一个 Hook，当 Claude 试图修改这些文件时自动阻断：

1
在 settings.json 里加入 hooks 配置

把下面的内容合并进你的 ~/.claude/settings.json：

"hooks": {
  "PreToolUse": [
    {
      "matcher": "Edit|Write",
      "hooks": [
        {
          "type": "command",
          "command": "node -e \"const f=process.env.CLAUDE_FILE_PATH||''; if(/(\\.(env|key|pem)|config\\.prod|secrets|cookie)/.test(f)){console.error('🚫 受保护文件：'+f);process.exit(2)}\"",
          "timeout": 5000,
          "onFailure": "fail"
        }
      ]
    }
  ]
}

这个 Hook 会检测文件路径，匹配 .env / .key / .pem / config.prod / secrets / cookie 时直接阻断写入。

⚡ 支柱五：Custom Commands ❌ 现在来创建

针对你的工作（抖音千川编导），创建三个最实用的命令：

1
/script — 生成广告视频脚本

文件：~/.claude/commands/script.md

为以下产品/卖点生成一条抖音千川广告视频脚本：$ARGUMENTS

脚本结构：
1. **黄金3秒钩子**：强视觉冲击或强痛点，开门见山
2. **痛点放大**（5-8秒）：描述目标用户的真实困扰
3. **产品登场**（8-15秒）：展示产品如何解决痛点
4. **社会证明**（15-20秒）：数据、用户评价或权威背书
5. **行动号召**（最后2秒）：限时/限量/清晰指令

风格要求：
- 口语化，不写书面语
- 每句话不超过15字
- 避免夸大词汇（最、第一、唯一）
- 输出旁白文案 + 画面描述（分两列）
2
/analysis — 竞品分析框架

文件：~/.claude/commands/analysis.md

对以下竞品进行抖音千川广告分析：$ARGUMENTS

分析维度：
1. **投放策略**：定向人群、出价方式、投放时段
2. **素材风格**：视频风格、时长、开头钩子类型
3. **文案特点**：标题公式、痛点切入角度、行动号召
4. **差异化机会**：对方薄弱的环节，我们可以切入的角度

输出格式：表格 + 简短结论

注意：基于公开可见的广告内容分析，不涉及非公开数据。
3
/commit — 生成提交信息

文件：~/.claude/commands/commit.md

根据当前 staged 的变更，生成一条 git commit 信息。

```bash
git diff --staged
```

格式：50字以内中文摘要，动词开头（添加/修复/重构/更新）。
只输出 commit 信息本身，不要解释。
