cmux 多智能体速查

布局 ≠ 会话 ≠ 协同

一个工作区

一个项目或一个大目标。相关 pane 放在一起。

多个工作区

不同项目、不同权限边界或不同 Git worktree。

手动多个 pane

独立会话；人类负责派工、同步、整合。

Teams 多个 pane

Lead 负责协调；cmux 显示、路由和通知。

开工口令

目标：一句话结果
成功标准：可验证条件
Lead：唯一派工与汇总者
Builder：只实现，不自行扩展范围
Verifier：独立测试并做对抗性审查
共享事实：文件、Git diff、测试输出

红线

  • 不要让多个智能体在同一 checkout 同时改同一文件。
  • 不要假设多个会话共享聊天上下文。
  • 不要把“进程停止”当作“任务完成”。
  • 没有测试证据，不进入整合。
