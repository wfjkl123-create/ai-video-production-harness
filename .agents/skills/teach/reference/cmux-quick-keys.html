cmux 快捷键与命令速查

绿色底 = 每天都在用的核心循环键 · 来源：manaflow-ai/cmux 官方 README

核心循环（先背这些）

⌘⇧U跳到最新未读通知（灯亮就按它）
⌘I通知面板，总览所有在等你的智能体
⌘1–8跳到第 1–8 个工作区；⌘9 跳最后一个
⌘D / ⌘⇧D向右 / 向下分栏
⌥⌘←→↑↓按方向在分栏间移动焦点

工作区（workspace）

⌘N新建工作区
⌃⌘] / ⌃⌘[下一个 / 上一个工作区
⌘⇧W关闭工作区
⌘⇧R重命名工作区（起个人话名字，别留 zsh）
⌘B收起 / 展开侧边栏

surface（同一栏里的标签页）与其他

⌘T当前栏里新开一个 surface（标签页）
⌃Tab / ⌃⇧Tab下一个 / 上一个 surface
⌘W关闭当前 surface
⌘⇧L分栏打开内置浏览器（智能体可操作它）
⌘⇧O恢复上一次会话（布局 + 智能体对话进度）
⌘⇧P命令面板（找不到功能时搜这里）

常用命令（在 cmux 终端里输入）

cmux hooks setup自动给检测到的所有智能体装通知/恢复钩子（Claude Code 在 Settings 里开开关）
cmux claude-teams启动 Claude Code 队友模式，每个队友自动成为原生分栏
cmux notify "文字"手动发一条通知（可接到脚本末尾提醒自己）
cmux ssh user@remote给远程机器开一个工作区（远程 localhost 也能在浏览器分栏直接打开）
cmux restore-session手动重放上次保存的布局快照
