## 0. 使用条件与边界

当用户只说“一个人加班后回家，最后释然”“做一条真实随拍的产品故事”“两人误会后和好”一类梗概，而产品、人物身份、时长、画幅和素材授权等硬约束已经明确时，读取本文件以补足可拍的细节。Harness 新项目必须先完成 Gate 0 并锁定 `creative_brief`；本文件不替代该流程。

- 这不是替用户另起故事：保留用户的角色、关系、转折、禁区和结局；只补齐镜头、空间、物理、环境和声音的导演决定。
- 不能确定会改变业务、角色身份、产品结构、敏感事实、时长或媒介权限的事项，仍按主 Skill 拦截澄清。
- 成果只允许进入现有 Skill 的自然中文导演正文；本文件的表名、分类名、示例逻辑和“案例”一词不得出现于模型正文。

## 1. 细节链：从大纲到可生成镜头

每个故事节拍先在脑内写成下列八格；模型正文只保留观众能看见或听见的内容。

```text
1. 本拍意图：观众在这一拍明白/感到什么变化？
2. 起始状态：谁在哪，拿着什么，画面第一眼看什么？
3. 触发：是什么已在画面中的事件迫使人物/镜头改变？
4. 主动作：起点 → 过程 → 终点，谁主动、谁被动？
5. 证据反应：身体 / 材料 / 道具 / 环境中是否需要一项证明动作真的发生？
6. 摄影机策略：为什么此刻跟、停、让、失焦、遮挡或揭示；或为什么有意保持不动？
7. 声音证据：哪一个同步声证明距离、材质或情绪？无来源不写。
8. 结束状态：位置、朝向、道具、惯性、情绪或环境余波留给下一拍什么？
```

质量门：关键动作若删去第 5–7 格只剩“人物做动作”，则从物理/环境、摄影或声音中至少补回一项真正有因果的证据；静态凝视或停留不强加反应。如果补了三项以上却不改变观众理解，删到一项。

## 2. 四类高价值细节

### A. 接触与重量（动作、产品、道具）

先写接触点，再写力量后果。适用于追逐、打斗、厨房操作、产品展示和生活动作。

```text
接触：手抓哪里 / 脚踩哪里 / 道具碰到哪里
传力：身体如何卸力、失衡、拉回或停住
余波：衣料、液体、粉尘、物体、地面、光线怎样延迟响应
```

- 一个动作单元只保留一个主接触关系，避免“踢、抓、转身、射击、爆炸”同时争夺注意力。
- 有移动物体时锁定其路径和终点；有多个对象时先锁数量与角色，不让背景对象凭空加入、消失或换位。
- 产品镜头的“证据”优先是材质、结构、开合、回弹、贴合或使用后状态；不要让产品为了显得动态而变形。

### B. 镜头不是旁观者（连续镜头、揭示、转场）

连续运动镜头必须有路线与事件关系；锁机位则说明为何保持不动，以及观众最终落在哪个可见状态：

```text
起点高度/距离/第一落点 → 经过什么空间门槛 → 因什么遮挡或改向 →
在何处停住/揭示 → 最后对准谁或什么
```

- 连续运动镜头只选择一条主路线；上升、下降、穿越、绕行可构成同一条有方向的路线，但不能各自抢镜。锁机位不需要空间门槛，只需让表演、环境或构图承担变化。
- 遮挡应是现实介质（人群、烟、门框、光线、前景物），遮挡后必须揭示新的叙事信息，不能只为炫技。
- Match Cut/变形转场先锁转场两端必须相同的画面锚：脸部大小、手的高度、屏幕位置、运动方向、镜头距离或色块；转场后立即交代新世界中该动作的真实原因。未能锁定这些锚时，改为 HARD CUT 并重锚空间。
- 开场不要空等：第一帧已发生轻微可读的状态（余震、呼吸、风、看向目标、一个仍在摆动的物体），再让事件升级。

### C. 媒介真实感（UGC、DV、纪实、直播感）

先回答“谁用什么设备、在什么年代、为什么拍这段”。然后让每镜的瑕疵来自操作者或设备，而不是随机滤镜。

- 选一组匹配的设备现象：手持漂移、自动对焦迟疑、曝光变化、构图慢半拍、轻压缩、突然停录等。每镜至多一个需要叙事解释的非完美事件；同一设备现象可跨镜持续，只在原因变化时改变，没有合理原因时可完全不写瑕疵。
- 非完美必须与情节一致：操作者追人时才偏构图；人从明处进入阴影时才有曝光呼吸；焦点在两主体之间切换时才有失焦。
- 声音遵循镜头距离和空间材质。纯日常/纪实默认同期环境声；若没有画内音乐来源，不以配乐替代事件节奏。
- 收尾选择与拍摄者身份相符的一种：机子中途关掉、镜头慢半拍错过离场、停在空景，或转向场外声音。它让“素材”成为完整记录。

### D. 情绪通过事件泄露（人物、关系、对白）

情绪不直接堆“害怕、释然、真实”。先明确人物此刻想隐藏/得到什么，再挑一个可观察载体：

```text
眼神目标变化 / 呼吸停顿或恢复 / 手与道具的关系改变 / 重心与距离改变 /
对方的迟到反应 / 周围声音突然稀薄或重新进入
```

- 一个节拍只让一个关系变化成为第一落点。群像中指定谁承接反应，其他人保持可读但不抢戏。
- 对白发生后留出对方反应或环境余音；不要用连续台词替代身体动作。
- 幽默、悬疑和反转都依赖前后反差：前半建立稳定规则，后半只打破其中一个规则，让机位、身体和声音一起承认后果。

## 3. 密度、时钟与可见性

### 节拍预算

| 生成单元 | 合理密度 |
| --- | --- |
| 5 秒 | 一个事件 + 一个反应/收束；不承诺完整复杂搏斗或长对白。 |
| 10–15 秒 | 2–4 个可分辨节拍；每拍至少留出看清动作终点的时间。 |
| 15 秒一镜到底 | 一条连续路线 + 2–4 次有因果的升级；不写互相冲突的多种主运镜。 |
| 多镜叙事 | 每镜承担建立、触发、反应、转折或收束之一；不让每镜都解释全故事。 |

### 细节取舍

1. 先保留：用户硬约束、开镜状态、主动作与终点、关系/产品的可见证据、空间与连续性。
2. 再保留：一个媒介特征、一个材料/环境反馈、一个对位声音。
3. 最先删除：重复形容词、镜头中看不见的衣饰、无关背景清单、没有原因的“8K/高级/电影感”、彼此冲突的镜头术语。

细节必须适配机位：远景写剪影、方向、距离和环境关系；近景才写手指、皮肤、纹理或小物。高速镜头不承诺可读文字和微小标识。

## 4. 正向不变量：防漂移但不堆负面

当角色数、身份、关键道具、空间侧、产品结构或转场锚点会直接影响验收时，写成正向的可见事实，并在跨镜时简洁重锚。

```text
角色：画面中只有已定义的两人；A 保持画面左侧，B 从右侧进入。
道具：杯子始终在 A 右手；碰撞后仍留在桌沿，而非消失。
空间：摄影机始终位于门一侧；对话轴线不跨越。
转场：两端同一高度的手穿过同一画面位置，动作不断。
```

只锁验收真正需要的变量。把所有物件、角度、光比和身体部位都写成硬约束，会压垮动作与情绪。

## 5. 生成前的导演自检（新增）

```text
□ 对于模糊梗概，是否在不改变用户故事的前提下完成了每拍细节链？
□ 每个关键动作有没有一个有来源的物理、环境、摄影或声音反应？
□ 连续运动镜头的路线是否有起点、空间门槛和叙事落点；锁机位是否写清保持不动的理由与最终落点，而不是运镜名词连写？
□ 参考媒介的缺陷是否由设备/拍摄者/场景引发，并与收尾一致？
□ 是否只写此机位、此速度、此时长实际可见/可听的细节？
□ 复杂动作的数量、位置、接触与终点是否先于风格描述被锁定？
□ 是否删掉了无因果的形容词、无来源音效和非必要伪精确？
□ 最终模型正文是否完全是连贯的镜头语言，没有表格、案例、审计或工作流元数据？
```

## 6. 常见错误与修正

```text
“细节多”但像清单 → 只保留服务本拍意图的一条细节链；其余删掉。
运动很大但没有重量 → 明确接触点、传力方向、一个余波和动作终点。
一镜到底只是连续漂移 → 补路线门槛、遮挡/揭示的理由和最终落点。
UGC 只有复古滤镜 → 写拍摄者身份、设备物理、按因果选择至多一个非完美事件和身份一致的收束。
转场像突然换世界 → 锁两端共同画面锚，转场后立刻写动作在新世界中的原因。
人物在做事却没有戏 → 指定谁想隐藏/争取什么，并让目光、呼吸、手或距离改变泄露它。
```
