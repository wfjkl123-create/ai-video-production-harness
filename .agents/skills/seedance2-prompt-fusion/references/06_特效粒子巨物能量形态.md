# 特效 · 粒子 · 巨物 · 能量 · 形态

> 特效只此一处。打斗/奇观/仙侠/科幻/灾难的特效写法 + 31 类 VFX 词条库。核心：特效不是炫技词，每一条都在封一个具体的"假"。日常 UGC 不用本文件。

---

## 0. 特效总原则：单体多层叠加，不是标签平铺

每个特效点是**一个清晰主体的多层叠加**，不是一串并排的标签。

**奇观合成公式**：`[形态] → [主体材质] → [密度连词] → [色彩+次材质] → [动态/因果] → [本体锚定]`

```text
✅ 奇观式（单主体层层加深）：月牙形 + 电磁火花 + 裹挟着 + 白金色拖影 + 和能量波动 + 的剑气
   —— 7 层单链叠加，主体"剑气"始终清晰，读起来"一道奇观渐次展开"。
✗ 标签拼贴（廉价感）：霓虹紫垂直紫雷 拽出 紫色巨型雷柱 + 隆隆震波
   —— 3 个独立标签并排，主体不清（紫雷？雷柱？震波？），像清单罗列。
```

**6 铁律**：① 单体主体清晰（其他都修饰这一个）② 链式叠加禁平行（用密度连词，不超 2 个并列加号）③ 维度齐 4+ 层（形态+主体+质感+动态+本体）④ 词条必变形（"环状尘云"→"翻卷成环的灰褐尘"，不原样照抄）⑤ ≥10 字门槛 ⑥ 主体动态化（加动词让它"在动"："九道蛇形紫电缠拧成熔金色雷柱"）。

**人话方向（禁学术词）**：诗性润色朝口语+视觉走，禁物理/化学/CG 术语。
```text
✗ 节律性扩散 → ✓ 波纹扩散/一圈圈荡开    ✗ 微滴气溶胶 → ✓ 水雾飞溅
✗ 菲涅尔边缘反光 → ✓ 边缘锐光          ✗ 双重曝光叠像 → ✓ 半透重影/拖影
✗ 析出/凝结成 → ✓ 化作/形成/渗出
```
自检：读出来能不能在脑里"看见画面"？像物理课文就改成直白描述。

## 1. 加点密度：只在奇观点加，过渡动作不加

```text
✅ 奇观时刻（雷击/破雷/被击飞/剑气合成/平台崩碎/云海撕裂）：加，一段戏 5-8 处
✗ 连接句/过渡动作/镜头交代（横移/抬头/后撤/落地撑步）：不加，保持原文流动
✗ 纯镜头层（急推/手持）：不加，除非配套奇观爆震
```
同一词条一段内 ≤2 次，第二次必须变形；一个加点最多 2 色（1 主 1 辅）。

## 2. 题材过滤（特效不跨题材用）

| 题材 | 优先类目 | 禁用 |
|---|---|---|
| 写实武侠 | 战斗/格斗/破坏/粒子/国风/拟声 | 能量场⑨/西方魔法/BOSS/能量强化层 |
| 仙侠玄幻 | 武侠/东方玄幻/元素魔法/国风 | 西方魔法/工业科技/游戏 UI |
| 现代科幻 | 能量场/工业/机甲/电火花/光学/游戏 UI | 东方玄幻/国风 |
| 写实战争 | 现代枪火/破坏/粒子/烟尘/拟声 | 能量场/元素魔法/玄幻/西魔 |

用户写"邵氏写实/不要法术爆炸"时，写实规则强制启用，只用物理细节（尘云/火星/划痕/血雾）。

## 3. 特效质感：通透 vs 塑料（反假贴图）

```text
正向（要）：translucent / semi-transparent / airy / 有间隙 GAPS / 能透过看到背景 / 由细小粒子构成 / 内部发光 / 光穿过
负向（避，放 Avoid）：dense opaque wall / solid glass tube / neon glowing tube / plastic / CGI / video-game look / muddy
```
两个平衡：① 又要"加足"又要"通透"= HUGE/intense + 同时 OPEN/GAPS/translucent；② "密不透风"的解法是拉开间隙+降密度+能透过看到背景，**不是**减风量。

**粒子感 ≠ 整图噪点**：分作用域写——整图 `clean/sharp, no film grain, no photo noise`；特效 `the wind is particulate, full of fine swirling particles (粒子只属于风，不是整图颗粒层)`。

## 4. 能量 / 发光特效：给时间轴，且光要照亮环境

```text
能量不能瞬间从无到最大：一点亮起 → 向外扩散 → 越来越亮 → 面积越来越大 → 约两秒到峰值爆盛。
声音同步走同一条充能曲线（低频嗡鸣攀升 → 峰值轰鸣），声画共用一个高潮点。
光必须真正参与照明：映亮人物背部、甲壳边缘、空气尘粒、地面——只贴在符箓上发光就是假贴图。
前提：环境色调先压低饱和，红金能量光才有视觉增量；满屏高饱和时特效会糊成一团。
能量沿既有受力轴线释放（贴背处 → 正前方），不是随机方向爆炸。
```

## 5. 形态变化：六步因果链 + 锁数量

变形/分离重组/机甲变身/铠甲拼合/法器激活/御剑成型/法阵成型时用——治即梦"形态瞬间替换、凭空多出/镜像复制"：
```text
六步：初始可见 → 外层解锁 → 零件沿可见路径动 → 引导锚牵引重组 → 逐层显形 → 一声+一沉降锁定
锁数量铁律：只一个 / 禁镜像复制 / 禁凭空多出 / 禁跳过中间态
变形对象优先选环境或可牺牲道具：人物/产品的身份锚不参与变形（除非用户明确要主体变）——让世界变、锚点不变。
```

## 6. 巨物尺度：超框 + 比例锚 + 延迟反应

治即梦把巨物拍成"大号道具"。三个抓手：
```text
尺度分层递进：人 → 小物 → 大物 → 巨物，画面始终给渺小参照物。
超框构图：最大主体装不进画框，只给局部（腿/尾/甲壳占据上方或远景大面积），人物只占画面底部很小一块。
延迟反应：巨物动作发生后，地动/尘墙/人被掀飞/恐慌声滞后到达，禁同步同帧。
透视/比例锚：沙地纹理、尘雾、远处山脊、巨物投影从前景延伸到背景，远景略虚化。
主运镜只用 slow lateral truck / dolly back / locked-off，不要同时推拉摇移。
失败线：巨物不要变人形、不缩成普通动物比例，人物不漂浮，镜头不突然变中景摆拍。
```

## 7. 升格 / 子弹时间 / 状态连续性（封"假"）

```text
升格慢动作：次级物理必须一起慢——奔跑起伏、扬起沙尘、甩动衣摆发丝、面部肌肉颤动都缓慢拉长。只人慢、沙尘正常速 = 假升格。
子弹时间：近乎完全静止凝固，连半空尘粒都几乎不动；人物定格在上一秒的动作里（不换摆拍姿势）；全画面只保留一个运动主体（如迸发的能量光），用绝对静止反衬。
状态连续性：湿头发/滴水/汗尘混发——是"刚发生过什么"的证据，HARD CUT/换景别后必须逐镜重写，否则模型让头发自动变干、伤口消失（见 references/03 §6）。
```

## 9. 多层声源声场（大场面 diegetic 声音设计）

大场面灾难/战场/群兽戏，声音不是一句"环境音"，而是**按频率分层、全程铺满、随镜头此消彼长**的一片声场（仅画内音，不配旋律 BGM）。逐层写明 频率位置 + 材质 + 节奏：
```text
最底层 超低频地鸣：巨物体量带来的持续地动轰响，低沉到接近体感的隆隆震颤（low frequency rumble）。
低频层 兽王碾地：沉重脚步砸地一声接一声（heavy ground stomp）+ 甲壳刮过地面碎石的钝重摩擦。
中频层 兽群：埋头拱地的钝闷摩擦、甲肢刮砂的沙沙、扑咬时甲壳相撞的脆硬咔哒，多点散布、有近有远。
中高频层 虫群：翅鞘高速摩擦的尖锐嘶鸣、扑跳落地的轻快顿响、追咬的急促咯咯。
表层 人群：杂沓脚步的噗噗闷响、由远及近又掠过的惊叫呼喊。
```
纪律：各层全程交织叠压、密度饱满、无一刻静默；随镜头横移，各声源远近比例自然此消彼长。一声极远的巨大兽鸣可作"叙事驱动 + 剪辑动机"（听见 → 硬切到声源，见 references/03 §1）。对白戏的 @音色与台词写法见 references/05 §5。
