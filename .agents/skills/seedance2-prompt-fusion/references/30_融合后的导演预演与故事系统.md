# 融合后的导演预演与故事系统

本文件融合原 ref 01 的脑内预演、场面调度、视听签名，ref 05/26 的素材与细节编译，以及 v6.7 Director's Read、directing-engine、storytelling 与 genre guides。它先决定“为什么这样拍”，再决定“怎么写”。

## 1. 先分叙事与非叙事

- narrative：人物选择、关系、信息或价值发生变化，必须完成完整导演读解。
- non_narrative：产品展示、材质变化、抽象视觉、环境氛围或功能说明，只记录具体用途、视觉变化与“不虚构人物戏剧”的拒绝项。
- 同一项目可有两种 lane，但每个 clip 只执行自己的 lane；产品英雄镜头不能被强塞心理戏，人物剧情也不能退化为漂亮产品转台。

## 2. 统一导演预演记录

叙事拍摄前内部回答：本场功能、开头到结尾的价值变化、观众跟随谁、权力如何移动、人物真正目标、阻力与策略、台词与身体的矛盾、一个压住的行为、一个不可替换细节、最该拒绝的俗套。再补原 Skill 的世界规则、人物站位、轴线、空间层次、触发、摄影机动机与可继承末态。

这些字段不是输出模板。把“想挽留但不敢说”编译成擦同一块盘沿两次；把“权力转移”编译成谁停住、谁向前、谁占据前景。

## 3. 一句意图统领完整设置

每场先写一句内部意图，例如“让观众比她早一秒意识到门不会再开”。镜头、焦段、调度、表演、光、声音、剪辑与时长都必须能回答“因为这个意图”。漂亮但不服务意图的技术删除。

- 亲密对话：减少覆盖与游走，让微行为可读。
- 权力冲突：用高度、距离、遮挡和静止差异编码变化。
- 揭示：先遮后显，让摄影机与人物共同发现。
- 决定：用一个不可逆的动作证明选择。
- 产品/变化：用受控摄影、材质光和明确前后态证明价值，不虚构戏剧。

## 4. 项目声音与戏剧弧线

项目选择一个功能性导演声音：观察自然主义、构成古典、运动直觉、表达风格化、亲密极简或图形形式主义。它约束全片常态的机位、运动、光比、色彩、表演和节奏；只有关键转折可有意打破一次。

多段故事先规划 open → rising → turn → climax → release 的趋势，但只从当前已接受素材编译当前 clip。未来弧线是意图，不得覆盖真实成片状态或授权当前镜头提前完成后续高潮。

## 5. 双方差异的统一裁决

- 原 Skill 强调空间、轴线和镜头预演；v6.7 强调目标、潜台词和俗套拒绝：两者必须同时成立，心理读解必须落到原 Skill 的可拍空间载体。
- 原 Skill 倾向导演自主补细节；v6.7 要求不可替换细节：优先从用户故事和素材取证，允许创作时才补，并确保该细节改变表演或镜头，而非装饰。
- 类型指南只提供优先级，不提供套话；不得因“恐怖、广告、动漫”自动叠加一套固定镜头包。
- 不模仿在世导演或受保护工作室标签；用可执行的功能性声音描述替代。

## 6. 导演预演验收

- 开头到结尾是否有一个清晰可见变化？
- 每个摄影和光线决定是否有戏剧或展示动机？
- 叙事场景是否有目标、阻力、策略与可见选择；非叙事是否避免虚构心理？
- 是否有一个只属于本故事的细节和一个被具体替换掉的俗套？
- 末态是否能被下一镜继承，而非在高潮后模糊结束？
