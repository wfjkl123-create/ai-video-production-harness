# 防污染与失败诊断

> 提示词污染的总原理 + 6 个治理方法 + 排查清单 + 失败诊断。**防污染只此一处**。空间/朝向锚点写法见 references/03，情绪/抽象→可见的表演细节见 references/02，本文件立机制与方法，不重复词库。内衣塑身的污染源与清洁写法见 references/08。

---

## 0. 总纲：AI 不理解画面，只字面执行你点名的元素

污染不是"AI 不听话"，而是提示词里某些词把模型注意力拉向错误的视觉联想——它优先把识别到的关键词变成画面里可见的东西，不一定理解现实逻辑、镜头逻辑和你的真实意图。

> **一句话原则：少写污染词、少写否定词、少写抽象词，多写镜头看得见的画面证据。别给 AI 出"命题作文"，要给它做"情境填空"。**

**5 个污染机制：**

1. **Token 拆分** —— AI 把句子拆成一个个视觉任务分别执行，不先理解完整故事。"一个人在医院用 iPad 看剧"→ 人/医院/iPad/看剧，于是病床、iPad 屏幕、影视画面都要出现。
2. **关键词联想陷阱** —— 一个词带出一整套刻板场景（见 §1）。普通场景里有用，要生成反常规、生活化镜头时就把画面带偏。
3. **白象效应** —— 否定词先激活被否定对象。说"不要想白象"脑里先出现白象；"不要学校"反而激活学校，"不要动漫风"反而激活动漫风。AI 对"不要/别/不能"权重弱，对其后的名词敏感。
4. **视觉代偿** —— 抽象动作（背对/望向/电影感/俯视/特写）AI 不知怎么落画面，就用更容易看见的元素代偿。"背对"代偿成后背/背包/头盔背面，"望向"代偿成眼睛/正脸，两个目标冲突就朝向混乱。
5. **命题作文效应** —— AI 为"证明关键词被执行了"宁可牺牲现实逻辑：看 iPad→屏幕转向观众导致人物自己看不到；打游戏→手机/电脑屏幕翻向镜头；修图→显示器反转；读书的字→焦点跑偏变成文字展示。

> 机制 1+5 = "AI 逐元素字面执行、只写镜头看得见的"（SKILL 铁律 6）；机制 3 = 正向锁定（§2 方法二）；机制 4 的朝向冲突用 references/03 §0 的"身体朝向 / 脸朝向 / 视线落点分开写"解。

## 1. 关键词联想陷阱速查

| 触发词 | 模型常见联想（要生活化镜头时会带偏） |
|---|---|
| 护士帽 / 安全帽 / 圣诞帽 / 厨师帽 | 护士服+医院 / 工地+施工 / 圣诞装饰 / 后厨+做饭 |
| 游戏 / 修图 / 看剧 | 手机或电脑屏幕翻向镜头、显示游戏或编辑内容 |
| 学生 / 创业 / 约会 / 直播 | 学校+校服+教室 / 西装+办公室+落地窗 / 玫瑰+蜡烛+餐厅 / 补光灯+麦克风+夸张表情 |

判断标准：**这个词会不会让 AI 认为"必须把某个东西明显画出来"。** 会，就是污染源。

## 2. 六个治理方法

### 方法一 · 找出污染源，换成可见行为
先问：这句话里哪个词会让 AI 自动脑补一整套模板？再把它换成镜头可见的身体动作 + 接触点 + 视线。

```text
打游戏 → 男生坐在地铁座位上，双手横向握手机，两拇指在屏幕边缘快速轻点，眼睛盯着手机屏幕
医院看剧 → 一个人靠在病床上看 iPad，屏幕朝向人物，观众只看到屏幕背面和微弱反光
修图 → 男生坐在电脑前，右手握鼠标，身体微微前倾看着显示器，桌上有数位板和相机存储卡
```

### 方法二 · 否定句全改成肯定结果
```text
不要 X → 写要出现的 Y          不要 A 风格 → 写目标材质/光线/镜头/皮肤/空间
不要某物出现 → 指定替代场景与可见背景   不要某种表情 → 写嘴/眼/眉/头部姿态的正向状态
```
例：不要下雨 → 晴天后地面有柔和阳光、空气清透；不要动漫风 → 真实摄影质感、自然皮肤纹理、真实镜头光影；不要乱手 → 双手自然垂放体侧、手指放松。
**规则：不想看到的东西，绝不写进主提示词。**

### 方法三 · 少写抽象词，多写画面证据
抽象词不是不能用，但不能只靠它，要翻译成可见证据（情绪类抽象词→可见的细节，见 references/02）。

| 抽象词 | 易触发套板 | 视觉翻译 |
|---|---|---|
| 电影感 | 泛黄滤镜/光晕/空镜堆砌 | 清晨公交站，女生站在阳光里等车，白衬衫被光照亮，风轻吹头发，远处行人车流 |
| 松弛感 | 咖啡/沙发/阳光 | 身体重心自然偏向一侧，肩膀放松，手里慢慢转动杯子，眼神不看镜头 |
| 高级感 | 西装/豪车/落地窗 | 干净留白构图，低饱和色彩，真实材质纹理，柔和侧光，物品少而有秩序 |
| 身材好 | 裸露/健身炫耀 | 肩宽腰窄，衣服贴合身体线条，站姿挺拔，外层衣物利落轮廓 |

中文套话速改（同一原理，社区共识版）：`氛围感`→写制造氛围的物理元素（薄雾、逆光轮廓、湿地面反光、低环境声）；`大片感/史诗级`→写物理规模（人群数量、镜头距离、建筑高度）；`质感`单独用→指明哪种（磨砂玻璃、丝绒吸光、纸张纤维）；`震撼`→写造成震撼的那一个画面对比或揭示；`唯美/绝美`→写色彩、构图与光的具体行为，或最重要的那一个视觉细节；`酷炫转场`→写转场名（match cut 匹配剪辑 / HARD CUT / whip pan 甩镜）；`超高清/8K/杰作/顶级品质`→删，质量不是请求出来的。

### 方法四 · 描述镜头里看得见的元素，不只写镜头术语
镜头词可保留，但别只靠"特写/中景/俯视角"，要把该景别里可见的内容写出来（空间锚点写法见 references/03）。

```text
背影看地球 → 宇航员背对镜头站在月面，远方黑色太空悬浮一颗蓝色地球，观众只看到背包、头盔后侧、肩部轮廓
特写宇航员 → 画面集中在上半身，面罩占画面中心，胸前生命维持装置、缝线、肩部反光清晰可见
俯拍宇航员 → 镜头从上方看，能看到头盔顶部、肩膀、氧气瓶顶部、鞋尖方向、地面阴影
```

### 方法五 · 把大词拆成动作 / 空间 / 物体
自带模板的大词，解法不是堆更多限制，而是拆成具体生活动作。

```text
创业 → 凌晨小房间，年轻人坐折叠桌前改方案，桌上泡面盒、笔记本电脑、手写草稿，灯光很暗，眼睛盯屏幕
约会 → 两人坐便利店门口长椅，一人手拿热饮，另一人低头笑着看他，旁边路灯与夜晚街道
直播 → 夜晚卧室，女生坐书桌前对着手机轻声说话，小台灯、一杯水、手机靠书本旁，背景普通书架与暖色床头灯
```

### 方法六 · 反向利用注意力机制
污染机制也能反向用：
```text
想拉近镜头 → 增加目标主体的局部细节描述，把注意力引向主体
想改角度   → 不只写角度词，写这个角度下能看见的身体部位/道具表面/背景遮挡关系
想避免屏幕翻转 → 删"看剧/游戏/修图"等内容展示词，或明确写"屏幕朝向人物，观众只看到背面/侧边/反光"
想修正不听话 → 一次只改一个污染词，别同时改十处，否则无法判断是哪个词带来改善或恶化
```

## 3. 输出前防污染排查清单

```text
□ 有没有写入任何不想看到的对象（不要学校/不要下雨/不要动漫风）？
□ 有没有用自带模板的词（学生/护士/厨师/创业/约会/直播/游戏/修图/看剧）？
□ 有没有只写抽象感受（高级感/松弛感/电影感/治愈感）却没写可见证据？
□ 有没有要求观众看到现实中看不到的信息（屏幕内容/书上文字/画纸正面）？
□ 有没有同时写互相抢注意力的动作（背对镜头 又 望向某物）？
□ 有没有把镜头控制写成纯术语，而没写这个镜头里能看到的元素？
□ 若翻车，能否指出唯一污染词，并只替换这一处重新生成？
```

## 4. 失败诊断与抽卡修正

**先定位失败层级，再对症改一处：**

```text
方向/朝向漂移（忽前忽后、跳轴）→ 方向锚到镜头、朝向三分写（references/03 §0）
主体被污染（多出元素、屏幕翻转、模板场景）→ 找污染源换可见行为（§2 方法一/五）
参考图污染（照搬背景/姿势/构图、风格塌方）→ @ 分工 + 换自洽参考图（references/03 §3、05）
动作瞬移 / 打击失重 / 状态复位 → 写起止+物理反馈+段尾状态卡（references/03、06）
抽象词落不了地 → 翻成画面证据（§2 方法三）
画面内文字/logo 破碎 → 文字保持静止、居中、声明保护，让光绕着它扫——别让模型在运动中重绘小字
提示词被平台拦截 → 换风险表面词为生产语言，不是换语言绕过（见下）
```

**被拦截的安全改写（改表面词，保创作意图）**：拦截多半是措辞撞了风险面，不是创意本身违规。风险词→生产用语：打斗→"choreographed action beat 编排动作段、无写实伤害"；血→红色织物点缀/有色液体；武器特写→"安全道具、拍摄场景摆放"；名人脸/影视复刻→原创角色原型 + 只借镜头功能、色板、节奏。安全提示词被误杀时，加澄清而非删创意："staged 摆拍场景、非写实、无真实武器、原创成年角色"。**不要把敏感内容翻译成另一种语言蒙混**——还会失败，且属于绕过。内衣塑身的品类合规写法见 references/08。

**重抽五裁决（拿到成片先裁决，再动手）：**

```text
保留：本镜的"主花销"（见 §5）已到位、无致命伤 → 锁定收工，次要瑕疵交后期。
后期修：缺陷属于后期域（调色/字幕/音量/首尾几帧不稳）→ 不为剪辑几分钟能修的事烧抽卡。
编辑不重生成：构图时序都对、只错一层 → 用视频编辑只改那一层（references/10 §2）。
重抽：提示词没错、只是这把手气差 → 原词重抽，最多 2-3 次；还不行就是词的问题。
重写：同一缺陷出现 ≥2 次 = 系统性问题不是运气 → 按上表定位层级改词，别抽第三次赌运气。
```

止损：开抽前定好次数上限和"够用即收"标准（主花销到位、次要瑕疵可后期）；预算烧一半仍卡同一缺陷 → 换策略（拆镜头/换模式/该实拍就实拍）。

**抽卡修正纪律：**
- **一次只改一个污染词 / 一个杠杆**，重生成再对比；同时改多处就无法判断是哪一处起作用。
- **失败片段回收**：失败视频不是废片——截 1 秒正确的产品结构 / 半秒自然动作 / 一帧可做首帧的画面沉淀进素材库；70% 正确的帧截图做下一轮首帧，再图生视频收敛。

## 5. 一条生成只有一份保真预算（三花销）

**身份保真**（脸/产品/logo/服装稳）、**动作幅度**（大动作/物理/编排）、**场景密度**（人群/多层环境/天气）竞争同一份生成预算——三样全要 = 三样全糊。写词前先分配：

```text
每条生成点名 1 个主花销 + 1 个次花销，其余主动节省并写成约束。
产品广告 → 主：产品身份（@图锚定）；次：一个材质动效节拍；省：场景密度/人群/天气。
动作舞蹈 → 主：动作幅度（@视频供节奏）；次：@图重锚身份；省：面部特写/布景细节。
对白特写 → 主：面部稳定（锁定机位）；次：那句台词；省：大动作/背景活动。
```

- **身份交给 @参考图背**：文本省下的预算全给动作与时序（同 references/05 §6 权重管理）。
- **大动作的代价是脸**：又要大动作又要脸部特写 = 二选一；情绪放身体和调度，特写单独开一镜。
- **重要小细节占画面越小越糊**（logo/手部/文字最先崩）：放大画面占比，或单独给它一镜。
- **链式生成每隔几段用原始参考图重锚身份**：误差逐帧累积，链到 4-5 代必漂——原始参考图才是身份锚，上一段输出只配当衔接锚（同 references/10 §1）。
- **多目标冲突时保最脆弱的**：产品身份 > 运镜奇观；口型 > 头部大动作；角色一致性 > 复杂编排；首尾帧落靶 > 额外风格变化。谁最容易碎，预算就先保谁。
