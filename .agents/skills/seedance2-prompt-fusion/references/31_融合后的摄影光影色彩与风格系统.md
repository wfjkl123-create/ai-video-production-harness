# 融合后的摄影光影色彩与风格系统

本文件融合原 ref 01/02/05/09 的机位、焦段、光位、STYLE DNA、媒介真实感，与 v6.7 camera、lighting、style、cinematography shot language、color pipeline 和 field-observed tips。

## 1. 摄影先回答观看关系

先决定观众站在哪里、知道多少、与主体多近，再选择景别、视角、焦段感和支撑方式。一个 Shot 只留一个主运镜；副层只能是符合设备和拍摄者身份的轻微呼吸。摄影机运动必须由发现、追随、避让、逼近、揭示或关系变化触发。

镜头合同最小集：景别、机位高度与角度、焦段感、支撑/运动、主体画框与方向、结束构图。专业用户给出的精确决定原样保留；普通任务以观众可见结果表达，不堆参数。

当镜头包含明确 FOV/焦段、狭小空间、强角度、多人复杂站位、首帧揭示或具名创意镜头装置时，先读 ref 40；不要只凭焦段名判断可行性。先锁镜头主要任务与主体在画面中的可读尺度，再用 refs 41–43 求解机位和装置。FOV 只描述视场，不单独决定景别、透视、人物大小或微表演是否可读。

## 2. 光是有来源的空间事件

- 指定可信光源：窗、灯、屏幕、太阳、招牌或火焰。
- 光位、软硬、明暗比和色温服务人物暴露程度、材质可读性与空间层次。
- 光变化必须有画内原因；门打开、云遮日、屏幕切换或主体遮挡均可。
- 产品材质用形状稳定的高光、反射与阴影证明，不靠“高级、8K、奢华”。

## 3. 风格是可继承的系统

STYLE DNA 统一记录媒介身份、镜头行为、光线逻辑、有限色板、材质/颗粒和节奏。风格不是一串形容词，也不是每镜重新抽卡。UGC 的抖动、失焦、滚动曝光、风噪和构图修正必须来自“谁拿什么在拍、为何来不及”；电影感则来自受控观看关系、光与色，而非默认慢动作。

色彩在生成阶段只描述主色关系、跳色和光源逻辑；显示变换、ACES、LUT、色域、合法电平与版本属于后期交接。不能把后期管线术语写进提示词冒充模型控制。

## 4. 连续性与有意变化

跨镜锁定媒介、主色板、黑白层级、主体肤色/产品色和项目导演声音。场景转折可改变光比、色温或运动强度，但一次只改变能读出意义的主变量，并保留身份与空间锚。

## 5. 双方差异的统一裁决

- 原 Skill 的焦段/光位词库提供选择，v6.7 的意图与 shot contract 决定取舍：不为“专业”把所有可选词写入同一镜头。
- 原 STYLE DNA 可保留具名摄影术语，但不得以在世作者模仿替代视觉说明；必须拆成机位、运动、光、色、介质与节奏。
- 原 UGC 非完美事件与 v6.7 anti-slop 合并后，每镜最多一个有因果的介质偏差；随机缺陷同样是 AI 套路。
- 精确调色与交付元数据留给后期，提示词只写画面意图。

## 6. 摄影验收

- 摄影机为何在这里、为何移动、在哪里结束？
- 是否只有一个主运镜，且主体方向与画框占比可继承？
- 镜头主要任务、主体画框占比、焦段感和空间净空是否相容；微表演在当前尺度是否真实可读？
- 每盏关键光是否有来源，并真实作用于皮肤、材质或环境？
- 风格能否用媒介、光、色、运动和节奏复现，而非只靠标签？
- 生成意图与后期技术要求是否被清楚分开？
