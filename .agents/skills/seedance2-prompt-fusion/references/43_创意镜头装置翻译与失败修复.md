# 创意镜头装置翻译与失败修复

本文件把具名摄影装置或风格诉求翻译成“相机/镜头/主体/前景背景如何变化”，并限制多个强装置相互冲突。装置服务故事，不替代故事。

## 1. 装置翻译合同

每个强镜头装置内部先回答：

```text
deviceName：用户要求的装置名称，原样保留
dramaticJob：它让观众发现、失衡、逼近、疏离、震惊或转换什么
setup：首帧必须建立的主体、前景、背景和空间参照
trigger：哪一个画内事件启动装置
cameraBehavior：机位路径、镜头视野/焦点变化、支撑方式
subjectBehavior：主体同时在做什么，不能冻结等待摄影机表演
peak：观众在哪一刻读到装置效果
recovery：装置结束后画面如何稳定或交给下一镜
protectedElements：人物身份、产品结构、台词、轴线等不可牺牲项
failureSignature：装置最可能如何失败
```

最终正文不输出字段名，只把可见变化编入当前镜头因果。

## 2. 单主装置纪律

一个短 Shot 只允许一个 `primaryDevice`。每个强装置必须填写 setup、trigger、cameraBehavior、subjectBehavior、peak、recovery；手持呼吸、轻微跟焦或环境运动可以作为低强度质感层，但不能与主装置争夺注意力。第二装置即使标成非主，只要强度仍高且与主装置同时发生，也直接视为冲突。

用户明确同时要求两个装置时：

- 若可按时间先后执行，写成建立 → 主装置 → 恢复，不在同一瞬间叠加；
- 若两者物理或叙事冲突，保留用户优先级更高的一项，并暴露取舍；
- 不得用“更顺滑、更电影化”静默抹掉用户明确点名的装置。

## 3. 常见装置的可见翻译

### Dolly zoom

- 先建立主体与远近背景参照；没有背景尺度变化就无法证明装置。
- 相机向前/后移动，同时视野反向变化，使主体画框大体稳定而背景透视明显伸缩。
- 精确距离、FOV 和持续秒数只有在用户给值或当前 surface 实测支持时才写；否则描述可见结果。
- 常见失败：只做推拉、主体大小漂移、背景没有层次、动作人物冻结。

### Crash zoom

- 必须由发现、震惊、证据出现或喜剧落点触发；先明确变焦目标。
- 快速改变画框后短暂稳定，让观众读到目标；不与同时大幅平移、旋转和甩镜叠加。
- 常见失败：没有触发、目标不在焦点、变焦后继续漂移。

### 荷兰角

- 滚转方向必须相对画面垂直线描述，并用门框、地平线、桌沿等参照证明。
- 俯拍/仰拍与滚转分别求解；倾斜服务失衡、压迫或关系偏移，不是通用“电影感”。
- 常见失败：只有人物歪斜、背景仍水平，或左右倾斜语义不清。

### 窥视/遮挡揭示

- 前景必须有合理物理来源和拍摄者位置；遮挡比例不能把主要事件永久盖住。
- 写清主体何时、从哪里、因何进入可见区域。
- 常见失败：随机黑边、前景粘在镜头上、首帧自动全员可见导致揭示失效。

### 甩镜/鞭甩转场

- 起点与终点分别有明确主体或空间锚；中段模糊来自高速转动，不是全片持续糊。
- 转场两侧的运动方向、亮度/色块或轮廓需要可接。
- 常见失败：没有落点、方向相反、把主体变形当运动模糊。

## 4. 动态曝光与运动节奏

“180-degree shutter”只可作为摄影内部参考。除当前 surface 明确可控外，正文应写成观众可见的结果：自然运动模糊、手脚边缘不过度冻结、快速转动时中段适度拖影、装置峰值后恢复清晰。不得把物理快门角度写成模型已保证执行的参数。

## 5. 风格与命名翻译

- 用户明确点名的镜头装置保留名称，并补可见执行；不要只留下名字。
- 用户点名导演/影片风格时，保留合法且必要的锚点，同时拆成观看距离、机位行为、光色、节奏和材质；不得让名称替代镜头设计。
- 附件默认英文不进入本系统。中文台词和人物因果保持中文；只保留白名单摄影锚点。
- 素材标签遵守当前 surface：Higgsfield 原生标签逐字保留；Harness 使用 `@素材[exact-id]`，不得手写自由 `@图N/@视频N`。

## 6. 最低成本失败修复

| 失败 | 先检查 | 最小修复 |
|---|---|---|
| 装置没出现 | 是否有 setup、trigger、peak | 补一个可见参照与单一触发，不先加更多术语 |
| 主体大小漂移 | 装置是否要求主体画框稳定 | 锁主体画框，减少额外运镜 |
| 背景没变化 | 是否有前中后景层次 | 增加真实背景参照或改用更适合的装置 |
| 人物像木偶 | 摄影机运动时人物是否仍有任务 | 恢复触发—反应—选择链，不加随机微动作 |
| 空间穿墙 | 机位净空是否存在 | 调整距离/视野/站位或拆镜，并暴露实质变化 |
| 画面过度倾斜 | 俯仰与滚转是否混写 | 只保留服务故事的一个倾斜维度 |
| 多装置互相抵消 | 是否有两个 primaryDevice | 保留一个主装置，其余改为低强度质感或移到下一镜 |

## 7. 验收

- 只看画面变化，不看术语，观众能否认出装置？
- 装置是否由故事事件触发，并在峰值后留下新状态？
- 主体是否继续表演，身份、产品、台词和轴线是否保持？
- 是否只有一个主装置？
- 所有精确数值是否有证据级别；无证据时是否已翻译为可见结果？
