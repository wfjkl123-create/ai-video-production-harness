# Seedance 2.5 基础公式与真人角色

## 0. 适用、入口与验收合同

**什么时候用**：所有 Seedance 2.5 新生成任务；纯文生真人、多人物对白、首帧/首尾帧和多模态生成都先用本公式建立故事与身份。

**什么时候不用**：只修改已有视频时走编辑合同；只增加尾部走延长；白模和多宫格还必须加载各自专项手册。基础公式不能替代 operation 选择。

**产品入口与操作步骤**：进入“视频生成”→选择 Seedance 2.5→选择首帧/首尾帧/多模态或纯文生→设置画幅、分辨率与 4–30 秒时长→按下述四部分写提示词→生成后按本文件末尾清单验收。UI 与参数提交前以当前页面复核。

**常见失败模式**：素材只写“参考”导致污染；一句话概述只有风格没有事件；具体情节缺少触发/反应/结束状态；真人堆形容词却无稳定识别点；多人共用一段身份和声线导致串脸串词；全局补充重复动作导致模型反复执行。

**短原创例子**：

```text
素材描述：图1只负责女人的脸、短发和灰色风衣；禁止迁移姿势、街景和文字。
一句话概述：雨夜街角，女人误把陌生男人当成网约车司机，发现误会后两人从警惕转为忍笑。
具体情节：00–04s 她拉开车门……；04–08s 男人抬手解释……；08–12s 她看见车牌后愣住……
全局补充：女人身份和风衣不变，两人声线独立，保持街灯光向；无字幕、无水印。
```

**验收**：四部分是否各司其职；素材职责是否唯一；故事因果是否完整；真人身份和声线是否可区分；人物表演是否由触发产生；生成后是否逐人、逐句、逐时段核对。

**官方追溯**：基础提示词 outline `CVRHdYwawooBvIxWKMUcg86lncf`，sourceOrder 192–217；真人写法 outline `Aosyd5Ih5oVwkTx0s7ycyMRcnSe`，sourceOrder 218–259。

## 1. 官方基础骨架

```text
完整提示词 = 素材描述 + 一句话概述 + 具体情节描述 + 全局补充（结尾）
```

### 素材描述

按实际上传顺序写“编号 + 唯一职责 + 禁止迁移”。无素材时整个模块省略，不能虚构参考图。

### 一句话概述

压成：`主体 + 地点 + 核心事件 + 题材/视觉风格 + 关键运镜（确有必要才写）`。

这句话只立故事脊柱，不能替代后面的动作因果和镜头执行。

### 具体情节

按时间轴或故事线写。每个区间至少回答：

1. 镜头从哪里看、如何运动；
2. 开始状态是什么；
3. 什么事件触发动作；
4. 主体怎样行动，对方/环境怎样反应；
5. 台词、画内音、物理反馈是什么；
6. 区间结束时人物、道具、视线、摄影机处于什么状态。

正向描述承担主要控制；反向项只列真正会破坏成片的字幕、BGM、变形、越轴、无关人物等。

### 全局补充

只重申贯穿全片且跨镜容易漂移的变量：角色身份、机位/轴线、场景核心结构、光向、声音范围、无字、关键禁项。不要把每段动作再复制一遍。

## 2. 真人角色八维公式

官方公式可归纳为：

```text
人物 = 年龄/族裔 + 肤色与皮肤质感 + 面部结构 + 眼神与底层情绪
     + 发型发色 + 服装与材质状态 + 体型/情绪/气质 + 其他必要要求
```

### 可执行写法

- **年龄/族裔**：具体年龄段 + 地域/族裔 + 骨相或脸型，不用“漂亮女生”空泛概括。
- **皮肤**：冷暖、肤色、毛孔/雀斑/干纹等真实纹理；“去 AI 感”要落到可见纹理与光线。
- **面部**：眼型、眉骨、鼻梁、唇形、颧骨/下颌中选 3–4 个稳定识别点。
- **眼神**：视线目标 + 目光状态 + 底层情绪；“有灵魂”必须变成眼睑、焦点、停留和回避。
- **头发**：颜色 + 长度/发型 + 发丝状态 + 风/湿度/运动互动。
- **服装**：版型 + 颜色 + 类别 + 材质/新旧状态 + 穿着细节。
- **体型/气质**：骨架、肩颈、姿态、呼吸与动作方式；不要只堆“清冷、破碎、电影感”。
- **其他**：构图、视线或动作若已在 Shot 中明确，不在人物定义重复。

## 3. 人物一致性与表演不是一回事

人物定义负责“是谁”；时间轴负责“此刻为什么这么做”。每个表演节拍写成：

```text
触发事件 → 生理/情绪反应 → 动作选择 → 对方反应 → 新状态
```

例如“尴尬”不是指令；应写成：听见对方的问题后，她短暂移开视线，指尖捏住杯沿又松开，嘴角试图维持礼貌微笑，对方看见后停住追问。

## 4. 去 AI 感的优先级

1. 真实光源与合理曝光；
2. 皮肤、头发、布料的非均质纹理；
3. 由触发产生的微反应与不完美停顿；
4. 明确视线目标和呼吸；
5. 最后才是“写实、电影级”等风格词。

不要用一长串审美形容词代替可见事实，也不要把同一个动作在多个段落重复，防止模型反复执行。

## 5. 纯文生多角色对白合同

没有人物参考图时，每个主要角色必须有独立身份和声音锚，不能共用一段人物描述：

```text
角色A：年龄/骨相/发型/服装/体态；声线、语速、音量与说话习惯。
角色B：与A可区分的年龄/骨相/发型/服装/体态；独立声线与说话习惯。
```

对白逐句写成：`时间 + 说话人 + 动作/视线 + 台词 + 听者可见反应`。一人说话时，另一人保持听者状态；下一句前留出呼吸或反应时间。全片禁止串词、换声、两人同时说同一句、凭空克隆角色。

30 秒内出现多场景、多轮对白或结尾反转时，再读 `25_自适应控制与30秒对白密度.md`：按目标声线实际试读，不使用统一“每秒字数”冒充硬能力；先为建立、听者反应、不可压缩动作和结尾停留分配时间，再写台词。

切到新场景后重新锚定：谁在画面左/右、面对谁、坐/站在哪里、手里有什么、摄影机在哪一侧、180 度轴线如何保持。上一场的衣着、身份、关系和情绪余波继续存在。

## 6. 基础自检

```text
□ 每个素材是否只有一个主要职责，禁止迁移是否明确？
□ 一句话概述是否包含事件，不只是美术风格？
□ 每个时间段是否有开始状态、触发、动作、反应和结束状态？
□ 人物八维是否只保留稳定识别点，没有堆砌互相冲突的形容词？
□ 多角色是否逐人定义身份和声线、逐句绑定说话人，并写听者反应？
□ 多场景/多轮对白是否选择了最低充分控制等级，并通过实际试读？
□ 切换场景后是否重新锚定左右位、轴线、道具和视线？
□ 抽象情绪是否变成视线、呼吸、肌肉、手部和对手反应？
□ 全局补充是否只重申跨镜铁律？
```
