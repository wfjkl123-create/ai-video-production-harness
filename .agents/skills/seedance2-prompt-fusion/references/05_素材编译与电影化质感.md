# 素材编译与电影化质感

> 两件事：① 把故事/剧本/小说/口播素材编译成可拍材料（进导演系统前的入口纪律）；② 即梦投喂的工程写法 + 电影级反塑料质感。STYLE DNA/大师基因见 references/01，去塑料基础见 references/02，资产先行见 references/07。

---

## 1. 素材编译入口（故事/剧本/口播 → 可拍材料）

用户给的是故事大纲/剧本片段/小说段落/分镜草稿/口播文案时，先编译再进导演系统，别把文学段落直接改写成镜头。

**① 模式选择**（能判断就直接选，标"默认"）：
```text
一镜到底：单一连续动作、空间不复杂、情绪/动作流畅递进、适合跟拍/推进/固定机位。
多机位分镜：节奏紧凑、动作变化多、多人对话/打斗/追逐、需要反打/特写/转场/冲击点。
素材像小说/口播情绪递进 → 默认一镜到底；像动作/冲突/多事件 → 默认多机位。Seedance 2.0 或不支持长时长的入口，>15s 拆 Generation；Seedance 2.5 普通生成可原生到 30s，30–180s 只在明确选择超长入口时使用。
```

**② 有无参考图决定描述密度**（最实用）：
```text
有参考图：角色/道具/场景只写 20 字内核心识别 + @图号 + 职责分工，不重复大段外貌（防污染）。
无参考图：补足物理描述——外形、服装材质与颜色、面部特征、状态、空间布局、光线、散落物。
```

**③ 禁文学修辞，全翻成可见物理证据**：
```text
✗ 心如刀割 → ✓ 双手按住胸口，呼吸变急，肩膀收紧，嘴唇发白
✗ 怒火中烧 → ✓ 下颌咬紧，颈部肌肉绷起，视线固定对方脸上，右手攥紧桌沿
✗ 城市在夜色中沉睡 → ✓ 夜晚街道无人，窗户大多熄灯，路灯在湿地面形成暗黄反光
```
抽象词不是不能理解，是不能直接投喂——必须落成"身体部位 + 动作方向 + 表情肌肉 + 道具/环境反馈"（同 references/04）。

**④ 对白绑动作节拍**（对白不受"禁修辞"限制，但必须绑一个动作）：
```text
格式：[角色/旁白] + [情绪标签] + [关联动作] + 说："台词"
例：母亲把碗放到桌面，声音压低，在"人家"两字上加重，说："你看看人家……再看看你自己。"
硬规则：每角色每镜≤2 句；台词短、口语、能被口型和动作承载；旁白只保留素材已有的不新增；字幕后期加。
```

**④.5 每镜选一个节拍类型**（拆脚本时给每镜指定它的"事件"，公式：前状态 → 可见动作 → 改变后的末状态；末帧必须不同于首帧，否则这镜白拍）：
```text
到达（主体进入新空间）· 揭示（隐藏信息变可见——灯条扫过产品标签）· 抉择（用手势完成选择——放下信封看向门）·
变形（材质/环境改变——霜漫过玻璃停在logo前）· 反转（预期动作掉头）· 追逐（一方逼近）· 接触（两元素相遇）· 退场（走出/隐没/消散）
```

**⑤ 秒级时间轴**（每动作知道发生在什么时候，别给 5 秒塞 6 个动作，每 1-2 秒一个明确节拍）：
```text
一镜到底：0-2s 建立位置与起点 / 2-6s 主体动作推进 / 6-10s 冲突或证明 / 10-15s 结果与尾部状态留钩子
多机位：分镜1丨0-2s丨景别+运镜：动作 …… 分镜N：动作闭环/尾帧状态
```

## 2. 即梦最稳写法：中文叙事骨架 + 英文术语锚点

即梦对"中文写谁在做什么 + 关键术语英文锚定"理解最稳——不是纯中文（术语不精准），也不是纯英文 tag soup（动作不自然）。术语英文白名单见 SKILL 铁律 4。
```text
镜头：match cut / top-down god's-eye view / slow dolly out·in / side tracking shot / ECU / MS / locked-off / bullet time / motion blur
光学：12mm wide / 50-85mm 长焦 / 极浅景深 T1.4 / anamorphic widescreen / 浅景深
质感：35mm Kodak Vision3 film grain / color-negative / low-saturation / 轻微胶片颗粒
构图：dutch angle 荷兰角 / 越肩背面视角 / 三分法
```
> 属性清单行可用"+"密集连接（`locked-off shot + 全景 + 水平正对X`），但**主体动作仍用自然句子**——即梦吃属性清单的"+"，动作叙事要句子。

## 3. STYLE DNA 头部块（专业级四块，别简化成一句基调）

风格锚定到具体导演/影片/胶片，且要写到"摄影指导能照着打光"的程度。四块写全（全段统一、只写一次）：

**① 风格定调**：媒介 + 具名导演/影片/类型 + 质感 + 色调一句话；**具名之后立刻把那个"氛围"拆成几个可视维度**（沙丘 →「巨物体量感 / 低饱和沙色 / 大气尘霾 / 辽阔纵深 / 渺小尺度对照」），别让模型自己猜"沙丘味"。可加"完全写实，禁止 3D"压住 CG 感。
**② 光影布置（具名光位，不只写"侧光"）**：主光从哪个方向、穿过什么进来；补光在哪；负补光压暗谁；空气介质（薄雾/尘）；轮廓光落在哪些边缘（发丝/肩线/衣袖/道具边）；光源是否在画面内要声明（"天光不在画面内"），天光与地面可冷暖分离（"天光偏冷、地面偏暖"）。
**③ 相机规格（参数即风格，唤醒训练数据）**：画幅 + 焦段 + 光圈 + 帧率 + 快门 + ISO + 白平衡 + 滤镜（如 Black Pro-Mist 1/8）+ 对焦点 + 景深。
**④ 调色 / 影调**：对比 + 黑位 + 高光 + 高光色/阴影色 + 皮肤（保留毛孔细纹发丝、哑光不油亮）+ Bloom/Halation/颗粒/暗角。

示例（家庭情绪戏，暖白＋冷调对比）：
```text
① 真人实拍 live-action，非CG非动画；是枝裕和式家庭日常质感，自然室内窗光，暖白生活色调、情绪处压低饱和、克制不狗血。
② 主光为午后窗光从画面左后方落地窗斜射进客厅、经纱帘柔化；正前方白色反光板极淡补脸、保住眼神光；屏风背光侧轻微负补光；空气极淡薄雾，发丝/肩线/衣袖/道具边有柔和暖金轮廓光。
③ 全画幅，50–85mm，f/2，25fps，1/50s，ISO 400–800，5200K，Black Pro-Mist 1/8，眼睛精准对焦，浅景深。
④ 低对比、黑位轻抬、高光柔压；暖白高光、青灰阴影；皮肤保留毛孔细纹发丝、哑光不油亮；轻微 Bloom/Halation、极轻 35mm 颗粒与暗角。
```
> 相机参数与色调必须和"基调一句话"自洽——奶油柔焦/粉杏暖金/梦境化适合浪漫或产品柔美，凉薄冲突戏别套，否则柔光会消解张力。具名风格 A×B×C 配比与不互斥自检见 references/01 §2。

## 4. 色卡锚定（颜色一致性杀手锏）

上传一张色卡图作 @参考，强制所有颜色按色卡执行（比"低饱和灰蓝"稳得多）：
```text
@色卡图 作为整段画面色卡锚定，所有色彩严格按色卡 N 色执行，不可偏离色板，重点呈现[暖灰雾沙色地面/偏冷天光/尘烟暖调]。
```
颜色还要锁成系统 + 双区分轴：每方一个固定色（相邻色拉开饱和度）+ 形态/质地（软流动粒子 vs 硬结晶尖锐）。同一硬铁律在 正向 + 锁定 + 负面 三处复写=注意力加权（但术语堆叠≠重复=稀释）。适合多镜调色统一、品牌色/产品色锁定。

## 5. @音频音色 + 台词（对白戏）

```text
歌/配乐 → 只标 @audio_N，不转写歌词，描述表演。
对白/人声 → 标音色 + 写台词 + 声音指导：
  角色（@音频N + 普通话男/女声 + 语调平静/温和 + 在"关键词"上自然重音 + 念白方式[扁平/克制/略带关切]）："台词"
行内音频标签（即梦实测向）：台词末尾加方括号点音色与音效——"领旨" [低沉男声][编钟余音]；支持度随版本变，失效就回落到上面的声音指导写法。
```
> 一角色一 @音色；**不要把台词转写成会让模型生成新声音念字**——@audio 携带台词，文字只给你定调；情绪放脸上不堆在声音里（声音指导比台词内容更决定表演真实度）；默认画面无字幕，台词只驱动口型，字幕后期加。

**口型是音画联合约束**：音画一次同过程生成，口型精度被头部转动、大幅运镜、繁忙手部动作一起挤压——口型重要的镜头用锁定 medium close-up、不转头、不摸脸、简单表情。可靠度排序：音效 > 配乐 > 对白，对白最脆弱先试拍；台词要紧时压低同期配乐与音效。可靠口型预算远小于"能塞下的字数"：一句 = 一口气（约 1.5-2.5 秒一个意思），普通话口型最稳（训练权重最高），长台词宁可拆镜也别硬塞。即梦的对白口型是开关项（可能默认关），生成前确认已开启，别先怪提示词。有真人录音素材时，@音频 就是口型编译器——模型只对口型不再自己配音，比让它合成人声稳得多（仅用自有/已授权录音）。

## 6. 反塑料 Capture Realism（电影级质感天花板）

AI 视频最常见的失败是**过对比、塑料感**。产品 TVC / 高质感片 / 跨段零漂移时叠加；日常 UGC 只借前两条。四机制：
```text
① 平面间大气（最大杠杆）：写"雾/空气密度悬浮在相机、主体、背景之间"，逼远景比前景更柔更脱色更低对比，主体坐进画面深度里。浓度按场景缩放（室内 thin / 外景 light / 夜戏废墟 heavy）。
② 有湿无亮（仅潮湿/出汗/雨）：表面 damp 不是 beaded、wet 不是 glossy，潮让颜色加深、不产生高光点；湿发 damp matte clumping 不油亮。干场景删此条。
③ 皮肤逐区灭高光：额头/鼻梁/颧骨/太阳穴/下巴/锁骨零高光（鼻梁颧骨爆高光是 AI 皮肤最大破绽）+ 真实绒毛/细毛孔/次表面散射/暖调；讨喜上限：纹理 fine/soft/even，无痘无疤无粗毛孔，真实但永远好看。
④ 对比曲线说三遍：影调（阴影轻提、高光柔滚降、不死白死黑）+ 灭高光（所有表面 specular 外科式去除）+ 调色（低对比、略去饱和、保暖调）。说一遍会被模型默认对比覆盖。
```
无人纯环境镜：删皮肤句，保留①④套到环境表面（湿水泥/金属/玻璃）。商业光泽（棚拍）时此引擎可减/可跳。

**五种电影模式（选一）**：M1 叙事（手持带呼吸·负片日光teal-amber）/ M2 棚拍编辑（锁三脚架·饱和编辑，唯一允许刻意高光）/ M3 动作（全程手持·暗部重颗粒尘雾）/ M4 演出（手持+环绕硬切·舞台冷暖bloom）/ M5 氛围空镜（锁定或极慢推拉·调色板驱动给hex）。

**密度纪律**：单镜成品 280-400 词，多镜不超 600，每个词都要干活。**超预算要压缩时按序保留**：@分工与 tag > 开场实态（参考图带不了的）> 本镜动作与端点 > 情感载体 > 连续性锁 > 已完成/预留节拍排除——先删的永远是风格助推词、重复形容词、未来剧情摘要、参考图里已可见的背景描述。**情感载体不许省**：让观众产生感受的那几句具体光线/表演/声音选择，优先级高于连续性锁——连续性全对但情感平坦的片子照样是废片，照样重抽。**权重管理**：别花大量笔墨写人物穿着款式（算力会被分散到表皮、逼出标准平视摆拍），精简到身份+情绪+动作，把算力留给空间、光影、胶片质感（有人物三视图时尤其不必再描述形象）。**分辨率感知细节**：只写这个机位/焦段/运动/光照下相机真能解析的细节（高空高速看车 → 车标读不出，删，只剩剪影+色块+车灯+运动模糊）。**夜戏**：实用光驱动、整体偏暗+硬实用光穿透（不是亮夜、不是满屏 teal），雾接住灯束成可见光锥。

## 7. 建 / 改双寄存器（图生视频 / 迭代心智模型）

判错寄存器是最大时间黑洞：
```text
建（重型）：基于参考图出新关键帧/首帧/定调 → 信息密度高，重型 prompt 把"按我说的造"推满。
改（轻型）：在现成图/帧上调一处 → "改 X，其余全部不变"，写越多越可能顺手重画没让动的地方。
```
迭代优先走"改"；要换姿态/换机位/换结构这种大改，回"建"重起，别在微调里硬磨。

**图生视频做减法（底图定生死）**：图片阶段把光影、质感、冷暖、哑光皮肤钉死后，视频提示词只交代要动哪里（"轻微呼吸、温柔打字、保持原有光影"），别把图片提示词的光影/材质/场景再抄一遍——AI 会顺底图物理逻辑自然推演（胸腔起伏、手指轻敲、阴影自然附着）。

**图生视频两模式（写动作前先选）**：
```text
Hold 模式（图就是这一刻，让它活着）：先判断人物为何维持这一刻。允许有呼吸张力的主动静止；只有注意力、气口、风、触碰或情绪压力等 cue 出现时，才选择一个镜头可读的眼睑、呼吸、发丝或视线变化，不固定数量、不均匀散布。
  其余用"正向 + 锁定"双句钉死——"她保持坐在窗边，不起身、不转身、不出画"；运镜至多一个 slow push-in。
React 模式（有事发生在主体身上）：把一个情绪展开成子节拍并给足落地时间——"听见声音 → 眼睛睁大 →
  血色涌上脸颊，用 2-3 秒完成"；赶出来的情绪像故障帧，关键节拍 ≥2s。图明显是"戏中一刻"而非
  自然开场帧时，锚定起点："视频从这一瞬间开始"。
```
