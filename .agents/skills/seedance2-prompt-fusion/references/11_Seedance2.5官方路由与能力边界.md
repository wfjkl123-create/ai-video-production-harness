# Seedance 2.5 官方路由与能力边界

> 来源基线：即梦官方在线《Seedance 2.5 使用手册》，2026-08-07 抓取，页面显示 08-06 更新。在线页是能力与案例主证据；Word 导出只作文字/静态图交叉校验。界面、价格、积分与参数可能变化，执行前仍须看当前入口。

## 1. 先判任务，不要把所有请求都写成“普通生成”

| 用户目标 | 入口/路由 | 提示词的核心责任 | 不可混淆 |
|---|---|---|---|
| 4–30 秒新视频 | Seedance 2.5 普通生成 | 素材分工、全局设定、无缝时间轴、全局约束 | 新建视频恰好 30 秒时默认走这里 |
| 30–180 秒一次性视频 | 超长视频 | 全局参数、角色/场景锚、连续故事线、阶段状态 | 独立模式；30 秒只有用户明确选择超长入口时才走这里 |
| 在现有视频尾部增加 4–30 秒 | 视频延长 | 只写新增区间；继承原片终态并设计延续/转场 | 原片须在当前入口允许范围内；官方页当时要求底片 ≤30 秒 |
| 文字修改现有视频 | 智能编辑 | 修改对象 + 变化 + 生效时序 + 保留项 | 不要重写整部视频 |
| 圈选/箭头/点位修改 | 高级编辑 / 视频编辑 | 标注对象与时刻 + 局部变化 + 全片/局部作用域 | 标注负责“哪里”，文字负责“怎么变” |
| 用 3D 预演控制动作/运镜 | 白模控制 | 先选严格渲染或创意参考；参考图负责外观/材质 | 只有严格渲染模式才把白模当空间运动权威 |
| 用故事板或资产宫格控制视频 | 多宫格 | 先声明每格代表镜头、人物、场景或其他对象 | “一格一镜”只适用于明确的分镜宫格 |
| 移除 BGM/字幕、绿幕、局部消除、视角修改、音色/多人参考、转场 | 对应编辑或多模态模式 | 精确写输入职责、修改对象、时间范围、保留项 | 官方案例展示能力，不保证任意复杂输入都稳定成功 |

### 1.1 一个主操作，零至多个专项能力

每次 2.5 任务先选择一个主操作：普通生成、超长、尾部延长、文字编辑、标注编辑、白模、两段无缝转场或多宫格。BGM、创意迁移、局部消除、视角、音色、多人和绿幕是专项能力，只能叠加在主操作上；每个专项必须声明它作用的对象、时间范围和保留项。

不要把两种主操作写进同一份提示词。例如“延长原片”与“重做原片”为不同任务；“两段无缝转场”只生成桥接段，不能借机重写两端视频。30 秒新视频默认普通生成，只有用户明确选择超长入口时才进入超长模式。

## 2. 当前官方参数快照（只作编译前检查）

- 输出 `duration`：官方页列为 `-1` 或 4–30 秒；分辨率列为 480p、720p。
- 图片：单次最多 30 张；官方建议主体图 1–8 个更稳，更多主体稳定性下降。超过 5 个主体时，多张单视图通常比一张多视图更稳。
- 视频：最多 10 段，单段约 2–30 秒，合计不超过约 30 秒；官方建议主体视频 5–10 秒更稳。
- 音频：最多 10 段，单段约 2–30 秒，合计不超过约 30 秒；支持仅音频输入。
- 视频编辑：官方建议输入 20 秒以内效果较好；参考图 1–5 张较好，6–8 张可尝试但稳定性下降。
- 超长视频：独立入口 30–180 秒。
- 视频延长：官方页面当时要求底片不超过 30 秒；单次新增 4–30 秒，可把 30 秒底片延到 60 秒。

这些是 2026-08-07 官方页面的快照，不写成永恒常量。若当前 UI 或 API 与此冲突，以当前已验证入口为准并记录差异。

## 3. 素材职责合同

任何多模态提示词先列清单。审计记录至少含 `素材 ID | 生效区间 | 唯一职责 | 保留范围 | 禁止迁移 | 冲突优先级 | 退出状态`：

```text
@素材[person-a]：全片生效；只负责人物身份、发型、当前服装、鞋和体态；禁止迁移背景、姿势、构图。
@素材[scene-a]：全片生效；只负责场景结构与光向；禁止迁移人物。
@素材[motion-a]：0–6 秒生效；只负责动作节奏与摄影机轨迹；禁止迁移原人物、字幕、水印、品牌。
@素材[voice-a]：对白段生效；只负责说话人音色、语速与停顿；禁止当作画面参考。
```

除非用户明确缩窄为“仅身份/仅脸部”，人物或角色参考默认是**完整可见人物参考**：身份、脸、发型、当前服装、鞋、配饰和身体比例都应保持；背景、姿势和构图默认不继承。每个受控维度只能有一个权威素材，冲突时以责任表中的优先级裁决。

平台编号必须按实际上传顺序编译。模型面对的是本次独立请求，不知道项目历史；提示词不得写“沿用前面”“参考上一个视频”这类未绑定指代。用户提供案例或示例时，另列“允许迁移的维度”；只说“参考结构”时，只迁移层级和信息粒度，禁止默认迁移故事、镜头、风格、人物或素材范围。

## 4. 证据等级

- **官方明示**：正文直接写出的能力、参数、公式和操作步骤。
- **官方案例展示**：页面提供提示词、素材与成片，可说明“曾在该案例中实现”，不能自动推广成稳定能力。
- **视觉审计观察**：逐秒抽帧看见的结果与偏差；属于观察，不冒充官方承诺。
- **导演推导**：本 Skill 为提高可执行性增加的因果、连续性、表演和防污染规则；必须与官方规则相容。

交付时若用户问“模型一定能做到吗”，必须按这四层回答，不把示例成功写成保证。
