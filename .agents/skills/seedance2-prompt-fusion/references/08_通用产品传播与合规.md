# 通用产品传播与合规

本附录只保留可迁移的方法，不包含品牌、产品配方、历史项目、受众名单、销量、素材或真实案例。

## 一、先把“卖点”改写成镜内证据

不要只说“更好、更舒适、更高端”。先写清观众在画面和声音里能看到或听到的事实：

1. 主体是什么，哪些可见结构或材质是身份锚点；
2. 使用前的具体情境或困难；
3. 人物如何操作、接触或比较；
4. 哪个可观察结果回应了前述困难；
5. 哪些内容只能作为主张，必须用审慎表述或由真人另行核验。

任何功能主张都不得被镜头、字幕或旁白夸大为医疗、绝对效果、保证结果或无法证明的比较结论。

## 二、提示词合同

每段产品镜头至少分开声明：

- `identity`：仅锁定本次已授权产品的可见结构、颜色、材质和不可变识别点；
- `interaction`：人物如何拿取、穿戴、调节、展示或比较；
- `evidence`：镜头要拍到的动作结果，不把推断写成事实；
- `claims`：可说、需弱化、禁止说的文案边界；
- `exclusions`：不迁移参考素材中的人物、商标、包装文字、背景、字幕、声音或受保护表达。

若没有已授权的产品参考媒体，不应编造精密结构、认证、价格、功效、品牌关系或用户评价。

## 三、发布前最小复核

- 产品结构是否与本次锁定参考一致；
- 人物动作是否真实可完成，接触点是否连续；
- 是否存在未经证实的效果、对比、认证、价格或适用人群宣称；
- 是否误带入参考素材的品牌、真人、台词、字幕、水印或原音；
- 是否把生成结果误称为已验证的商业事实。

发现任一项失败时，先删除或改为可见事实，再重新审查；不要只换同义词继续传播同一项无证据主张。
