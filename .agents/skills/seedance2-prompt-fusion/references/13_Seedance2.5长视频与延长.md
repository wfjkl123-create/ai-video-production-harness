# Seedance 2.5 长视频与延长

## 1. 原生 30 秒提示词

本 Skill 将官方 30 秒章节明确展示的总述、可选多模态参考、全局设定、时间戳剧本，与官方基础四部分中的“全局补充”组合为五部分生产结构：

```text
【总述名称】一句话写清全片基调与核心事件
【多模态参考层】素材职责与一致性锁定；无素材则省略
【全局设定】环境/物理质感 + 视觉风格 + 镜头语言 + 人物/主体造型 + 表演核心 + 禁止项
【时间戳剧本】连续覆盖 0–T 秒的阶段或镜头
【全局补充】跨镜连续性、声音范围、无字与关键禁项
```

### 时间戳规则

- **本 Skill 的生产纪律**：时间轴无缝覆盖，上一段结束时间 = 下一段开始时间，总和等于请求时长。官方个别案例的书面时码存在 1 秒标注空档，因此这条是为消除执行歧义而增加的导演约束，不冒充官方硬限制。
- 每段写：阶段名/镜头功能 + 可见动作与物理反馈 + 情绪/导演意图 + 结束状态。
- 允许一镜到底或切镜；若切镜，明确转场、前后景别和状态交接。
- 不把“潜台词”当模型能直接看见的指令。先说明因果，再把潜台词翻成眼神、呼吸、动作和空间距离。
- 原生 30 秒只是容量上限。简单单镜头可写短，复杂剧情应按可执行节拍分配时间。

## 2. 30–180 秒超长模式

官方页面把超长视频列为独立入口，一次生成 30–180 秒。提示词骨架仍是：

恰好 30 秒的新建视频默认使用普通生成；只有用户明确选择“超长视频”入口时，30 秒才按本节编译。31–180 秒必须走超长入口。

```text
全局参数 + 素材描述 + 一句话概述 + 具体故事线 + 全局补充
```

长时长不能靠把 30 秒模板机械拉长。先建立：

- **角色状态表**：身份、服装、道具持有、伤势/污渍、关系；
- **场景地图**：地点、出入口、方向、光线与时间变化；
- **故事阶段**：每段必须改变信息、关系、位置或风险；
- **连续性账本**：每阶段结束状态成为下一阶段开头；
- **重复控制**：避免同一动作、同一句台词或同一高潮被模型循环。

官方案例展示过约 60、64、90 秒等结果，不等于角色、物理和叙事在任意 180 秒任务中都稳定。高一致性、高风险任务仍可主动拆段，但那是制作决策，不是模型硬限制。

## 3. 视频延长

当前已验证的延长路由只允许**尾接**：新增片段接在已绑定原片的最后一帧之后，原片区间保持不变。`向前续写`、`前向续写`、`往前延长`、`向后续写`、`后向续写`都不能当作方向合同；改写为“接在原片末帧之后追加 N 秒”。若用户要在原片之前生成内容，先核验当前 UI 是否提供该入口；未核验前不得把它伪装成视频延长。

延长的提示词只对新增区间生效。写作顺序：

```text
新增 0–N 秒接在已绑定原片的末帧之后；原片保持不变。
原片末态：人物/位置/朝向/道具/光线/摄影机/声场分别为……
继承：人物身份/服装/位置/朝向/道具/光线/摄影机运动方向。
新增触发：……
新增动作链：起点 → 过程 → 结果。
摄影机如何延续或为什么切镜：……
新增区间结束状态：……
禁止：生硬切镜、凭空出现、动作复位、身份/场景漂移。
```

不要让“参考原视频”替代状态描述；把末帧可见状态写出来。延长后继续延长时，每次都重新以最新成片终态为起点，并记录污染风险。

## 4. 转场只在叙事需要时使用

官方列出的转场可按功能选择：

| 功能 | 适合 | 控制重点 |
|---|---|---|
| 自然切镜 | 常规叙事 | 给足镜头呼吸和前后动作完成时间 |
| 淡入淡出 | 开头/结尾、明显时间流逝 | 明确变暗/变白与下一画面浮现 |
| 叠化 | 回忆、梦境、柔和时间推移 | 两画面短暂重叠，避免主体重影失控 |
| 白闪/黑闪 | 重音、冲击、动作节点 | 闪光由事件触发，不当万能遮羞布 |
| 擦除 | 明确地点转移、复古语法 | 指明覆盖方向 |
| 遮挡 | 跨空间 | 指定遮挡物、全屏遮挡时点、揭开后的空间 |
| 相似物 | 蒙太奇 | 前后形状/颜色/构图对应 |
| 动作/动态接力 | 动作、换装、旅行 | 前后方向、速度、姿势连续 |
| 拉近/拉远 | 宏观与微观切换 | 前镜细节如何成为后镜全貌 |
| 水墨等风格化转场 | 古风、人文、回忆 | 转场材质必须符合全片风格 |

转场公式：`类型 + A 镜结束动作/构图 + 过渡载体与方向 + B 镜起始构图/动作 + 连续性约束`。只写“丝滑转场”无效。

## 5. 长视频验收

```text
□ 时间轴是否无缝覆盖并等于请求时长？
□ 每段是否改变故事状态，而非重复展示？
□ 人物、道具、方向、光线和摄影机状态是否逐段交接？
□ 延长提示词是否明确“新增段接在原片末帧之后”、只描述新增时长，且没有要求重做保留段？
□ 转场是否有叙事动机、载体、方向和前后构图？
□ 30–180 秒是否确认走超长入口，而不是误把普通生成参数拉长？
```
