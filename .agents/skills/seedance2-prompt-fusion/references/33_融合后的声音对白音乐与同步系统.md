# 融合后的声音对白音乐与同步系统

本文件融合原 ref 02/05/10/25 的发声、音色、画内音、对白时长和音乐卡点，与 v6.7 audio、audio guide、audio post delivery 和 sync-budget protocol。

## 1. 四个对象必须分离

人物图负责身份；音频参考负责获授权的音色、速度、情绪或节奏；文本负责具体台词；时间轴负责何时发生。不得暗示人物图自动锁声，也不得把参考音乐的完整旋律、声音身份或版权内容当作可复制资产。

## 2. 对白按表演事件编译

每句对白绑定唯一说话人、发声方式、台词、起止窗口与听者反应。自然对白链是：说话原因 → 说前准备 → 发声 → 台词 → 余波 → 对方晚半拍反应。多人时逐句显式归属，不用“他们说”。

先实际试读再分配时码。保留呼吸、动作、听者反应、转折后的停留；读不完先删重复信息、减少镜头或拆段，不用异常语速压缩。口型、多人动作、精确卡点共享同步预算，不能同时拉满。

当口型是当前镜的核心验收项，镜头必须让唯一说话人的嘴部保持可读：避免被手、头发、产品或前景人物持续遮住；切镜只落在一句话完成后的呼吸、停顿或下一句开始前，不切进词内。这里不要求逐音素机械描述，也不把口型要求扩散到没有说话的人或非说话镜。

## 3. 声音是空间与重量证据

- 画内音写声源、距离、材质和动作对应关系：脚步、布料、杯底、门轴、呼吸、风或空间混响。
- 音效必须由画面事件产生；大场面分前中后景声层，但只突出当前叙事声源。
- 音乐卡点把节拍映射成可见变化：脚步、切镜、灯光、撞击或摄影机重音；不承诺未经验证的逐采样精确。
- 沉默也是声音决定，用于让选择、反应或转折可读。

## 4. 生成与后期边界

提示词阶段只要求当前 surface/operation 已验证可生成的对白、环境声、SFX 或 BGM 关系。跨 clip 音乐连续、配音替换、降噪、响度、声道、字幕、M&E 和最终混音属于后期交付。要验证同步能力时固定其他变量，逐级增加台词、说话人或卡点密度，并记录实际 take，而非凭经验宣称上限。

每个生成单元在写正文前必须按 ref 44 五选一锁定声音策略：原音精确保留、原生生成、参考引导、外部无重编码回填或静默画面测试。提示词中的可听内容、音频素材职责、节点 `generateAudio/enableSound` 与后期方案必须同向；“声音一致”要拆成声纹、语速、停顿、波形、PTS 或最终听感分别验收。

## 5. 双方差异的统一裁决

- 原 Skill 允许英文音频锚点，v6.7 强调参考职责：标签逐字保留，但必须写“借什么、不借什么”。
- 原 30 秒对白密度采用试读与节拍账本；v6.7 sync budget 提供实验方法：前者用于编排，后者用于验证当前模型/入口，观察结果不升级成永久官方能力。
- “原生生成声音”不等于“可直接交付”；提示词通过与后期 QC 分层报告。

## 6. 声音验收

- 每句是谁说、怎么说、何时说、谁在听和如何反应？
- 口型重点镜中，唯一说话人的嘴部是否可读？切点是否避开词内而落在完成句、呼吸或停顿？
- 台词是否真实试读并留出不可压缩动作与停顿？
- 每个声音是否有画面来源、距离与材质？
- 参考音频的允许迁移和禁止迁移是否明确？
- 哪些在生成完成，哪些明确交给后期？
