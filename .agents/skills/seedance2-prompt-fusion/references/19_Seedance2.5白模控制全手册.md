# Seedance 2.5 白模控制全手册

> 白模不是一种“视觉风格词”，而是一条空间控制工作流。官方手册展示了 Maya/Blender 插件导出 camera 路线与白模视频，再上传即梦进行动作、运镜与美术渲染。本文件区分已由官方展示的能力与本 Skill 为提高可执行性增加的制作纪律。

## 产品入口与操作步骤

1. 在 Maya/Blender 中设置 camera 路线、白模人物/物体动作、接触和遮挡。
2. 通过官方说明的即梦插件或等价导出方式输出干净白模视频；保留工程和审查版作为证据。
3. 在即梦 Web 的 Seedance 2.5 多模态/白模工作流上传白模视频，并按需上传人物、场景、产品或道具图。
4. 在提示词中声明严格渲染或创意参考，逐项写输入职责和对象映射。
5. 选择当前入口支持的画幅、分辨率、时长并生成。
6. 用白模/成片逐时点对照；只在空间、动作、身份、材质和声音分别通过后交付。

插件名称、入口位置、素材上限和参数可能变化，执行时必须以当前官方界面复核；本节不把历史 UI 当永久合同。

## 1. 白模能控制什么、不能控制什么

白模/灰模 animatic 主要提供：

- 摄影机位置、朝向、焦距变化和运动路径；
- 人物/物体在空间中的站位、路线、速度和动作时序；
- 接触、遮挡、前后景、透视和相对尺度；
- 镜头切换骨架与动作衔接；
- 场景大型结构和地面高度关系。

白模通常不能单独稳定提供：

- 真人脸、发型、服装和精细体型身份；
- 产品材质、logo、文字和微小结构；
- 最终场景材质、天气、光影和色彩；
- 声音、对白、情绪微表演；
- 低模中没有建出的手指、衣褶、软体、流体等精细物理。

因此“上传白模 + 写严格还原”不是完整任务。必须有映射表、外观锚、材质/光线说明和逐时点验收。

## 2. 两种控制模式

### 2.1 严格渲染 / 强控制

适用：1:1 站位、动作、接触、构图和运镜复现；产品与人物关系敏感；复杂多人调度。

合同：白模视频是空间、动作时序与摄影机的权威。下游只替换外观、材质、光线和声音，不主动改编动作。

若用户要求真正的逐时点 1:1，必须保留 `.blend`/Maya 工程、camera、animatic 与关键帧作为可验证证据。只有几张白模截图属于 keyframes-only，只能约束离散时点，不能宣称锁定连续运动。

### 2.2 创意参考 / 动作迁移

适用：只借动作机制、调度思路或运镜节奏，允许成片自然调整。

合同：明确列出哪些可变，例如速度可微调、手势可自然化、路径可为场景避障；同时列出不可变的事件顺序与镜头功能。成片不能再标注“1:1”。

## 3. 上游白模准备

### 3.1 工程准备清单

```text
□ 画幅、帧率、总时长与目标生成单元一致。
□ 唯一激活 camera；焦距、传感器/视场角和裁切安全区已确认。
□ 人物/道具使用稳定 ID，不靠颜色记忆身份。
□ 地面、墙体、台阶、门窗和关键遮挡体已建出。
□ 手持物、座椅、桌面、产品等接触对象有真实父子/约束关系。
□ 动作没有脚滑、穿地、穿墙、手穿物、道具跳变。
□ camera 没有穿过几何体，切镜点有明确原因。
□ 导出视频不含多余 UI；若带轨迹/ID，仅供审查版，生成版应尽量干净。
```

### 3.2 粗颗粒与细颗粒

- 粗颗粒：只有方块人、路线和 camera。文本必须补全人物映射、动作含义、场景结构、接触点、材质、光线和声音。
- 细颗粒：人物骨架、物体、场景和时序清晰。文本重点做外观替换、材质渲染、光影、声音与排除调试标记。

不要把粗颗粒缺失的信息留给模型猜；也不要用长提示词覆盖细颗粒白模已经明确的空间事实。

## 4. 输入职责与映射表

严格模式在写提示词前建立：

| 白模 ID | 最终对象 | 外观素材 | 必须继承 | 允许调整 | 禁止 |
|---|---|---|---|---|---|
| ACTOR_A | 女主 | 图1 | 路线、动作、朝向、接触、时序 | 微表情、衣料次级运动 | 串脸、换位、改动作 |
| ACTOR_B | 男主 | 图2 | 同上 | 同上 | 与A互换身份 |
| PROP_01 | 手提包 | 图3 | 尺度、手部接触、运动 | 材质细节 | 漂浮、穿手、变形 |
| SET | 饭店 | 图4 | 墙/桌/门透视和遮挡 | 材质、陈设、光线 | 改 camera、改空间 |

素材职责头：

```text
视频1是白模 animatic，只负责 camera、空间、站位、动作时序、接触和遮挡，是这些项目的唯一权威。
图1只负责 ACTOR_A 的脸、发型、服装、体型与材质；禁止迁移图1的姿势、背景和构图。
图2只负责 ACTOR_B 身份……
图4只负责场景的材质、配色和光向；不得覆盖视频1的透视、布局和 camera。
```

## 5. 四类白模任务

### 5.1 白模直接输出

目的：保留无材质白模/灰模外观，生成干净的预演视频。

```text
严格按视频1的 camera 与动作输出纯白哑光白模预演；背景为中性灰，保留接触阴影和空间遮挡。人物与道具不加真实材质、纹理或身份特征；无坐标轴、骨骼、轨迹线、文字和 UI。
```

### 5.2 白模人物/动物替换

目的：将低模主体替换为人物/动物/角色，同时继承动作。

控制重点：骨架比例差异、手脚接触、衣物/毛发次级运动、身份不串、动作不被“自然化”到偏离白模。

### 5.3 白模场景美术化

目的：保留结构、透视、camera 和物体路线，替换材质、天气、光线和环境。

控制重点：新场景不能覆盖空间；地面/墙/门与白模对应；光向在 camera 运动中连续；反射和阴影遵守接触。

### 5.4 标注增物/增角色

目的：在白模指定位置增加人物、动物、道具或特效。

必须写：目标帧与位置、相对尺度、朝向、进入方式、接触对象、遮挡层级、持续时段、结束状态。只写“这里加一只狗”会导致漂浮和尺度错误。

## 6. 提示词完整合同

```text
【任务】把视频1的白模 animatic 渲染为 [类型/时长/画幅] 最终视频。

【控制模式】严格渲染。视频1是 camera、空间、站位、动作时序、接触和遮挡的唯一权威，不改动作节奏、不改镜头路径。

【输入职责】
视频1：……
图1：……；禁止……
图2：……；禁止……

【对象映射】
白模 ACTOR_A → 图1人物……
白模 PROP_01 → ……
白模 SET → ……

【全局渲染】
场景结构与白模一致；材质……；主光从……；人物皮肤/头发/服装……；声音……。

【时间轴】
[00.0–04.0s] camera 与白模一致；ACTOR_A……；接触……；结束状态……
[04.0–08.0s] ……

【严格保留】camera、焦距变化、构图、站位、动作节奏、接触、遮挡、道具尺度。
【排除】白模颜色、坐标轴、骨骼、轨迹线、控制器、camera cone、网格线、调试文字、穿模、脚滑、道具漂移、身份互换。
```

短原创例子：

```text
视频1是两人在饭店入座的白模 animatic，严格负责两人的路线、椅子接触、坐下时序和 camera 横移。图1只负责女主外观，图2只负责男主外观，图3只负责暖色饭店材质。把白模 A/B 分别替换为女主/男主；椅子、桌面和门的位置严格沿用视频1。坐下时臀部与椅面真实接触，双脚不滑地，手不穿过桌面；排除白模灰色、关节球、轨迹线和坐标轴。
```

## 7. 时间轴与多镜头

- 时间轴分段应与白模动作/切镜节点一致，不要为了文字整齐改分段。
- 每段只补充白模看不见的身份、表情、材质、光线、声音和物理细节。
- 切镜后重述当前 camera、人物左右位、道具和动作状态，防止身份/空间复位。
- 一镜到底时写“camera 全程严格跟随视频1”，不要叠加另一个主运镜。
- 多角色对白需单独绑定说话人和听者反应；白模只给口部/身体时序，不自动提供声线。

## 8. 常见失败和修复

| 失败 | 判断 | 修复 |
|---|---|---|
| 动作/运镜偏差大 | 白模被当普通风格参考，或提示词给了冲突动作 | 明确严格模式和唯一权威；删掉冲突镜头/动作词 |
| 人物替换成功但串脸 | 身份素材职责不清或多主体过载 | 一人一锚、一 ID 一映射；逐镜重申 A/B，不让场景图带人 |
| 脚滑、接触穿模 | 白模自身接触不成立，或缺少接触验收 | 先修 `.blend`；写接触面、受力、遮挡；逐帧验收 |
| 场景美术覆盖布局 | 场景图被误当构图权威 | 明确只迁移材质/配色/光向，不迁移构图；白模空间优先 |
| 道具尺寸/位置漂移 | 没有 ID、尺度和父子关系 | 建模时约束；映射表写相对尺度和接触对象 |
| 保留白模线框/UI | 未写排除项或上传的是审查版 | 使用干净生成版；排除坐标、骨骼、轨迹、camera cone、文字 |
| 衣物/毛发僵硬 | 只要求严格动作，未给次级运动 | 允许衣料、头发按惯性自然响应，但不得改变主体动作 |
| 口型/声音错 | 白模没有声音职责 | 独立绑定音频/台词、说话人和时点 |
| 原视频偏差大但仍称 1:1 | 只看首尾帧或主观“差不多” | 使用逐时点叠加/抽帧检查；失败则降级为创意参考，不虚报 |

## 9. 逐时点验收

严格模式至少在动作起点、接触前、接触瞬间、动作峰值、离开接触、转向、切镜前后和结尾抽帧。每个时点检查：

1. camera 位置/朝向/构图/焦距是否对应；
2. 每个主体的屏幕位置、朝向、姿态和尺度；
3. 手脚/臀部/道具的接触点与遮挡；
4. 物体相对位置、地面高度与场景透视；
5. 人物身份、服装和道具是否稳定；
6. 材质、光线、阴影和次级运动是否连续；
7. 调试元素是否完全排除；
8. 声音、对白和口型是否在正确时点。

验收结论分开写：

- `空间/动作控制 PASS|FAIL`
- `身份/材质渲染 PASS|FAIL`
- `声音/对白 PASS|FAIL`
- `可宣称严格复现 YES|NO`

任何一项失败都不能用“视频生成成功”替代。
