# 空间连续性 · Frame Map · 多段

> 人物位置、运动轨迹、构图、运镜的前后冲突，根因是用了好几套不一致的空间说法。**本文件是全 Skill 唯一的空间语言**——讲站位、方向、构图、连续性，只用这一套词，别再另起"站位图/俯视图/CAM 地图"等叫法。
> 核心不是"动作写得更多"，而是每镜先建立一个可拍摄的空间坐标系，再让动作在坐标里发生。

---

## 0. 统一空间语言（全程只用这套词）

```text
左右：画面左侧 / 画面中央 / 画面右侧（写全，不缩成"画左/画右"）
纵深：前景 / 中景 / 背景
占比：主体占画面几分之一；背景锚点占哪里
朝向：身体朝向__、脸部朝向__、视线落点__（三者分开写，背身/转身尤其要分）
机位：贴地 / 低角度仰拍 / 平视 / 俯拍 / 越肩 / 正反打 / 远景长焦
运动方向：向画面左 / 向画面右 / 朝镜头 / 背向镜头 / 贴地推进（一律锚到镜头或画面，禁裸写"向前/向后/朝后面"）；速度：慢/匀/快
透视锚：地面线条 / 墙面 / 门框 / 沙丘 / 远处人群 / 巨物腿部如何形成纵深
轴线：摄影机始终位于__一侧，不跨越__
```

**为什么一切都要锚点：AI 不理解物理空间。** 它没有物理世界模型——你写"向后走"它不知道是相对哪里的后，写"两米高"它只能瞎猜，于是同一条提示词时而向前时而向后、忽大忽小，全靠抽卡。把每个方位/尺度/位置/构图都钉到画面或镜头里的一个锚点上，"猜"就变成"可执行的相对关系"：

- **方向锚到镜头/画面**：不写"向前/向后/朝后面走"。写"朝镜头慢慢退后 / 背朝镜头退后 / 向画面左侧走"——有锚点、有方向、有依据。
- **尺度锚到参照物**：不写"两米高/多少米宽"。写"相对旁边的消防栓有两倍高 / 手里的尺子有一臂之长"。
- **位置/占比锚到占位物**：用一个锚点把人物钉住，让人物在锚点左/右或替换它；必要时指示最终不渲染占位物。例"小红坐在沙发左侧的红球上（画面最终不出现红球）"。
- **构图逐主体写死**：每个主体 = 画面方位+高低 + 侧身角度 + 外观 + 状态，再交代前景/远景虚化层（范例见 §2）。

## 1. 镜头包裹动作：先写镜头运动，再写其他

**这是所有分镜的铁律，不分简单复杂。** AI 视频模型最容易漂移的不是动作细节，而是"动作发生在哪个可见空间里"。先写动作，模型会先想象角色再临时找角度拍，前后镜头就跳轴、换位、变比例。**先写机位、构图、景别、画面占比、前中后景 = 先给模型摆好摄影机和地面坐标，再让动作发生。** 复杂连续性项目把 Shot 从 `人物做什么+场景+镜头` 改成 `摄影机先在哪看 + 谁在画面哪 + 运动方向如何持续 + 人物才开始做什么`。

**复杂场景五步结构法**（严格按此序，契合模型顺序执行，把动作"包裹"进已建立的空间场）：
```text
1 光学/摄影机参数（焦段、景深、机身/胶片美学——唤醒高质量训练数据）
2 摄影机空间位置与运镜轨迹（机位高度 + 一个主运镜方向）
3 环境光影与物理氛围（动作发生的舞台）
4 主体相对镜头的精确空间动向（不是绝对方向，是相对镜头）
5 关键局部交互与细节（微观真实感）
```

**绝对摄影机坐标系（根治方向失控）**：AI 隐空间里没有以"人物面部朝向"为基准的绝对方向感；中近景缺地平线/建筑参照时，"向前走"只能随机概率推算 → 倒退滑步。**把摄影机当不可移动的坐标原点 (0,0,0)，一切运动都描述成相对镜头的位置变化**：
```text
向前冲刺 → 快速逼近镜头，身形在画面中迅速放大（Z 轴向镜头）
转身越走越远 → 背对镜头，向画面深处缓慢走去，背影逐渐缩小（Z 轴远离）
从右边开出来 → 从画面右侧画框边缘切入，横穿镜头前方，驶向左侧画框外（X 轴入画→出画）
老鹰飞下来 → 极低角度仰拍，从高空向镜头俯冲，利爪在镜头前急速放大（垂直落差转 Z 轴冲击）
```

**每镜都重复左右/前后/占比，不是啰嗦，是连续性"重锚定"**：HARD CUT 后模型不会可靠继承上一镜的空间记忆，每镜都要像独立镜头一样重新声明谁在左/右/中、谁在前/中/背景、谁朝向谁、主体占画面多少、运动方向。多人、巨物、追逐、战斗、贴地低角度尤其必须重锚。

## 2. 文本 Frame Map（没有俯视图/首尾帧时怎么写）

每个镜头开头先写 4 个锚点，再写动作：

```text
镜头功能：建立空间 / 追逐 / 冲击 / 情绪 / 巨物比例 / 转场。
机位与构图：__景别 + __机位 + __焦段；画面左侧是__，右侧是__，前景是__，中景是__，背景是__。
空间与透视：__形成从前景到远景的纵深；__占画面__，__只露出__，防止主体比例漂移。
主运镜：只保留__，运动方向__，速度__；副质感仅为__。
```

也可用 bullet 把每个出场主体/关键物件/特效逐一铺开（方位写全、只写镜头拍得到的）：

```text
【画面坐标】
- 画面左侧·前景：谁 + 一句状态/朝向
- 画面右侧·中景：谁 + 一句状态/朝向
- 画面中央·背景：透视锚是什么
```

> 只写"拍得出来的"：方位、远近、占画面大小、谁挡谁、谁被光照。不写"谁占主动/谁有退路"这类拍不出的判断——那属于导演脑内预演（references/01），不进成稿。

**多主体构图范例（每主体钉死 方位+高低 + 侧身角度 + 外观 + 状态 + 虚化层）：**

```text
江流在画面左侧偏高、四分之三侧身、黑色光面屏脸亮着两个青色小眼点、暗红破布衣湿透贴身、发梢滴着水珠，头顶趴着那只青铜螃蟹；
丹眉在画面右侧偏低、黑色短发红色发饰、米白立领湿衣贴身、湿发滴水、神情冷淡正对镜头；
画面底部一道斜向的甲壳兽尾部背甲虚化作前景遮挡，远景是虚化的崖壁与尘霾。
```

每个主体都有画面方位、高低、朝向角度、可锁外观、当前状态，前景用虚化遮挡、远景用虚化拉开纵深——模型不必猜谁在哪、谁多大。

**用大透视 + 前景遮挡建 Z 轴纵深（破 AI 平面化）**：AI 默认平视+正中心构图、缺 Z 轴参照，画面发平。压低机位（`extreme low angle / ground level`）+ 广角（`Big Perspective, wide-angle lens`）强制改变消失点、拉出向上透视；再放一个**重度模糊的前景遮挡物**（`heavily blurred foreground`，如桌腿/玻璃/人群/蒸汽，配 `shallow depth of field`），在二维画面里划出前/中/后三层，观众大脑自动算出空间距离、Z 轴坐标系成立。前景极度模糊 vs 中景主体绝对清晰，还顺手破了 AI"全局焦点都清晰"的塑料感。

## 3. @参考源分工（先隔离，后调度）

多图不是"都当参考"，必须逐图写明只负责什么，避免人物/产品/场景/色卡互相污染。文本本身承担 Frame Map——不要写"参考图控制站位"，直接写"谁在画面哪里、摄影机从哪看"。

```text
@图1 只负责人物 A 的身份/脸/发型/服装/身形比例，只提供样貌不提供姿势与构图。
@图2 只负责人物 B 的身份……   @图3 只负责场景空间结构/地面材质/光源方向/远景氛围。
@图4 只负责巨物/道具的形体/材质/体量比例。   @图5 只负责色卡，所有颜色严格按色卡，不偏离。
@参考视频 只负责动作节奏/机位/运镜/剪辑点，不参考原人物、原产品、原品牌、字幕。
文本 负责镜头顺序、空间关系、动作因果、运动方向、失败线。
```

**体量用参照物锚定（即梦工程细节）**：@图 分工时把体型直接绑到参照物——「龙虱仅成年人腰部高度、半人高」「兽王庞大到镜头无法摄全身、只能拍到身体一截」。比"巨大/很大"稳得多，参照物把"多大"从形容词降成画面可对照量（同 references/06 §6 巨物超框）。

**Seedance/即梦 的 @tag 平台规则（封 tag 失效与切镜复位）：**

```text
· 每个镜头是独立 generation，模型无跨镜记忆 —— 每镜都从头重新引入它的 @tag，别写"接上一镜"。
· tag 两侧留空格、不碰标点：正确 `…潜入院中 @图3 ，她…`；错误 `@图1.` `@图1,` `(@图1)`。
· 首次提及用身份名词 + tag，之后用代词：写"原始女人 @图1 …她…"，别写裸代词"她 @图1"——名词才给冷启动一个锚。
· 一个镜头内同一 tag 只在首次出现时标一次，之后用代词；下个镜头再标。
· 不要把 tag 已经携带的外观再用文字重描（@图2 带了发型服装就别再写），但 tag 本身每镜都要重标。
```

**角色多图按景别分工（封参考图污染）：**

```text
脸部 ref（正面特写）= 主身份锚，每镜每次该角色出现都带，不论景别。
身形 ref（全身/多视图 sheet）= 只在 远景/全身/中景 带（看衣着、剪影、体型时）。
细节 ref（皮肤/眼/发/手微距）= 只在 特写/极特写/能看清质感的中景 带。
铁律：特写/极特写丢掉身形 sheet —— 脸在 sheet 上又小又是怪角度，带上反而污染。
```

**供体视频怎么挑（动作/运镜迁移的成败在输入端）**：
```text
选：单一清晰动作、干净剪影、稳定机位的片段——多人杂乱素材迁移过来的是噪声，不是动作。
静音上传：除非要它管时序，否则供体视频先静音（或明确写"@视频1 只负责运镜，声音以 @音频1 为准"）。
迁移得好：编排动作 / 手势时机 / 运镜节奏 / 调度走位。   迁移不好：手部细节 / 多人同步 / 面部表演——别指望。
```

> 参考图风格冲突会整批塌方：同一职责喂进互斥风格（写实真人 vs 卡通）会连续系统性崩，根因在输入端，删词治不了——回去换一套自洽参考图重建（详见 references/05）。

## 4. HARD CUT 多镜：切镜后必须重锚定

HARD CUT 不是简单换行，是告诉模型"前一镜结束，下一镜重新摆摄影机"。每个 CUT 后第一句不写动作，先重锚：

```text
镜头硬切至 __ 景别，摄影机位于 __，A 仍在画面 __，B 仍在画面 __，背景锚点 __ 仍在 __，不换位、不越轴。
```

避免：
- "接上一镜""继续刚才"但不写具体位置。
- 切镜后只写脸部特写，忘了说明脸朝向、视线目标、背景锚点。
- 同一景别相似角度硬切，模型会误以为是漂移而不是剪辑——每次切镜尽量同时改变景别和镜头性格。

## 4.5 对话戏正反打（环绕弧线 + 镜像构图 + 不越轴）

两人对话戏最稳的拍法：用一条贯穿全程的环绕弧线把正反打串起来，每个反打都是同一弧线上的对位机位。

```text
全程同一条想象中的环绕弧线，机位始终沿同一方向（如顺时针）极缓慢微微环绕——每个镜头都带这一点点弧形移动，画面不至呆板。
正反打切换：机位跳到弧线的对面，但环绕的旋转方向始终不变，且不越过两人之间的轴线。
镜像构图：A 不居中、偏画面左侧、脸朝右望向 B；反打 B 不居中、偏画面右侧、脸朝左望向 A（一左一右、脸朝向相对、视线落点写死）。
给对话一个物理分隔/前景遮挡：用两人之间的一件实物（桌沿、巨物尾巴、屏风边缘）虚焦横切画面下缘作前景，人物上半身露在它之上——既建 Z 轴纵深，又把"谁对谁说"锁死。
每个反打：先重锚（机位/景别/谁在画面左右/脸朝向）→ 再台词（绑音色）→ 画内音。
```

> 治"对话戏越轴/换位/呆板平切"。例：母女隔着餐桌吵架，正反打沿同一环绕弧线、桌沿虚焦作前景分隔、母偏左脸朝右、女偏右脸朝左，不越轴。

## 5. 一镜到底跟拍

最怕模型中途换机位。开头声明"一镜到底 + 摄影机始终如何运动 + 主体始终如何相对镜头"：

```text
整段一镜到底 continuous one-shot，不 HARD CUT。摄影机贴近地面/肩后/侧后方，以 __ 景别跟随主体，全程保持 __ 距离。
主运镜只保留 tracking / lateral truck / dolly back，运动方向始终向 __。主体始终位于画面 __，
背景从 __ 逐渐过渡到 __；地面线条/墙面作为透视锚持续滑动。动作从 __ 经 __ 停在 __，不切新机位、不突然变正脸摆拍。
画内音仅脚步/衣料/呼吸/碰撞/环境底噪，不配背景音乐。
```

贴地低角度追逐补：摄影机在脚踝高度或更低，画面下方始终可见地面纹理与脚步落点；腿/脚在前景快速穿过，上半身只部分露出；背景锚点横向滑动，证明是摄影机跟拍而非角色原地跑。

**两种时间契约别混用**：一镜到底用阶段语言（起初 / 接着 / 最后），全程不出现镜头标签；多镜分切用"镜头一/镜头二"标签，每镜一动作一端点。同一条提示词里"一镜到底"+ 镜头标签并存，模型会自作主张切碎长动作。

**9:16 竖屏构图安全区（千川默认画幅）**：主体和关键动作居中偏内，别贴画框边缘；简化运镜，避免快速横向动作出画；上方留字幕安全头部空间、下三分之一留后期字幕位；需要同素材裁 1:1/4:5 版本时，脸、产品、logo 一律远离四边（构图时就为裁切留位，如"产品定格在画面中央偏左"）。

## 6. 多段 Generation：拆分 + 段尾状态卡 + 续接三件套

>15s 必拆 Generation。切分参考：`20s=15+5 · 30s=15+15 · 45s=15×3 · 60s=15×4`。

每段独立完整（不写"接上一段"），靠**段尾状态卡**显式承接（直接写进下一段开头）：

```text
【段尾状态】人物位置__、朝向__、视线__、手中道具__、身体惯性方向__、情绪__、产品状态__、环境余波__。
【下一段开头】同一 [人物/产品/场景] 从上段尾状态继续：__。保持同一光影、服装、产品、场景与镜头风格。
```

**无首尾帧续接三件套**（没首尾帧图时用文本补）：

```text
1. 每镜独立复述空间：重新写机位、景别、左右、前中后景、主体占比、透视锚。
2. HARD CUT 后重锚定（见第 4 节）。
3. 运动惯性接续：身体重心仍向__，脚步/手臂/衣摆延续上一秒方向；摄影机仍以__速度向__移动；尘土/衣料/人群反应沿同一方向滞后半拍。
```

**状态连续性证据（切镜不能自动复位）**：上一场留下的物理状态——湿头发、顺发丝滴落的水滴、汗与尘混在脸侧的发丝——是"刚发生过什么"的连续性证据。HARD CUT / 换景别后必须逐镜重写，否则模型会让头发自动变干、伤口自动消失。

**观察态优先于计划态（续接最大坑）**：下一段开头必须基于**上一段实际生成出来的末状态**（回看成片或截末帧读取：姿势、画面位置、道具、光影、开放中的运动方向），不是脚本里计划的末状态——生成常有偏差，按计划态续写 = 从没发生过的画面接戏。配套两条节拍纪律：①已完成的节拍明确标记"已发生"，下一段绝不重演（否则动作重播、台词复读）；②留给后面段落的节拍绝不写进本段（否则未来事件提前泄漏）。故事背景可以喂动机、氛围、节奏，但不能让本段提前演掉后面的戏。

续接可直接贴的中文短语：`从上一段真实结尾继续` / `不要重演上一段动作` / `本段只拍当前任务` / `后续剧情暂不出现` / `保持上一段开放动作方向` / `本段止于__，__暂不出现` / `只修复尾部漂移，不改前半段`。

## 7. 输出前空间质检

```text
□ 摄影机在哪、看向哪、什么景别构图？谁在画面左/右/中？前/中/背景分别是什么？
□ 透视锚能否证明空间和比例？主体占画面多少、巨物/产品占多少？
□ 主运镜只有一个吗？运动方向写清了吗？
```
