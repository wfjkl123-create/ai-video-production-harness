# 融合后的多段连续性延长与分镜系统

本文件融合原 ref 03/10/13/17/20/25 的 Frame Map、段尾状态卡、延长、转场和多宫格，与 v6.7 sequence、continuation、project state、handoff、dense storyboard、multishot、2D anime 和 continuity QC。

## 1. 三层状态模型

- project：canonical 人物、产品、世界、导演声音、最终故事结果和不可变锁。
- scene：场景目标、空间轴线、进入/退出条件、光与声音阶段。
- clip：`this_clip_only` 的任务、来源、开镜状态、唯一变化、结束状态和验收。

未来 clip 只保存 provisional intent，不提前写成已发生事实。每次仅编译当前 clip；完整故事规划不能绕过真实素材来源门。

## 2. 真实观察与计划状态的优先级

继续或延长前必须取得被接受的前片或真实尾帧，观察位置、朝向、视线、道具、动作阶段、镜头阶段、光与声音。观察状态覆盖原计划的瞬时态；canonical 身份锁仍覆盖漂移。没有接受源时，只能规划下一段，不能宣称无缝续接。

交给下一段前必须完成三方对账：上一段计划末态、接受成片观察末态、下一段计划开态。逐项记录一致、可在下一段吸收的偏差、必须回到 canonical 重锚或返工的冲突。尾帧若进入生成输入，只能控制位置、姿态、视线和运动阶段，并同时绑定 canonical 人物/产品/场景权威；不得把漂移像素升级为新身份。

## 3. 空间与剪辑连续性

统一使用画面左/右、朝向镜头/背向镜头、前中后景和真实比例锚。HARD CUT 后按风险重锚主体身份、位置、方向、动作阶段、镜头尺度和声桥；连续动作镜头保留屏幕方向、接触关系与惯性。故意跳切、越轴或图形匹配必须明确为叙事选择，并在切后重新建立空间。

## 4. 分段、延长和重锚定

按事件密度、身份脆弱度、场景边界、声音同步和 operation 限制拆 clip，不按固定秒数机械切。延长优先继承真实末态；连续多次延长累积构图、脸、服装和背景漂移时，从 canonical 资产与已接受状态重新建立干净起点。

多宫格/分镜板是镜头规划与补间来源：每格必须有独立镜头身份、顺序、角色和状态，不能让模型把格线、相邻姿态或多个角色混成同一时刻。2D/anime 连续性还要锁线条、色板、变形规则和运动节拍。

## 5. 双方差异的统一裁决

- 原段尾状态卡升级为 project/scene/clip lineage，但仍保留其具体位置、朝向、道具、惯性与末态字段。
- 原文本 Frame Map 解决单镜空间，v6.7 project state 解决跨镜谱系：两者同时需要，状态文件不能替代可拍空间语言。
- 接受成片是下一段瞬时态的证据，不是对原计划或身份漂移的自动批准。
- 无缝不是“没有剪辑痕迹”；更重要的是动作、空间、因果、身份和声音能被观众连续理解。

## 6. 连续性验收

- 当前 clip 的唯一职责与 `this_clip_only` 是否明确？
- 开镜状态是否来自真实接受源，还是仍是待验证计划？
- 身份事实与瞬时观察是否分层，切镜后是否按风险重锚？
- 末态是否完整记录位置、朝向、动作、道具、摄影、光和声？
- 延长次数或漂移风险是否已经需要 canonical 重锚定？
