# Seedance 2.5 逐功能十四字段合同

> 本文件是机器可验收的逐功能合同层。每个 `[CONTRACT:*]` 区块都独立包含十四个字段；不得借用同文件其他章节。详细原理、技巧和案例仍读 refs 12–21。

## 目录

参数、基础提示词、真人、普通30秒、超长、延长、智能编辑、标注编辑、白模、时间戳、多语言、无字/无BGM、基础优化、BGM分离、创意迁移、局部编辑、视角、音色、多人、绿幕、两段转场、多宫格。

## [CONTRACT:PARAMETERS] 参数与基础功能交互

- 定义：为当前 operation 选择素材、画幅、分辨率、输出时长与入口。
- 适用：任何 Seedance 2.5 执行前。
- 不适用：不能把历史参数快照当永久 API 合同。
- 产品入口：视频生成 → Seedance 2.5 → 对应模式。
- 输入限制：页面快照为图最多30、视频最多10且总约30秒、音频最多10且总约30秒；提交前实时复核。
- UI步骤：选模式、上传素材、选画幅/分辨率/时长、填提示词、核对后生成。
- 提示词公式：素材职责 + 事件主线 + 时间轴/差异合同 + 全局约束。
- 字段解释：模式决定 operation；素材职责决定可迁移信息；时长决定时间轴上限。
- 参数：普通4–30秒、超长30–180秒、延长新增4–30秒均为页面快照。
- 改变与保留：只改变所选 operation 允许的部分，其他输入职责保持。
- 短原创例子：30秒新短剧选普通生成，不把 duration 写成60秒。
- 官方追溯：outline `W60ldY3EqoCOsMxMzKycuMoLnfd`、`KVjedtiu7oRzmqxbWN3c95ginhd`，sourceOrder 56–189。
- 失败模式：选错模式、素材超限、把建议范围误当硬上限、用旧UI提交。
- 验收：当前界面参数、素材总数/总时长、输出时长和 operation 全部一致。

## [CONTRACT:BASE_PROMPT] 基础提示词

- 定义：官方四部分骨架：素材描述、一句话概述、具体情节、全局补充。
- 适用：所有新生成任务的基础编译。
- 不适用：延长和编辑不能只套新生成骨架。
- 产品入口：视频生成 → Seedance 2.5 → 普通/超长入口。
- 输入限制：无素材则省略素材层；有素材逐项绑定职责。
- UI步骤：上传素材、确认编号、写四部分、设置参数、生成。
- 提示词公式：素材职责 + 主体/地点/事件 + 可见动作因果 + 跨镜铁律。
- 字段解释：概述立故事脊柱；情节负责执行；补充只锁跨镜变量。
- 参数：时长与画幅由当前入口决定，公式本身不替代参数设置。
- 改变与保留：素材只迁移声明的身份/动作/场景/声音，禁止其余污染。
- 短原创例子：图1只负责女主身份；她在雨夜误上陌生人的车，发现误会后忍笑下车。
- 官方追溯：outline `CVRHdYwawooBvIxWKMUcg86lncf`，sourceOrder 192–217。
- 失败模式：概述只有风格、情节无触发、全局补充重复动作、参考污染。
- 验收：四部分各司其职，故事因果、素材职责和结束状态可逐项核对。

## [CONTRACT:HUMAN] 真人人物

- 定义：用八维稳定身份加可见表演因果生成真人角色。
- 适用：纯文生真人、多人对白、身份一致性任务。
- 不适用：已有 canonical 人物图时不能用文字另造冲突身份。
- 产品入口：视频生成 → Seedance 2.5；有身份图则走首帧/多模态。
- 输入限制：多人一人一锚；主体过多时稳定性下降。
- UI步骤：绑定人物图、逐人写身份/声线、写对白时间轴、生成。
- 提示词公式：年龄/族裔 + 皮肤 + 面部 + 眼神 + 头发 + 服装 + 体型/气质 + 必要要求。
- 字段解释：身份回答“是谁”；触发—反应—动作—新状态回答“为何这样表演”。
- 参数：保留3–4个稳定面部点；台词秒数按正常语速分配。
- 改变与保留：表情和姿态可随剧情变，脸、发型、服装、体型和声线保持。
- 短原创例子：32岁东亚女性，短卷发、圆下颌、旧灰外套；紧张时先捏杯沿再避开视线。
- 官方追溯：outline `Aosyd5Ih5oVwkTx0s7ycyMRcnSe`，sourceOrder 218–259。
- 失败模式：形容词堆砌、双胞胎脸、串声、情绪无可见载体。
- 验收：逐人检查身份、声线、视线、台词归属和听者反应。

## [CONTRACT:STANDARD30] 原生30秒

- 定义：普通模式一次生成4–30秒；恰好30秒默认走这里。
- 适用：单次完整短剧、TVC、MV或一镜到底，目标不超过30秒。
- 不适用：31–180秒走超长；修改底片走编辑；续尾走延长。
- 产品入口：视频生成 → Seedance 2.5 普通生成。
- 输入限制：多模态输入按当前参数复核；纯文生不写参考素材。
- UI步骤：选普通模式、画幅/分辨率/30秒、绑定素材、生成。
- 提示词公式：总述 + 可选素材层 + 全局设定 + 与风险匹配的连续故事/CUT/时间戳 + 全局补充。
- 字段解释：这是本Skill把官方30秒章节与基础“全局补充”组合的生产结构。
- 参数：4–30秒；多场景、对白、卡点或反转任务要求时码从0连续覆盖到30；简单单镜头选择最低充分控制，不为套格式强加时间轴。
- 改变与保留：每段推动关系/信息/位置/风险，身份、道具、轴线和声音跨段保留。
- 短原创例子：0–7秒街边电话，7–12秒入座，12–25秒虚报条件，25–30秒反转。
- 官方追溯：outline `Y2q4dEGEhoxbf5xXmnGc1CS4n0d`，sourceOrder 260–305。
- 失败模式：控制强度过高或不足、镜头过载、台词说不完、听者无反应、切场后换位、结尾无状态。
- 验收：复杂任务时间轴=30秒；台词按目标语速试读；故事完整，多人/道具/声音连续，反转后有可见停留，真实末帧正确。

## [CONTRACT:ULTRA] 超长视频

- 定义：独立入口一次生成30–180秒长视频。
- 适用：连续长故事、MV、氛围片、长情绪或空间探索。
- 不适用：恰好30秒且未明确选超长时仍走普通；身份刚性任务可主动拆段。
- 产品入口：模式下拉 → 超长视频 → 时钟设置时长。
- 输入限制：素材限制按当前入口；长时不等于可无限增加主体/场景。
- UI步骤：选超长、绑定素材、选30–180秒、核对画幅/分辨率、生成。
- 提示词公式：全局参数 + 素材职责 + 故事主线 + 分阶段时间轴 + 全局补充。
- 字段解释：角色表锁身份；场景地图锁空间；阶段表推动故事；账本交接状态。
- 参数：30–180秒页面快照；建议每10–15秒设可验收阶段。
- 改变与保留：信息/关系/时间可阶段变化；身份、道具持有、因果和方向连续。
- 短原创例子：60秒摄影师抵达、寻位、架机、拍下极光并拉远收尾。
- 官方追溯：outline `UrjUd4f5DoA2IYxf6kec16y6nCD`、`RS5wdJrtDoZsJYx6wSSc5xCbn9b`，sourceOrder 306–336、695–721。
- 失败模式：动作/高潮循环、末尾白闪、人物或空间持续变形、静态拖时长。
- 验收：逐阶段和真实末帧检查故事、身份、空间、道具与音频连续性。

## [CONTRACT:EXTEND] 视频延长

- 定义：保留底片，向尾部新增4–30秒；新增段只能接在原片末帧之后，提示词只作用新增区间。
- 适用：续动作、续对白、续剧情或用转场进入新场景。
- 不适用：修改原片走编辑；连接两个固定端点走两段转场。
- 产品入口：生成流选择底片 → 视频延长 → 时钟选择新增时长。
- 输入限制：页面快照要求底片不超过30秒；当前入口实时复核。
- UI步骤：看末尾1–2秒、选新增时长、写“接在原片末帧之后”的边界、写末态与新增段、生成、核对接缝。
- 提示词公式：尾接边界 + 末尾状态 + 新增触发 + 动作链 + camera/转场 + 结束状态 + 禁项。
- 字段解释：末态含位置/朝向/惯性/道具/光线/声音；转场必须有载体。
- 参数：单次新增4–30秒；套娃前重新读取最新真实末态。
- 改变与保留：只新增尾段；原片、身份、服装、道具和声场目标为保留项。含糊的“向前/向后续写”不是可执行边界。
- 短原创例子：从女人握杯对视的末态延6秒，男人说反转台词，女人愣住。
- 官方追溯：outline `LZqmdUyxiooBQwxhV9scZAkbn5b`、`MBECdiuETojiYrxudwzcQHbmn2g`，sourceOrder 337–489、638–694。
- 失败模式：第一帧跳变、动作重做、凭空出现、生硬切镜、多轮漂移放大。
- 验收：原片区间、接缝、第一新增秒、结束状态、真实末帧与声音分别检查。

## [CONTRACT:EDIT] 智能编辑

- 定义：用文字对已有视频做最小差异修改。
- 适用：明确对象、属性和生效时段的修改。
- 不适用：需要精确定位但文字歧义大时改用标注编辑。
- 产品入口：选择智能编辑；上传本地视频后可能唤起高级编辑。
- 输入限制：官方建议20秒内较稳、1–5张参考图较稳；不是硬上限。
- UI步骤：上传/选择底片、写对象/变化/时序/保留项、生成。
- 提示词公式：对象 + 变化 + 生效时序 + 严格保留项。
- 字段解释：对象唯一；变化可见；时序可解析；保留项限制重绘面。
- 参数：全片或明确开始/结束时间；输出时长需与底片核对。
- 改变与保留：只改目标属性，身份、动作、构图、camera、背景和声音按需保留。
- 短原创例子：把全片男人蓝裤改成黑棉裤，其余人物、动作、镜头和原音频不变。
- 官方追溯：outline `ZBnDdijdloaQyPxtWeHcc7MTnGg`、`WtPYdb5MvoRNpLxxakdcmmgWn8a`，sourceOrder 490–524。
- 失败模式：只改一帧、整片重绘、时长截断、声音误删、对象串改。
- 验收：目标变化、传播时段、非目标区、总时长和原音频逐项差分。

## [CONTRACT:MARK_EDIT] 高级/视频标注编辑

- 定义：用框选、画笔、箭头或定位点锁定具体帧与对象，再用文字定义变化。
- 适用：局部删除、替换、增物、服装/颜色变化。
- 不适用：标注不能替代全片跟踪、物理接触和保留项说明。
- 产品入口：高级编辑/视频编辑 → 标注画面 → 添加至输入框。
- 输入限制：选目标清楚、遮挡少的帧；区域不覆盖无关对象。
- UI步骤：停帧、标注、写提示、添加帧标签、核对时间戳、生成。
- 提示词公式：标注时点/区域 + 对象名称 + 目标变化 + 传播时段 + 保留项。
- 字段解释：标注回答哪里；文字回答什么、何时、哪些不动。
- 参数：单帧标签必须配全片或区间传播范围。
- 改变与保留：区域内目标改变，区域外与非目标时段保持。
- 短原创例子：以00:04框选裤子为目标，从00:00到片尾改为黑色，桌椅和女伴不变。
- 官方追溯：outline `FFzHd6KPhohAEdxn4PMctdv8nUf`，sourceOrder 525–563。
- 失败模式：标注越界、残留、背景糊块、颜色污染、物体漂浮。
- 验收：逐帧检查目标跟踪、边缘、背景补全、非目标区和时长。

## [CONTRACT:WHITE_MODEL] 白模控制

- 定义：用Maya/Blender animatic控制camera、空间、站位、动作、接触和遮挡，再渲染外观。
- 适用：复杂调度、1:1空间目标、人物/产品与camera关系敏感。
- 不适用：几张关键帧不能宣称锁定连续动作；创意参考不能宣称1:1。
- 产品入口：DCC插件/导出白模视频 → Seedance 2.5多模态/白模工作流。
- 输入限制：白模负责空间，身份/场景/产品需独立锚；上传限制实时复核。
- UI步骤：导出干净animatic、上传白模与外观素材、声明模式/映射、生成。
- 提示词公式：控制模式 + 白模职责 + 对象映射 + 渲染 + 时间轴 + 排除调试元素。
- 字段解释：严格模式逐时点继承；创意模式只迁移动作/运镜机制。
- 参数：画幅、帧率、时长、唯一camera与目标生成单元一致。
- 改变与保留：改变材质/身份/光线；保留camera、空间、动作、接触与遮挡。
- 短原创例子：把饭店入座白模A/B替换为男女主，严格保留拉椅与坐下接触。
- 官方追溯：outline `LBsudhf9ZoRjNQx8UN0cX3pBn3P`、`YvxXdyNdcoMuPlxbyLCcv5Ttnob`，sourceOrder 564–635、1230–1277。
- 失败模式：动作偏差、串脸、脚滑穿模、场景覆盖布局、调试线入画。
- 验收：camera/空间/动作、身份/材质、声音三类逐时点独立判定。

## [CONTRACT:TIMESTAMP] 时间戳文本控制

- 定义：用可解析区间控制动作、对白、镜头和场景发生时间。
- 适用：多镜头、对白、MV/卡点、广告、课程和长叙事。
- 不适用：时间戳不能替代故事因果或可见动作。
- 产品入口：任何支持文本提示的Seedance 2.5生成入口。
- 输入限制：无独立媒体上限；受当前operation总时长约束。
- UI步骤：先分故事节拍、分配真实秒数、连续写区间、核对总时长。
- 提示词公式：[开始–结束] 开始状态 + 触发 + 动作/反应 + 声音 + 结束状态。
- 字段解释：区间是验收坐标；结束状态是下一段输入。
- 参数：本Skill要求从0无缝覆盖到总时长；这是生产纪律而非官方强制语法。
- 改变与保留：段内状态可变；跨段身份、道具、axis和声音账本保留。
- 短原创例子：[05–09s] 她听见问题后移开视线，捏杯沿又松开，结束时仍未回答。
- 官方追溯：outline `Pj4zdZT8woN7bVx2pQGcs45sn9g`，sourceOrder 722–761。
- 失败模式：区间缺口/重叠、台词超时、切镜后状态复位、时码装饰化。
- 验收：区间覆盖、真实动作/台词时长、段尾交接和故事变化。

## [CONTRACT:MULTILINGUAL] 多语言

- 定义：以目标语言生成对白/表达，并绑定说话人和表演。
- 适用：多语言口播、广告、短剧和本地化内容。
- 不适用：页面案例不能证明任意语言/口音/长对白稳定。
- 产品入口：普通或超长生成；音色参考时同时绑定音频。
- 输入限制：参考音频应单人、干净、无BGM；台词量受时长约束。
- UI步骤：选语言、写目标语言原文、逐句绑角色/声线/动作、生成。
- 提示词公式：语言/口音 + 说话人 + 时间 + 目标语台词 + 情绪/动作 + 听者反应。
- 字段解释：语言决定文本；声线决定说法；时间决定口型和节奏。
- 参数：按正常语速给足秒数，长对白拆句并留反应。
- 改变与保留：台词语言可变，角色身份/声线/画面职责保留。
- 短原创例子：角色A用自然日语低声说一句道歉，B先停顿一秒再回应。
- 官方追溯：outline `IOCpdFX8Ro3vvJxgalMcnFJHnHh`，sourceOrder 762–827。
- 失败模式：混语、错音、串词、口型不同步、字幕文字错误。
- 验收：ASR、母语听审、说话人绑定、口型、语言纯度和文字OCR。

## [CONTRACT:CLEAN_AUDIO] 去字幕与无BGM

- 定义：分别控制画面文字和声音中的背景音乐，不用一个“干净”概括。
- 适用：净画面、后期合成、二次配乐或保留现场声。
- 不适用：全静音时应明确移除全部声音；保留字幕时不能写无字。
- 产品入口：新生成用全局约束；已有视频用智能/视频编辑。
- 输入限制：已有视频需能区分BGM、对白与环境声；音频质量决定分离难度。
- UI步骤：选择生成/编辑入口、分别列画面和声部去留、生成。
- 提示词公式：画面无字幕/文字/logo/UI/水印；声音移除BGM并保留指定声部。
- 字段解释：字幕属于画面；BGM、对白、环境声、动作声是四个声音职责。
- 参数：全片或具体时段；未指定默认按全片执行。
- 改变与保留：改变文字/BGM状态，保留人物、camera、对白与指定现场声。
- 短原创例子：全片无字幕和logo；移除音乐，保留对话、脚步与饭店环境底噪。
- 官方追溯：outline `JECcdEPa9oIMSyxvI3ecyYldnVf`，sourceOrder 828–854。
- 失败模式：误删对白、音乐残留、水下感、画面被重绘、文字残影。
- 验收：OCR、安静段听审、对白完整性、环境/动作声和画面差分。

## [CONTRACT:BASE_OPTIMIZATION] 基础生成优化

- 定义：2.5案例展示真人/毛发/声音、长尾动作、长时空和切镜的综合改善。
- 适用：用于选择更具体的身份、物理、动作和镜头写法。
- 不适用：案例改善不是任意输入的稳定保证。
- 产品入口：普通或超长视频生成。
- 输入限制：主体、时长和多参越复杂，仍有稳定性下降。
- UI步骤：选入口、把抽象要求改成可见物理事实、设置时长、生成。
- 提示词公式：具体主体 + 触发动作 + 物理反馈 + camera响应 + 结束状态。
- 字段解释：真实感来自光/材质/不完美反应，不来自“8K电影感”堆词。
- 参数：每镜保留一个主运镜；动作数量按真实时长收敛。
- 改变与保留：动作和情绪变化，身份/场景/物理规则保持。
- 短原创例子：猫落地时爪垫压地、毛发随惯性回弹，camera轻微下沉跟随。
- 官方追溯：outline `Afnydaq1YoT4qMxBYTrcgMswnFJ`，sourceOrder 855–912。
- 失败模式：实体语义偏移、多余人物、文字缺失、互动穿模。
- 验收：语义、身份、长尾动作、接触物理、camera和真实末帧。

## [CONTRACT:BGM] BGM分离/移除

- 定义：从已有视频移除背景音乐，按需保留对白、环境声和动作声。
- 适用：二次配乐、采访净化、配音前处理。
- 不适用：全静音、替换画面或重新创作声音时使用其他合同。
- 产品入口：智能编辑或视频编辑。
- 输入限制：底片需有可处理音轨；混音越复杂越需人工听审。
- UI步骤：上传/选择视频、列声部去留、要求画面保持、生成。
- 提示词公式：移除BGM/尾响 + 保留对白/环境/动作声 + 画面不变目标。
- 字段解释：每个声部独立声明；“音频保留”不等于只保留人声。
- 参数：全片或具体时段；输出音量关系和同步需验收。
- 改变与保留：只改变BGM声部，画面和指定现场声目标为保留项。
- 短原创例子：移除咖啡馆钢琴和尾响，保留两人对话、杯碰声与环境底噪。
- 官方追溯：outline `VxBFdcBJgoq3XGxz04icmvgenXf`，sourceOrder 934–964。
- 失败模式：音乐残留、对白失真、环境声误删、声画不同步。
- 验收：源分离/听审、ASR、音量远近、画面差分；视觉联系表不能证明成功。

## [CONTRACT:CREATIVE] 创意迁移

- 定义：只迁移camera、节奏、动作机制、光影情绪或转场机制。
- 适用：借参考片结构制作新主体/新场景内容。
- 不适用：1:1复刻或复制人物、品牌、台词和具体表达。
- 产品入口：多模态参考生成或编辑入口，按当前功能选择。
- 输入限制：参考视频只绑定一个核心机制更稳；输入时长按当前限制。
- UI步骤：上传参考、命名机制、写新因果、列禁止迁移项、生成。
- 提示词公式：参考视频职责 + 核心机制 + 新主体映射 + 新事件 + 禁止污染。
- 字段解释：机制是可抽象的镜头/节奏功能，不是原片表面元素。
- 参数：一次优先一个主机制；多机制需明确主次。
- 改变与保留：迁移机制，保留新项目人物/产品/场景/声音。
- 短原创例子：只迁移“贴近倒影后高速拉远揭示空间”，改为咖啡滴到办公室。
- 官方追溯：outline `FUiGdsgH6ohT8fxLGFQcoOSQn8f`，sourceOrder 965–998。
- 失败模式：原片人物/字幕/品牌污染、机制与新物理不兼容、效果稀释。
- 验收：机制可识别、具体表达不复制、新项目身份和品牌干净。

## [CONTRACT:LOCAL_EDIT] 局部消除与编辑

- 定义：在目标区域/时段删除、替换、增加或改变局部外观。
- 适用：去物、背景补全、换衣/颜色、加道具。
- 不适用：全场景重做或camera重构应走其他专项。
- 产品入口：高级编辑/视频编辑标注界面。
- 输入限制：目标需在标注帧清楚；移动/遮挡对象需全片跟踪说明。
- UI步骤：停帧、完整标注轮廓、写任务/传播/保留、加帧标签、生成。
- 提示词公式：目标 + 删除/替换/增加 + 背景/接触补全 + 时段 + 保留项。
- 字段解释：补全含结构/纹理/透视/光线；增物含尺度/接触/遮挡。
- 参数：单帧标注配全片或区间；区域尽量不越界。
- 改变与保留：只改目标区域和时段，非目标人物/camera/声音保持。
- 短原创例子：删除00:03框选垃圾桶，全片用墙砖透视和阴影自然补全。
- 官方追溯：outline `XFM8dEowko643ExuUJlckohhnYe`，sourceOrder 999–1056。
- 失败模式：残影、背景糊块、颜色污染、新物漂浮、整片重绘。
- 验收：逐帧边缘、背景、跟踪、接触、非目标区和源/结果差分。

## [CONTRACT:VIEW] 空间视角修改

- 定义：锁定事件与场景，只改变camera位置、角度、焦段或运动。
- 适用：高/低/POV/俯视/跟随/绕拍重构。
- 不适用：空间信息不足的大幅换位若无场景/白模锚风险过高。
- 产品入口：智能/视频编辑或多模态参考入口。
- 输入限制：新视角需要生成不可见区域；变化越大越需空间参考。
- UI步骤：上传底片、定义camera五要素、列场景/动作保留项、生成。
- 提示词公式：只改camera + 新机位/高度/朝向/焦段/运动 + 物理可达 + 保留项。
- 字段解释：camera是唯一变化主体；axis/遮挡/地平线决定空间可信度。
- 参数：一个主运镜；对话保持180度轴线，除非明确重新建立轴线。
- 改变与保留：改变视角，保留人物身份、动作时序、场景结构、道具和声音。
- 短原创例子：改为桌面上方一臂高度轻俯视，仍保持两人相对座位和轴线。
- 官方追溯：outline `UMNZd5FKQoO7SGxisApcJKXin8c`，sourceOrder 1057–1086。
- 失败模式：越轴、camera穿墙、补景随机、动作不同步、身份漂移。
- 验收：原事件时点、新透视/遮挡/光向、axis、人物和道具一致。

## [CONTRACT:VOICE] 音色参考

- 定义：用参考音频控制音色、音高范围、语速、停顿和情绪质感。
- 适用：短剧、品牌口播、多语对白和角色声音一致性。
- 不适用：未经授权的声纹克隆；音色参考不自动复用原台词。
- 产品入口：多模态参考生成，上传纯音频或音视频参考。
- 输入限制：单人、干净、无BGM/强混响；页面建议5–10秒相对稳。
- UI步骤：上传音频、绑定角色/声音职责、写新台词/时点、生成。
- 提示词公式：音频职责 + 角色 + 时间 + 新台词 + 情绪/语速 + 禁止原BGM/原台词。
- 字段解释：音色回答“怎么说”；文本回答“说什么”；时码回答“何时说”。
- 参数：台词秒数按正常语速；多人一人一声线。
- 改变与保留：改变台词内容/情绪，保留目标音色特征和角色身份。
- 短原创例子：音频1只负责女主低沉慢声线；她在8–10秒说一句短回应。
- 官方追溯：outline `V06TdeANpoawgNxVKAqcPPnvnwd`，sourceOrder 1087–1134。
- 失败模式：换声、串词、音色后段漂移、带入原BGM、口型错。
- 验收：ASR、说话人、音色听审、口型、情绪、噪声和长时漂移。

## [CONTRACT:MULTI] 多人参考

- 定义：逐人绑定身份、声线、站位、动作和关系。
- 适用：双人对白、群像、多人互动和动作戏。
- 不适用：把多人图片混成一个万能“人物参考”。
- 产品入口：多模态参考生成，分别上传人物素材。
- 输入限制：官方建议1–5主体较稳；更多主体稳定性下降。
- UI步骤：一人一素材/ID、建身份矩阵、写axis/动作/台词、生成。
- 提示词公式：A/B身份职责 + 初始站位 + 触发/动作/对方反应 + 台词 + 结束状态。
- 字段解释：身份、声线、左右位和动作归属四条必须独立。
- 参数：同屏人数、参考数和台词密度按时长收敛。
- 改变与保留：关系/表情可变化，脸、服装、声线、ID和角色职责保持。
- 短原创例子：A画左先问，B画右停顿后答；A全程保持听者状态。
- 官方追溯：outline `NIRadyJPFoRhK8x8K3wc0wcNntf`，sourceOrder 1135–1195。
- 失败模式：串脸、换衣、换声、左右互换、克隆人、接触穿模。
- 验收：逐人逐帧检查身份、数量、站位、视线、台词和接触。

## [CONTRACT:GREEN] 绿幕

- 定义：把背景变为均匀绿幕，或把已有绿幕替换为目标场景。
- 适用：抠像前处理与场景合成。
- 不适用：两种方向不能混写；绿色主体/透明高反物需谨慎。
- 产品入口：智能/视频编辑或多模态参考入口。
- 输入限制：快速运动、毛发、半透明、高反和绿色服装是高风险输入。
- UI步骤：选择方向、上传底片/场景、写边缘/光线/保留项、生成。
- 提示词公式：生成绿幕=背景纯绿+主体边缘保留；替换=目标场景+透视/接触/光向匹配。
- 字段解释：边缘含发丝/模糊/透明；合成含地面接触/阴影/反射。
- 参数：全片传播；绿色均匀度和溢色需后验测量/目视。
- 改变与保留：只改背景，主体身份、动作、尺度、camera和颜色保持。
- 短原创例子：把白墙替换纯绿，保留舞者发丝和纱裙半透明边缘，不染绿皮肤。
- 官方追溯：outline `Hge5du5MdoBuitxBiCxcOhz6n2b`，sourceOrder 1196–1229。
- 失败模式：绿边、溢色、缺手/发丝、场景漂移、接触阴影缺失。
- 验收：逐帧边缘/运动模糊/透明、主体色、透视、光向和接触。

## [CONTRACT:SEAMLESS] 两段视频无缝转场

- 定义：功能目标是在两个固定端点之间生成补间，并尽量保持两段输入；结果仍需逐帧核对。
- 适用：混剪、变装、时空过渡和两段视频拼接。
- 不适用：单底片续尾走延长；不能把“不修改原片”当必然保证。
- 产品入口：多模态参考/视频转场入口，上传前后两段视频。
- 输入限制：两段视频长度/总输入按当前入口；端点需有可匹配元素。
- UI步骤：上传A/B、读取A尾/B头、选桥梁、写连续变化/保留目标、生成。
- 提示词公式：A尾状态 + 触发 + 单一桥梁 + 连续变化维度 + B头对齐 + 两端保留目标。
- 字段解释：桥梁可为遮挡/相似形/动作/视线/旋转/焦距；对齐含位置/大小/方向/速度/颜色。
- 参数：补间时长以当前入口为准；一次优先一个主载体。
- 改变与保留：只允许补间承担变化；两端原片是应保留并验收的目标。
- 短原创例子：雨伞横扫满屏变成舞台幕布，再同向揭开第二段舞台。
- 官方追溯：outline `NDnGdQ7uEowoNtxfkgJcjQh7nFh`，sourceOrder 1278–1301。
- 失败模式：两端被改、重复/拉伸、硬切、主体克隆、声场断裂。
- 验收：逐帧对比两端、A/B端点、桥梁连续性、补间角色和声音接缝。

## [CONTRACT:STORYBOARD] 多宫格分镜

- 定义：先声明每格语义，再用独立身份/道具锚和逐镜文本生成连贯视频。
- 适用：强叙事短片、工业预演、严格镜头顺序与构图。
- 不适用：宫格不是连续运动真值；非分镜宫格不能擅自写一格一镜。
- 产品入口：多模态参考生成，上传宫格与独立角色/道具/场景图。
- 输入限制：格线清楚、顺序明确；复杂连续动作升级白模animatic。
- UI步骤：上传、声明格子语义/顺序、绑定主体、写故事和逐镜、生成。
- 提示词公式：宫格职责 + 独立素材职责 + 故事主线 + 逐镜九项 + 全局锁定/排除。
- 字段解释：宫格控镜头；人物图控身份；文本补因果、声音和镜间状态。
- 参数：镜头时间按动作/台词分配，不按格数平均；全片时码连续。
- 改变与保留：镜间事件变化，身份、道具、axis、光线和格序保持。
- 短原创例子：9格生日分镜按左上到右下，许愿—吹灭—回全景，男孩与蛋糕另图绑定。
- 官方追溯：outline `VioXdWsYCoBdztxSyyecXsZ2nYg`，sourceOrder 1302–1338。
- 失败模式：生成分屏、格序错、线稿当身份、镜间瞬移、道具消失。
- 验收：逐格对照景别/机位/站位/事件，检查连续性和排除格线/编号。
