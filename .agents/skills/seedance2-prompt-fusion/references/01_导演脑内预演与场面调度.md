# 导演脑内预演与场面调度

> 复杂项目的最高优先级，且只此一处。剧情/复刻/电影化/多人/巨物/无首尾帧连续性，先在脑中拍一遍，再落到八要素成稿。
> 目的：防止把提示词写成模板填空。模板只整理已经想清楚的画面，不能替代导演构思。脑内预演不是成稿——想清楚后只把"观众能看见的"压进成稿，解释性推理不外露。

---

## 1. 脑内预演的 10 个判断（写成稿前先答完）

如果还说不清下面任一项，就不能直接写最终提示词。

1. **风格世界** —— 这是什么视觉世界？画幅、色调、光源、摄影媒介、质感、声音规则是否统一？先定整片世界，镜头才不会各拍各的。
2. **戏剧关系与价值翻转** —— 画面核心不是"谁在做什么"，是"谁和谁什么关系"：谁主动谁被动、谁压迫谁退让、谁藏情绪谁逼近真相。关系决定站位、视线、景别、表演强度。再问一句：**这场戏交付的单一翻转是什么**（安全→受威胁、希望→绝望、陌生→同盟、怀疑→下单）？什么都没翻转的戏是装饰，删掉或并进别的镜头。
3. **空间地图** —— 先在脑中画空间再写动作：入口在哪、A 在左还右、B 在前还后、道具靠近谁、出口在谁背后、前/中/背景分别给谁。空间稳，动作才有承接。
4. **轴线与视线** —— 先定摄影机不能跨哪条线：对峙轴线、追逐运动轴线、正反打谁看左谁看右、HARD CUT 后是否仍在同一侧。轴线乱，观众以为角色换位。
5. **视觉第一落点** —— 观众第一眼看什么（脸/手/产品结构/地面脚步/巨物的腿），占画面多少，其他元素是否都为它服务。每镜只能有一个第一落点，否则模型平均分配注意力。**善用"发现"过程**：别开场就用全景把信息全盘托出（观众探索欲骤降）；用前景烟雾/人群遮挡 + 摄影机缓慢移动设计一条视觉引导线，让观众由未知到明朗地"发现"主体，用信息差制造悬念。
6. **机位/景别/构图** —— 用机位赋予动作意义：全景交代关系，近景读情绪，特写证关键动作；俯拍弱化、仰拍压迫、过肩建对峙、贴地低角度建速度。构图即权力：居中=稳定，偏边=压迫/逃离/失衡。同一动作换机位意义全变，不能让模型替你选。
7. **透视与比例锚** —— 用环境证明空间和体量：地面线条、墙面、门框、沙丘、人群队列、影子、尘雾、光束做透视锚；巨物用人物比例、投影、地面震动证明；产品用手、身体、衣物边缘证明尺寸。不要只写"大/远/真实"，让画面自己证明。
8. **主运镜** —— 每镜先定一个主运动，不要把运镜当装饰：locked-off 让表演自己发生 / slow dolly-in 推入情绪或细节 / dolly back 揭示空间或关系 / lateral truck 维持横向追逐 / tracking 跟随保路线。摄影机响应（抖动/交棒）只是事件反馈，不能抢主运镜。
9. **动作因果链** —— 动作是因果不是动词堆叠：`外部触发 → 视线反应 → 身体微动作 → 主动作 → 对方反应 → 道具/衣料/环境反馈 → 结束状态`。人物因为画面里发生的事不得不动，不是为提示词而动。
10. **结束状态** —— 每镜把状态交给下一镜：人物位置、朝向、视线、手中道具、身体惯性、情绪、产品状态、环境余波。没有结束状态，下一镜只剩随机续写。

## 2. 先锁世界：视听签名（一次锁定，全片遵守）

复杂项目在第 1 节判断 1（风格世界）落地为一张签名卡，后续所有镜头都是它的硬约束。锁定前请用户确认。

```text
【视听签名】
介质：胶片/数字 + 模拟 LUT（如 Arri Alexa LF + 35mm 颗粒）   画幅：9:16 / 16:9 / 2.39:1
调色：具体术语（Teal-Orange / Bleach Bypass / 单色统治 / Kodak Gold 暖怀旧），不写"高级感/好看"
色彩 ID：每个角色或势力一个唯一色相（≤6 个），反派色与主角色对撞
核心主题：一句"主语 + 比喻动词 + 宾语"，必须可视化（测试：闭眼能否想象一帧，不能就重写）
```

**大师基因（具名风格走英文锚点）**：用 `A × B` 或 `A × B × C` 公式，≤3 位，自检不互斥。

```text
A = 主视觉骨架（60%）   B = 调色/质感（30%）   C = 节奏/剪辑（10%，可省）
例：Guillermo del Toro × Michael Bay（机械哥特骨架 × 工业巨物尺度）
禁忌：塔可夫斯基 × Michael Bay（慢与爆炸打架）；具名风格与画幅/类型要自洽。
```

> 一个具名导演 ≈ 一次下达几十条打光/构图/色彩指令的压缩包，比泛泛"电影感"稳得多——这正是 Seedance「越接近训练素材越稳」的用法。但要点名到"导演 + 代表作 + 年代"级别才锁得住。

**功能声部（不想用具名导演时的替代）**：选一个功能化"声部"当全片默认手感，同样一次锁定几十个选择且零 IP 风险：

```text
观察自然派：隐形机位/可得光/低饱和/长镜晚切/克制表演 → 纪实、真实瞬间、UGC 升级款
古典构成派：从容运镜/雕琢动机光/和谐色/踩节拍剪 → 高端广告、质感产品片
动能派：手持追踪/硬光高反差/去饱和颗粒/快切 → 动作、运动、燃向
亲密极简派：近焦段/单一柔光源/暖收敛色/慢而少的剪 → 情感戏、孤独、口播信任感
图形形式派：锁定精确构图/硬造型光/克制色板/冷面节奏 → 设计感品牌、冷幽默
```
选定后全片不换；**唯一一次打破声部 = 转折标记**（紧凑片里最广的一帧、全程动镜里唯一的静止镜头、冷色故事里唯一的暖光）——观众在模式被打破处感到意义。张力上升时景别整体收紧、剪辑变密、光比加深，收尾再松开。

## 3. 从导演判断翻译成画面（关系/情绪/权力 → 可拍证据）

脑内判断不能原样塞进成稿，要转成观众看得见的东西：

```text
关系判断 → 站位、视线、距离          情绪判断 → 呼吸、嘴唇、下颌、肩膀、手指（见 references/02）
权力判断 → 仰拍/俯拍/过肩/遮挡       空间判断 → 左右、前中后景、透视锚（见 references/03）
节奏判断 → 镜头时长、剪辑点、主运镜速度   主题判断 → 镜头功能与视觉第一落点
```

**关系驱动姿态（多人同框必做）**：姿态和特效是人物关系的外化，不是孤立美术。先想清谁强谁弱：

- 真正的强者**平静、从容、甚至零特效**（强到不必展示力量）；弱/急的一方**张扬、用力、满身特效**（越使劲越显被压制）。关系定了全片一致，别中途反过来。
- 把关系翻成具体 blocking 写死：谁坐/卧/倚/立、谁高谁低、谁俯视谁仰视、谁的视线锁在谁脸上。**漏写体位 → 模型默认全员站立齐高；只写"看向某方向" → 望向虚空而非看人。**

**复杂表演项目先抓戏再写动作**：先确认核心戏剧目标（低位谄媚 / 高位嫌弃 / 等级碾压 / 情绪暧昧 / 尴尬笑点）和核心关系（谁主动、谁讨好、谁压制谁），**再写台词和动作**。口诀：先理解戏，再写动作；先锁关系，再做画面。

**一致性法则（每件乐器奏同一个音）**：把导演判断压成一句意图（"让观众感到她的笃定开始裂"），然后机位、焦段、光、色、调度、表演、声音、剪辑全部服务这一句——每个选择都要能用"因为意图是 X"回答。各项单独看都专业但方向不一 = 高级堆砌，贵而无意义。

**场景功能 → 连贯配置速查**（按本场功能取一套起手配置，再按意图和声部弯折；每行是一套连贯组合，不是选词菜单）：

```text
亲密对话/口播信任 → MCU-CU 平视长焦、微动或锁定、柔动机主光、声音稀疏 ‖ 表演：忍住的微行为 ‖ 拒绝：游走机位破坏亲密
权力对峙 → 对立角度、高度编码地位、光暖冷分裂、调度收拢距离 ‖ 表演：静止即支配，小失态即转折 ‖ 拒绝：对称中立抹平权力差
揭示/发现（产品初露）→ 先藏后露：构图遮挡→一次运镜或光变揭开，镜头与主体一同发现 ‖ 表演：拍认出的反应，不拍物体本身 ‖ 拒绝：开场全盘托出
抉择/转折 → 推镜孤立抉择者、世界安静、一个手势完成选择、光随之变 ‖ 表演：一个有前后差的决定性动作 ‖ 拒绝：让台词干身体的活
追逐/动作 → 跟踪或手持、轴向纪律、高反差光、声音变厚、一个清晰目标 ‖ 表演：重量/恢复/险些失手可见 ‖ 拒绝：叠运镜+碎动作
产品 hero → 从环境到细节的受控运镜、动机 hero 光打材质、身份锁死、干净声底 ‖ 表演：产品即演员（一次精确的动效）‖ 拒绝："动感产品运镜"带飞 logo 与外形
短剧钩子 → 竖幅紧构图、快推落到定住的反应特写、揭示瞬间硬光变、一声刺点后切 ‖ 表演：脸做事——平静→僵住→屏息 ‖ 拒绝：把后果演完（留给下一段）
情绪低谷 → 距离+静止、冷柔光、负空间、近无声，镜头旁观不逼近 ‖ 表演：收容，最小的真实手势 ‖ 拒绝：配乐煽情+侵入式运镜
```

## 4. 导演预演表（写 Shot 前的思考顺序，不必在成稿里全展开）

```text
1. 视觉世界 / 视听签名：__
2. 核心关系 / 冲突：__
3. 本段情绪弧线：__（起：压住 → 中：泄露 → 峰值 → 收在克制后的状态）
4. 空间地图：A 在__，B 在__，关键道具在__，出口/威胁/产品位于__
5. 轴线规则：摄影机始终位于__一侧，不跨越__
6. 视觉第一落点：每镜观众第一眼看__
7. 镜头结构：一镜到底 / 多镜 HARD CUT；理由__
8. 主运镜策略：每镜只保留__，为什么__
9. 动作因果链：因为__，所以__，导致__，最后__
10. 结束状态承接：上一镜留下__，下一镜继承__
```

复杂项目标准输出顺序：**判断任务 → 补齐信息 → 导演预演 → 视听签名 → 镜头结构/Shotlist → 段尾状态卡 → 八要素成稿 → 失败诊断**。

## 5. 四种常见跑偏 → 修正

```text
模板化跑偏：每行都填了，画面仍随机像拼贴。→ 没先定空间地图、第一落点、动作因果。先补预演表，再重写 Shot，别只改词。
运镜装饰化：写了推拉摇移，镜头没叙事功能。→ 把运镜写成"为什么这样动"：推进情绪/揭示威胁/保持追逐方向/证明产品细节。
动作清单化：跑、回头、摔倒、尖叫，没真实因果。→ 改成"听见/看见/触到/失衡"引发后续动作。
空间漂移：HARD CUT 后左右交换、比例变化、追逐像原地跑。→ 每镜先写机位、左右、前中后景、透视锚、运动方向（见 references/03）。
```

口诀：**先在脑中拍完，再写给模型；先做导演判断，再做八要素输出。**
