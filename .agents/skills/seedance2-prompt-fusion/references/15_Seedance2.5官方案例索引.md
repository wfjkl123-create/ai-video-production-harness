## 2. 查案例的方法

不要把 142 个视频或 220 张图的目录全部塞进上下文。按当前任务过滤 JSONL：

1. `section` 或 `caseFamily`：先选同类功能；
2. `inputRole` / `outputRole`：确认是生成、延长、编辑、参考还是成片；
3. `reusableRule`：读取可迁移方法；
4. `visualObservation` 与 `caveat`：检查成片到底做到了什么、哪里不能过度推断；
5. `duplicateOf`：重复文件只看一次画面，但必须理解各自上下文。

只借方法和控制结构；不复制案例人物、品牌、台词、字幕、水印或受保护创意表达。

## 3. 从案例提炼出的共同规律

- **素材职责越具体越稳**：人物、场景、动作、镜头、音色分别绑定，不把“参考”当万能词。
- **长视频靠状态变化而非字数**：时间段必须推动人物、信息、空间或风险。
- **编辑是最小差异合同**：写清改什么、何时改、哪些不动；描述越泛，重绘面越大。
- **白模与多宫格分工不同**：白模控制连续空间运动；宫格控制镜头顺序与构图。二者都不天然提供高清身份。
- **转场必须有载体**：遮挡物、相似形状、动作方向、光线或材质变化承担连接。
- **声音单独定义职责**：保留对白、环境声、动作声与移除 BGM 要分别说明。
- **案例成功不等于稳定承诺**：长时长、多主体、多参考和复杂物理仍有稳定性下降与抽卡风险。

## 4. 失败使用方式

看到案例做成某效果，仍禁止：

- 用“官方案例有”推断任意输入都能 1:1 复现；
- 把视频封面或文件名当作完整运动证据；
- 把同 SHA 的重复节点统计为多个独立成功样本；
- 忽略提示词之外的输入素材、标注工具和模式选择；
- 直接复制官方长提示词充当新项目的成稿。
