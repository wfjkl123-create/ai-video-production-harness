# 镜头 · 光影 · 表演 · 活人感词库

> 八要素里"镜头/光影/动作/表演"的挑用词库 + 让人物像真人的活人感方法。**挑用，别全堆。** 这里是表演与镜头词的唯一归属；空间站位见 references/03，特效见 references/06，电影化质感深层见 references/05。

---

## 1. 景别（Framing）

| 术语 | 含义 | 适合 |
|---|---|---|
| ECU 大特写 | 眼睛细节、物体纹理 | 泪水、压痕、产品材质、单个证据细节 |
| CU 特写 | 脸和脖子 | 情绪反应、产品细节 |
| MCU 中近景 | 头和肩 | 对话主力，短剧/带货最常用 |
| MS 中景 | 腰部以上 | 动作主力、人物关系 |
| WS 全景 | 环境中的全身 | 建立空间、孤独/压迫 |
| OTS 过肩 | 对话、揭示 | 双人戏 |
| POV 主观 | 镜头即眼睛 | 第一视角、产品初露 |

叙事序：远景交代环境 → 中景交代动作 → 近景交代情绪 → 特写交代证据。**别只写"特写/俯视"术语，写该景别里看得见的内容**（见 references/04 方法四）。
景别×脆弱锚点：大远景里别要求面部表演（小脸必漂）；macro 里别要大动作和文字重绘；重要细节的景别要配得上它的占比（同 references/04 §5）。

## 2. 视角（心理）与三分法站位

```text
平视：真实、平等、生活感 → UGC、家庭、对话
低角度轻仰拍：权力、压迫、英雄感 → 强势角色、产品 hero
高角度轻俯拍：弱势、被审视 → 低头、被压
侧后方视角：展示后/侧面变化又避免低俗直给
第一人称/主观：代入感
```
三分法站位：左 1/3=被观察/等待；右 1/3=强势进入/对峙；中心=证明/情绪爆发；下 1/3=手持/局部特写。**视觉第一落点放视觉中心。**

## 3. 焦段（Lens）

```text
24-28mm 广、沉浸 → 动作、建立、动态空间    35mm 纪实自然 → 手持真实、街景
50mm 中性 → 最通用                        85mm 亲密、浅景深 → 脸、情绪、人像
100mm macro → 材质极细节                  长焦压缩 → 制造关系密度、情绪密度
```

## 4. 运镜（Movement）—— 一个 Shot 只留一个主运镜

```text
locked-off 固定：真实 UGC、镜前验证、可信证明    slow dolly-in 缓推：痛点发现、情绪靠近
slow pull-back 缓拉：揭示环境、孤独、释放        handheld follow 手持跟：家庭行动、纪实
tracking 跟拍：人物走动证明                      slow orbit/arc 环绕：产品结构/穿后结果（慎用）
gentle pan 摇 / tilt up 上摇：从细节摇到反应      whip pan 甩 / rack focus 移焦：快节奏转场（慎用）
```
要"手持真实感+推进"时分主次：主 slow dolly-in，副 subtle handheld breathing。**不要**推+拉+平移+环绕叠加。

## 5. 光影配置 + 基础去塑料

每镜明确：主光方向 / 辅光强弱 / 轮廓光 / 眼神光 / 实用光源 / 光比 / 阴影软硬 / 光线情绪。常用光：逆光·侧逆光 / 硬光 / 丁达尔光 / 暖光 / 侧光·轮廓光 / 眼神光 / 柔光 / 蝴蝶光。

**去塑料 ≠ 加细节数量，而是让材质、光线、微瑕疵、环境互动成立**：用自然窗光、室内实际光源、布料纹理、环境小动效、真实身体反应；写湿润反光、皮肤毛孔、衣料纹理、冷暖光关系、背景虚化、前景遮挡。
- 反涂抹：`clean edges, controlled details, no oversharpen, no chaotic high-frequency detail`，同时保留 `realistic skin pores, natural imperfections, refined fabric texture`。
- ✗ 只写 8K/超清/电影级当万能词。别说 "pitch black"，要看清写 "dim but visible"。
**光影写「效果」不只写「来源」**：AI 学的是"光影分布↔词汇"的相关性、不懂物理反射，且对"左/右"识别波动。所以①弱化裸方向词，用具名灯位术语（`Rim light` 轮廓光 / `Backlit` 背光 / `Split lighting` 分裂光 / `Rembrandt` 伦勃朗光）；②写光作用的后果（`long shadows` / `high contrast` / `volumetric light`）。大平光（直照全脸、无阴影过渡）= 塑料贴图；用**局部光源**（一盏台灯只照侧脸和双手）+ **冷暖对比**（暖脸冷背景拉空间层次）+ **哑光皮肤** `matte skin texture` 雕出骨相、去油腻高光。

**光比与光位即情绪（不只照亮，还在表态）**：
```text
光比：低光比大平补＝安全、坦诚、开放、商业感；高光比重阴影＝私密、威胁、隐瞒、戏剧感——按这场戏的"情绪暴露度"选，不按好看选。
光位即人物塑造：正面光保护与讨好 / 侧光揭示纹理与冲突 / 逆光轮廓孤立且神秘 / 底光不安 / 顶光审判感。
光随转折而变：剧情翻转处让光一起翻——云飘过、台灯按亮、门开进来一道光。光的变化=情绪变化的可视化。
```

- 深层反塑料引擎（Capture Realism 4 机制、中灰无缝、夜戏）见 references/05。

## 6. 五维表演 + 微情绪（让人物像真人，不是 NPC）

**核心：高级表情不是放大情绪，而是压住情绪，让细节慢慢漏出来。**

五维：① 情绪原因 ② 眼神方向（先看哪后看哪/是否回避）③ 面部微反应（眼眶/嘴角/眉心/下颌/喉咙/呼吸）④ 身体联动（手指/肩膀/衣角/袖口/重心/发丝）⑤ 结束状态。

**情绪→生理指标查表（禁情绪形容词，落到生理）：**
```text
恐惧=瞳孔扩大+眼白增多+胸口快起伏+手指颤+后缩    愤怒=下颌肌隆起+颈青筋+鼻翼张+握拳指节白
悲伤=眼睑下垂+下眼睑反光+嘴角下拉+肩内收          绝望=瞳孔涣散+头垂+手垂落
```

微情绪时间轴（15s）：前 1/3 情绪被压住没崩 → 中 1/3 从眼神/呼吸/嘴唇泄露 → 后 1/3 一个关键微动作/泪水到峰值 → 结尾停在克制后的状态，不夸张大哭大笑。

微表情词库（挑用）：
```text
眼神：短暂停住/视线下垂/不敢直视/慢慢发空/眼眶泛红/下眼睑湿润反光/短暂抬眼又垂下
嘴唇下颌：轻轻抿住/嘴角想上扬最后收住/唇线变紧/下颌绷住/喉咙吞咽/尾音压住后沉默
呼吸：变轻/停半拍/胸口极轻起伏/说话前吸气/说完没立刻动
身体联动：手指收紧/指尖停在衣料/摩挲袖口/肩膀内收/重心后移/衣袖随呼吸起伏/发丝贴脸侧
真实泪水：泪光先在眼眶聚集→表面张力→睫毛打湿→一滴沿脸颊缓慢滑落留泪痕（不要玻璃珠假泪、不立刻大哭）
```

**四层动作只作诊断词库，不作动作配额**：微动作、惯性动作、神经反应、失控反应只在当前 cue、景别和人物保护策略确实需要时挑一个。人物为消化信息、压住反应、维持立场而主动静止是合法表演；要排除的是无张力死帧、循环闪烁和机械重复。禁止“每个拍点至少一个微动作”这类计数规则。

**一次只压一个主动作/主情绪**：叠 ≥3 个微动作做复合情绪会衰减成中性结果，加参考图也救不回。表情优先靠"逐特征点名"（厚嘴唇/明显眼白/大黑眼珠子），抽象动词"复刻表情"无效。

## 7. 说话与发声（对白戏）

说话自然化 = 说话原因 + 标点停顿 + 发声方式 + 面部反应 + 手部动作 + 听者反应（不要只写"她说某句话"）。

标点控语气：逗号=短暂停顿；省略号=犹豫/未说完/压情绪；破折号=转折/被打断；问号=试探；感叹号=情绪增强（慎用）。例 `你……为什么要这样做？`
发声方式：轻声/压低声音/带哭腔/带笑意/气息不稳/尾音下沉/语速放慢/说话前吸气/说完短暂沉默。

**声音形成过程**（笑/哭不写"哈哈哈"）：笑=短吸气→鼻腔挤出→扩散；哭=鼻塞→压抑抽泣→嚎啕。@音色与台词写法见 references/05。

## 8. 活人感（人物像真人）

**核心：不是脸，而是"有事可做"。** 不要只写人物怎么动，要写为什么动；不让人物表演动作，要让人物正在经历事情（动作触发与因果链见 SKILL §1 + references/01 #9）。

**假人 5 根源**（中 3 项以上就假）：没处境 / 没动机（动作非事件触发）/ 没过程（只写结果）/ 没细微反应 / 没人物关系（多人同时演）。

**环境对抗 + 物理惯性（让人物离开"真空摆拍"）**：别让角色在无风无阻力的真空里走秀（重心永远居中、左右手对称、衣服纹丝不动 = T 台模特感）。给画面加风/阻力，逼出"不经意的物理反应"，并写成因果链：
```text
环境因（一阵微风吹过）→ 动作果（她下意识抬手按住帽子防风、头迎风微倾）→ 物理延续（重心微前倾，裙摆随风和向前步伐自然扬起弧度）
抓拍瞬间：写"步伐迈出一半时"而非站定，动作就有了惯性和重量。
```

**写原因让模型算后果**：一个物理原因 + 2-3 个可见后果 > 三个互不相关的动作。"厚重的木门关上，烛焰朝它弯了一下" > "门戏剧性地关上"。后果即证据：重量显现在落地时的压缩、动量在过冲与回稳、摩擦在滑行距离、风在被它吹动的东西上。
用环境因素锁死动作动机，人物就不再是随机分配动作的无脑 NPC（无故放下手、无目的左顾右盼）。

**多人戏铁律**：不要让所有人同时表演。一方先触发动作，另一方延迟半拍产生轻微反应。先设计调度（谁先出现/谁观察/谁主动靠近/谁挡谁/最后谁占中心），再写台词。

**三层注意力层级（多人镜头的条件路由）**：先给每个人一个现实任务和注意目标，再按当前事件选择一层；可以继续任务、主动静止或在 cue 后异步反应，不要求持续运动：
```text
① 背景任务层：非焦点人物继续当前任务、保持有张力的主动静止，或只在注意力变化时出现一次可读反应；不按时钟眨眼，不持续填充小动作。
② 唯一焦点反应：全镜只有一人获得一个带时间窗的小反应——"B 的嘴角抬起，定住半秒的注视"。
③ 大动作默认禁止：多人同框时明确排除起立/走动/转身/换姿势/拿东西，除非其中一个就是本镜的唯一节拍。
```
人与道具的接触物理（递东西/举杯）在多人镜头里极脆弱——接触写简单，或移出画面。面部精度扛不住时，让**道具承载情绪**（捏紧的杯子、揉皱的小票），别赌微表情。

**群体异步（防"整齐划一 NPC 感"）**：一群人/一群生物同框，绝不让他们同步做同一件事——写"每一个都在做不同的事、动作各异、参差不齐、无一同步"。对同一触发（一声兽鸣/一声巨响）的反应要**有先有后**：最近的猛地停下、旁边的慢半拍才反应、最远的过一拍才茫然抬头、甚至有人朝错误方向张望。各自先后错落、此起彼伏，才像真实人群。

错误→正确：
```text
✗ 她很尴尬。   ✓ 她低头看向裙侧，嘴唇轻抿，右手隔着裙面摸到压痕，指尖停顿半秒，肩膀微微内收。
✗ 女子缓慢抬头看镜头。   ✓ 女子听到门外脚步声后，才缓慢抬头看向门口。
```

条件补强句（只有 cue 和景别支持时才改写使用，禁止原样当万能后缀）：
```text
人物先继续当前任务；触发发生后，注意力先改变，再由一个最小且可见的身体反应泄露压力，随后作出选择并停在新的末态。没有明确触发时不强行眨眼、摸头发、移动手指或制造持续小动作。
```
