# Seedance 2.5 编辑、白模与多宫格

## 1. 智能编辑 / 高级编辑 / 视频编辑

### 纯文字编辑

```text
在 [时间范围]，把 [具体对象] 从 [原状态] 改为 [目标状态]；
变化如何发生/是否瞬时；全片或仅该区间生效；
严格保留 [人物身份、动作、构图、背景、光线、镜头轨迹、声音等未修改项]。
```

最小公式：`修改对象 + 动作/变化 + 生效时序 + 保留项`。

### 圈选、箭头、定位点

标注负责“哪里/哪个对象/哪一帧”，文字负责“改成什么、何时生效、哪些不动”。提示词不要再模糊写“这里”“红框内那个”，编译时明确：

```text
以 00:04 的已绑定框选区域为目标，只修改区域内男生长裤颜色为哑光黑色；
从 00:04 起至片尾保持同一黑色与布料纹理；
保留裤子版型、腿部动作、人物身份、上衣、背景、构图、摄影机和原音频不变。
```

若只在局部时间生效，明确开始和结束；若要求全片一致，明确从首帧到末帧。

## 2. 常见编辑任务

- **移除 BGM**：指定移除背景音乐，保留对白、环境声、动作声；若全静音则另写。
- **去字幕/水印/无关物**：指定对象、位置、时间范围，并要求用邻近背景结构自然补全；不凭空改构图。
- **绿幕**：指定背景整体替换为均匀绿幕，保留主体边缘、发丝、半透明材质与动作；不要把主体染绿。
- **空间视角修改**：锁人物、动作与场景结构，只改摄影机位置/焦段/运动；新视角必须物理可达。
- **创意迁移**：参考视频只负责创意机制、节奏或转场，明确禁止迁移人物、品牌、字幕、水印和原场景。
- **音色参考**：音频只负责说话人音色、语速、情绪与停顿；台词文本和画面职责分开。
- **多人参考**：逐人绑定身份和站位，写清互相视线、动作触发、轴线与结束状态。

## 3. 白模控制

官方展示的核心是：Maya/Blender 中先设摄影机路线和白模动作，导出视频作为动作/运镜参考，再用人物/场景图完成高质量渲染。

先选控制强度：

- **严格渲染 / 强控制**：白模视频是空间、站位、接触、动作时序与摄影机轨迹的权威，下游尽量逐时点继承。
- **创意参考 / 迁移**：白模只提供动作机制、调度思路或运镜节奏，允许自然改编；必须明确哪些可变，不能再声称 1:1。

再判白模颗粒度：

- **粗颗粒白模**：主要提供运动轨迹、机位、站位、光影变化和切镜骨架；文本必须补全角色/道具映射、完整动作链、场景与材质。
- **细颗粒白模**：结构和时序已经清楚，重点写分段材质渲染、风格、光影和环境；明确排除轨迹线、坐标线、camera cone 与调试标记。

严格渲染模式的职责拆分：

```text
白模视频：空间、站位、接触、动作时序、摄影机轨迹的权威。
人物参考图：脸、发型、服装、体型与材质；禁止迁移姿势/背景。
场景参考图：场景美术、结构材质与光向；不得覆盖白模摄影机和空间关系。
文本：说明替换映射、必须保留项、禁止污染项与细节验收。
```

常见路由：

- **白模直接渲染**：保持白色无材质外观，只生成指定动作/运镜。
- **白模人物替换**：把白模人形替换为指定人物/动物/角色，严格继承动作和镜头。
- **白模场景美术化**：保留结构、透视、遮挡和摄影机，替换材质、灯光和环境。
- **标注增物**：在框选位置添加白模人物/动物/道具，并写明动作、视线、接触点。

若用户要求 1:1 强控制，不能靠文字声称“严格一致”完成；必须把 `.blend`/animatic 当空间权威并逐时点审核。

## 4. 多宫格分镜

官方方法先要求声明每格的语义：每格可以代表一个完整镜头，也可以代表人物、场景、道具或其他对象。只有明确是“电影分镜脚本”时，才采用一格一镜。

分镜宫格可归纳为：

1. 明确宫格图是分镜，并声明每格都是一个完整镜头及阅读顺序；
2. 独立绑定人物、动物、道具、场景参考，不让宫格小人承担身份细节；
3. 先写故事梗概与关系变化；
4. 逐镜补齐景别、机位、运镜、动作、视线、声音和结束状态；
5. 镜间写转场或硬切后的空间重锚定。

模板：

```text
素材1是 N 宫格电影分镜，按左上到右下读取；本任务中每格代表一个完整镜头。
素材2只负责角色A身份；素材3只负责角色B身份；素材4只负责道具……
故事：……
镜头1（0–Xs）：构图/机位/动作因果/声音/结束状态。
镜头2（X–Ys）：……
全片锁定：角色、道具、空间轴线、画风与无字。
```

多宫格适合验证镜头衔接、人物站位和强逻辑叙事；它不是连续运动真值。复杂物理动作若需要逐时点控制，优先白模 animatic。

## 5. 编辑类验收

```text
□ 修改对象是否唯一、位置/时间是否可解析？
□ 目标变化与保留项是否分开写？
□ 局部编辑是否污染人物、背景、镜头、动作或原音频？
□ 白模与外观素材是否各司其职？
□ 多宫格是否先声明每格语义；若为分镜，是否声明阅读顺序和一格一镜；角色身份是否有独立锚？
□ 任何“1:1”是否有对应控制资产与逐时点证据，而非口号？
```
