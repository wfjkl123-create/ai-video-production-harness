# 即梦 2.0/旧入口 IO 限制 · 视频延长 · 视频编辑 · 音乐卡点

> **版本警告**：本文件的数量、15 秒输出、写实人脸与旧延长交互来自 2026-07 的 2.0/旧入口记录。明确使用 Seedance 2.5 时，先读 `references/11_Seedance2.5官方路由与能力边界.md` 和 13–14；2.5 官方在线参数与专项写法覆盖本文件的冲突项。本文件在 2.5 任务中只保留音频时钟、编辑最小改动和连续性等通用原则。

> 两件事：① 即梦平台的输入硬约束（写提示词前先对账）；② 以"现有视频 / 成组图片 / 音频"为被加工对象的四种玩法。@ 分工与 tag 语法的总规则在 references/03 §3，本文件不重复；对白口型见 references/05 §5。

## 0. 即梦输入硬约束（2026-07 记录，版本迭代以当前界面为准）

| 输入 | 数量上限 | 格式 | 大小/时长 |
|---|---|---|---|
| 图片 | ≤ 9 张 | jpeg、png、webp、bmp、tiff、gif | 每张 < 30 MB |
| 视频 | ≤ 3 个 | mp4、mov | 每个 < 50 MB，总时长 2–15s |
| 音频 | ≤ 3 个 | mp3、wav | 每个 < 15 MB，总时长 ≤ 15s |
| **总文件数** | **≤ 12 个** | — | — |

- 输出 4–15s 可选，自带音效/配乐，480p–720p。
- **不支持写实真人脸部素材**（图片、视频均自动拦截）→ 虚拟形象/资产路线见 references/07。
- 带参考视频生成费用略高；文件位紧张时，优先上传对画面或节奏影响最大的素材。
- 每个上传素材都必须有 @ 归属和明确用途——只写"参考 @视频1"= 引用模糊，必须点名参考什么（运镜 / 动作编排 / 特效转场 / 节奏卡点 / 音色 / 服装 / 产品外观 / 字体 / 首帧 / 尾帧，句式见 references/03 §3）。

**按最脆弱锚点选模式**：身份/产品要稳 → 图生视频（@图锚定 + 保持约束）；两个端点都要精确 → 首尾帧；要借动作/运镜 → 参考视频分工；成片只错一层 → 视频编辑（§2）；要接着拍 → 延长（§1）。谁最容易碎，就为谁选模式。

## 1. 视频延长（向后 / 向前）

```text
向后延长：将 @视频1 延长15秒。 + 分时段写"新增部分"的内容（1-5秒：…… 6-10秒：…… 11-15秒：……）
向前延长：向前延长10s， + 从哪个画面元素开始铺（先写镜头从哪里起、如何过渡到原片首帧的状态）
```

- **铁律：生成时长选"新增部分"的时长**——延长 5 秒，生成长度也选 5 秒，不是原片+新增的总长。
- 新增段照常走空间锚定与承接：接原片末状态起笔（位置/朝向/道具/光影），沿用 references/03 §6 段尾状态卡纪律。
- **延长链有累积漂移风险**：连续多代后，身份与细节可能逐步偏移；不存在固定“第几代必漂”的官方阈值。发现漂移时回到**原始参考图 / 原始首帧**重锚身份；上一段输出主要用作衔接状态，不应成为唯一身份权威。

## 2. 视频编辑（保留大部，定向改一处）

保留原视频大部分内容、只改特定元素，通常能缩小重绘范围。是否更便宜、更稳定取决于当前入口、计费和任务复杂度，执行前另行验证。改哪处写哪处，其余“全部不变”（同 references/05 §7 改寄存器：写多了可能扩大重绘范围）。

```text
剧情颠覆：颠覆 @视频1 里的剧情，[谁] [眼神/情绪转变]，[具体动作，干脆利落/带犹豫]，[对方反应+台词]。
角色替换：@视频1 中的女主唱换成 @图片1 的男主唱，动作完全模仿原视频，不要出现切镜。
元素添加：将 @视频1 女人发型变成红色长发；@图片1 中的大白鲨缓缓浮出半个脑袋，在她身后。
视频融合：@视频1 中由粒子组成的马逐渐具象化，粒子变密，逐渐过渡到 @视频2；@视频2 的马在奔跑中
  逐渐变为 @视频3 并逐渐消散——融合处必须写过渡因果（变密/消散/穿过），不能只写"过渡到"。
```

**出手前先裁决**（详见 references/04 §4 重抽五裁决）：构图和时序都对、只错一层 → 编辑；调色/字幕/音量级别的瑕疵 → 后期修，都不值得整条重抽。

## 3. 音乐卡点（音频当剪辑时钟）

```text
图组卡点模板：@图片1 @图片2 … @图片N 根据 @视频（或 @音频1）的画面关键帧位置和整体节奏进行卡点，
  人物更有动感，可根据音乐及画面需求自行改变参考图的景别，及补充画面的光影变化。
舞蹈复刻：让 @图片1 中的人物复刻 @视频1 中的舞蹈动作和卡点音乐，动作流畅无卡顿。
```

**音频时钟纪律**（卡点稳不稳全在这四条）：

1. **一拍一事**：每个音乐落点绑恰好一个可见事件——一次切镜 / 一个定格姿势 / 一次灯光脉冲 / 一件物品落地。一拍叠多事必糊。
2. **唯一时钟**：音频做时钟时别再给第二套时序系统——静音有声的竞争参考视频（或明确降级 `@视频1 只负责运镜，@音频1 负责节奏`），也别同时写秒级时间轴。
3. **强节奏才有钟**：干净鼓点、节拍器式脉冲最稳；密集混音、散板抒情曲模型找不到钟。
4. **时钟只在一次 generation 内有效**：音频不跨段延续，多段成片的统一配乐后期加（千川场景=剪映）。
