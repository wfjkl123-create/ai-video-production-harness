# Seedance 2.5 提示词在线与 Word 双源验证

> 强制规则：每一条 Seedance 2.5 最终提示词写完后，必须经过本流程，才能标记为“已验证”。结构 lint、目录覆盖 PASS 或案例文件存在均不能替代双源核验。

## 1. 双源角色与证据优先级

### 在线官方文档：主证据

负责确认：

- 当前官方目录、功能定义和 operation 区分；
- 参数、素材数量、时长、模式与 UI 操作；
- 在线视频的动作、镜头、声音职责和失败表现；
- 最新新增、修改或只在交互页面中存在的能力；
- 案例上下文、提示词与输入/输出角色。

### 用户 Word 文档：交叉证据

负责确认：

- 导出时保留的正文、表格、提示词片段和静态图片；
- 在线规则是否在用户持有文档中有文字或静态图对应；
- 在线版本相对 Word 是否新增、删改或换了表达；
- 用户未来离线审阅时能否从 Word 找到同类方法。

### 证据优先级

```text
当前在线官方正文/当前交互 > 同日在线审计证据 > 用户 Word 的 OOXML 源文本与真实媒体
> Word 渲染页面 > 评论区/用户反馈 > Skill 的导演推导
```

Word 与在线冲突时，不静默选择：报告两边内容、时间和证据类型；当前在线规则用于执行，Word 差异保留为 `SOURCE_DIVERGENCE`。

## 2. Word 能证明和不能证明什么

### Word 可以交叉确认

- OOXML `w:t` 中的正文和表格文字；
- 198 个真实静态媒体及 220 次图片引用；
- 文档结构、章节顺序、表格单元格和静态截图；
- 两个飞书外部链接的存在；
- 某个术语、功能或提示词片段是否被导出。

### Word 不能证明

- 视频是否真实运动、动作是否连续、转场是否丝滑；
- 台词、音色、口型、BGM 分离和环境声效果；
- 在线播放器中的 142 个视频结果；Word 包内嵌视频/音频/OLE 数量为 0；
- 当前账号权限、价格、积分、审核状态和最新 UI；
- 中文排版像素级忠实度：LibreOffice 渲染存在系统性 CJK 缺字；
- 在线页面当前仍与导出 Word 完全一致。

因此 Word 对动态/声音能力的结论必须写 `NOT_PROVABLE_FROM_WORD`，不能写 FAIL，也不能用静态截图冒充动态证据。

## 3. 写完提示词后的九步验证

### 第一步：提示词结构硬门

运行：

```bash
python3 scripts/validate_seedance25_prompt.py prompt.txt --mode MODE --duration N
```

时间轴错误、外部指代、延长缺末态、编辑缺保留项、白模缺职责、多宫格缺语义均必须返回 error。

### 第二步：绑定当前 operation 合同

从 ref 23 只加载当前 `[CONTRACT:*]` 区块，逐项检查十四字段。提示词不需要把十四字段标签全部写出来，但必须落实其中与模型执行相关的输入、公式、参数、保留/改变、禁项和验收目标。

### 第三步：在线章节核验

使用 coverage contract 中的 operation → outline ID 绑定，确认：

- outline ID 存在于当前在线目录；
- 对应 `sourceOrder/recordId` 有官方正文；
- mode、duration、输入职责和提示词公式未超出在线证据；
- 易变参数注明“当前快照/执行时复核”。

### 第四步：在线案例核验

从三个 catalog 检索当前 operation：

- 至少一个相似成功结构；
- 至少一个明确失败或高风险节点；
- 输入角色、输出角色、时长和是否有音轨与当前任务可比；
- 重复 SHA 不能计作多个独立成功。

### 第五步：Word OOXML 文本交叉

在 `full-text.txt`、`document-source-order.tsv` 与 `tables.tsv` 中检索当前功能名称、公式关键词和核心参数。结论只能是：

- `CORROBORATED`：Word 有相同或等价文字；
- `PARTIAL`：Word 只保留部分文字/表格/截图；
- `NOT_FOUND`：本 Word 未找到，不等于在线能力不存在；
- `CONFLICT`：Word 与在线规则明确相反；
- `NOT_APPLICABLE`：该结论本来就只能由动态在线证据证明。

### 第六步：Word 静态图交叉

如该功能依赖界面按钮、标注工具、白模截图或宫格结构，检查 Word 真实媒体/页面联系表是否存在相应静态图。静态图只证明界面/构图存在，不证明生成效果。

### 第七步：剧情与语义核验

Agent 人工检查：

- 用户核心剧情、角色关系、反转和结尾是否写进镜头因果；
- 对白能否在时间内说完，是否逐句绑定说话人和听者反应；
- 场景切换后是否重新锚定人物左右位、axis、道具与视线；
- 提示词是否真正自包含，没有依赖当前对话。

### 第八步：风险对照与修订

把在线失败案例中的风险逐项映射到当前提示词。若风险已被提示词约束和验收覆盖，标记 `MITIGATED`；未覆盖则先改写提示词，再从第一步重跑。

### 第九步：形成验证报告

报告必须与提示词 SHA、在线快照、Word SHA 和验证时间绑定。没有报告的提示词只能称“草稿”，不能称“已验证最终提示词”。

交付或下游使用前必须运行 `scripts/verify_seedance25_report_binding.py`；当前提示词 SHA 与报告 SHA 不一致，或报告状态不是 `VERIFIED_PASS`，立即 FAIL，禁止复用旧报告。

## 4. operation 专项核验

| operation | 在线主查 | Word 交叉 | 必验风险 |
|---|---|---|---|
| standard/30s | 参数、基础公式、30秒与时间戳 | 四部分/时间戳文字和静态案例图 | 过载、串词、切场复位、结尾缺失 |
| ultra | 超长入口、30–180秒、长时案例 | 超长章节文字/时长截图 | 循环、漂移、末尾白闪 |
| extend | 底片≤30秒快照、新增4–30秒、转场 | 延长公式、按钮/时钟截图 | 第一帧跳变、原片改动、多轮漂移 |
| edit | 智能/高级/视频编辑和标注工具 | 框选、箭头、帧标签截图与文字 | 非目标区重绘、时长截断、只改一帧 |
| BGM/voice | 在线视频与声音职责 | 只能确认文字/静态截图 | Word不能证明音频，必须听审 |
| green | 在线动态边缘表现 | 绿幕静态截图 | 绿边、溢色、半透明与运动模糊 |
| white_model | 插件、白模视频与渲染案例 | 白模说明和静态截图 | 动作/camera偏差、接触、身份材质 |
| seamless | 两段输入和补间案例 | 公式/静态端点 | 两端被改、硬切、声场断裂 |
| storyboard | 格子语义、宫格输入、生成视频 | 宫格静态图和逐镜文字 | 生成分屏、格序错、镜间瞬移 |

## 5. 在线案例的成功/失败对照

验证报告至少列：

```text
成功参照：nodeId / caseFamily / 为什么可比 / 借用的结构
风险参照：nodeId / 可见失败或证据缺口 / 当前提示词如何缓解
重复状态：是否与其他节点同 SHA
音频边界：视觉审查是否不足以证明声音
```

不得把“官方有案例”直接改写成“本提示词一定成功”。

## 6. Word 逐项交叉规则

### 文字

优先使用 OOXML 源顺序文本，不依赖渲染 OCR。关键词匹配后必须读取所在段落/表格上下文，禁止用一次命中冒充整条规则一致。

### 图片

只使用原 DOCX ZIP 中 198 个真实媒体；排除外置盘生成的 `._image*` AppleDouble 旁车。图片在 Word 出现 220 次，不代表有 220 个独立文件。

### 视频/音频文件名

Word 中 `.mp4`/`.mp3` 名称是普通文本，不是嵌入媒体，不得计为已看视频或已听音频。

### 排版

97 页已目视，但 CJK 缺字使中文字形、换行与在线排版不可验。文字完整性以 OOXML 为准，页面图只验证几何、表格和静态图位置。

## 7. 冲突与缺失处理

- 在线有、Word 无：`ONLINE_ONLY`，允许执行，但说明 Word 导出不完整。
- Word 有、在线无：`WORD_ONLY_STALE_OR_EXPORT_ONLY`，不得直接当当前能力；回在线复核。
- 两边参数不同：`CONFLICT`，当前在线优先，并要求执行前实时 UI 核对。
- 两边文字相同但动态无法证明：文字 `CORROBORATED`，效果 `NOT_PROVABLE_FROM_WORD`。
- 在线案例成功、Word 只有静态图：不能提升证据等级。
- 任何冲突未解释：最终验证 FAIL。

## 9. PASS/FAIL 条件

### `VERIFIED_PASS`

- 结构 validator 无 error；
- operation 十四字段合同适用项齐全；
- 在线章节、参数和案例证据支持当前写法；
- Word 已完成交叉并正确标注局限；
- 在线/Word 冲突已解释；
- 剧情语义人工检查通过；
- 至少一个成功结构和一个失败/风险结构已对照；
- 提示词修订后已重新运行全部检查。

### `VERIFIED_FAIL`

- mode/时长/输入违反在线规则；
- operation 必备字段缺失；
- 时间轴、素材职责、保留项或关键剧情不成立；
- 把 Word 静态图/文件名冒充动态或音频证据；
- 在线/Word 冲突未解释；
- 只做机器 lint，没有语义和案例风险检查。
