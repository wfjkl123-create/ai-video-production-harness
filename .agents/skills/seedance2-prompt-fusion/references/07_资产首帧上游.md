# 资产 · 首帧上游（图生视频准备）· 附录

> 默认不加载。做复杂短剧/TVC/带货剧情、需要跨镜头人物或产品零漂移时调用。**先用图把人物/产品/首帧锁死，再喂给 Seedance 动起来。**
> 核心：静态资产负责"角色统一性"，Seedance 负责"动态唤醒"。信任参考图载身份/服装，提示词只补图里读不到的状态（湿/脏/破/damp）。出图用的是图像模型（Neo Image 2 / GPT Image 2 / MJ 等），不是 Seedance；本附录只给 Seedance 上游所需的资产纪律。

---

## 1. 资产收敛链（单向，下游靠上游收敛，不能倒跑）

```text
已锁定 Shotlist → 地基单图（锁脸/锁形态）→ Shot 可见覆盖身份包（按需正脸/侧脸/正面全身/背面全身）→ 条件场景板 → Seedance 视频
```
跳级 = 让模型凭空脑补本该从参考图读取的东西 = 串脸/漂色/形态崩/跨轴。色卡来源：用户给一张电影感场景剧照 → 提取主色/辅助/点缀调色板生成色卡，再喂进每条 prompt。

## 2. 两步走：先地基单图焊命门，再按 Shot 覆盖补角度

别一上来就出四视图（身份没定就摊 4 格常不一致，而且镜头未必会用到）。按命门二选一取景：
```text
真人/写实脸角色（脸一致性是命门）→ 地基单图用半身锁脸（腰以上、竖幅 2:3、最好带场景背景虚化）。
形态命门类资产（怪物/机甲/载具）→ 地基单图用全身/正交（orthographic，无透视畸变）。
```
地基单图焊死“身份 + 形态 + 比例”后，读取已锁定 Shotlist：正脸/3⁄4 脸近景才补正脸，纯侧脸近景才补侧脸，完整妆造/高风险全身动作才补正面全身，背影或背面结构可读时才补背面全身。只有四个维度都会被镜头读到时，才把它们组成角色卡：
```text
6 格角色卡（3×2）：正全身 / 左侧头 / 背全身 / 右侧头 / 正脸特写 / 细节。
"replicate identically" 段是承重墙：逐项点名必须跨实际生成视图锁死的（结构/独特特征/自然不对称/精确色/markings 同位/材质纹理），这是阻止角度间漂移的关键。没有被 Shot 使用的角度不得为了“资料完整”生成。
```

## 3. 中灰无缝 = 角色/首帧默认底

锁脸、产品图、首帧、角色卡默认用**中灰无缝**，不用纯白/纯黑：纯白纯黑=主体-背景最大对比，视频模型在高对比边缘最易烤进 halo、边缘呼吸、轮廓不稳。中灰降对比 → 边缘干净、做视频参考帧时少继承对比和塑料。背景中性、主体真实自然色（不被灰背景冷移/冲淡）。光要均匀无影（reference plate 不是 beauty shot，任何打光戏剧性都会污染后续一致性）。

## 4. 防串脸三件套（多角色最易身份贴反）

```text
① 逐张角色参考图排他声明 + 绑画面位置：@图1 对应画面左上方的男人 / @图2 对应画面右下方的女人。
② 锁定段写"不要两人互相串脸"。
③ Avoid 写 "the two faces swapped or merged"。
```
位置用图像坐标：需要精确站位时在构图参考图上打点（白点）+ 文字"标记=谁的落点"。打点只锁"在哪"，身份另靠角色参考图 + 排他声明咬死。参考图风格冲突会整批塌方（写实真人 vs 卡通同职责→系统崩），根因在输入端，删词治不了——换自洽参考图重建。

## 5. 首帧 / 尾帧准备

```text
首帧：@图N 作为首帧（写首帧画面特征，如 横向 motion blur 色彩纹），开拍从它起，保持同构图取景。
尾帧：最后一帧定格在[构图 + 动作 + 人物状态 + 前景/背景]——既是收尾也是剪辑钩子，接下一段更稳。
70% 正确的帧可截图做下一轮首帧，再图生视频收敛（见 references/04 §4）。
```

**双图首尾帧提示词只写过渡逻辑**：`@图1 为首帧，@图2 为尾帧` 之后，文字只交代 保持不变项 + 一条物理动作路径 + 一个运镜 + 光影延续 + 声音——两张图已携带的外观别再重描。尾帧必须声明 `@图2 是最终视觉目标`，不是氛围参考，否则结尾不落靶。

**首尾帧变形（持续载体法）**：两图差异大（形态变化/场景切换）时，点名 A 端状态 + B 端状态 + 一个贯穿全程不变的**载体**（logo/剪影/光源/机位）——"纸鹤展开成平整纸张，红色蜡封始终固定在画面中央"。载体咬住观众视线，中间帧的怪异被遮掉；剪辑变体 = 载体在切点前后保持同一画面位置与大小，周围环境整体置换（match cut）。太难的变形拆两段首尾帧（A → 载体稳定的中点，中点 → B）再剪辑相接。

## 6. 视觉锚点标注法（站位/轨迹用标注图，比纯文字稳）

扩散模型对"空间绝对坐标"信号弱（注意力在元素特征匹配上），纯文字写站位/轨迹常被高权重元素覆盖。给它一张**标注图**信号强得多：
```text
1 先造空镜：不加人物，单独生成纯场景底图。
2 人工标记：在底图上用画框/箭头粗暴标出站位或运动轨迹。
3 带图生成 + 文字点名 + 去标记："图1人物按红色箭头从1走到2，光影自然融合，画面不要出现红线/红框"。
多角色色彩隔离防混淆：用不同颜色框/色块，文字明确"绿标人物从1走到2，红标从1走到2，蓝标不动，四处观望"。
必写负面：不生成线条/框线/箭头，否则会被一起渲染进画面。
```
