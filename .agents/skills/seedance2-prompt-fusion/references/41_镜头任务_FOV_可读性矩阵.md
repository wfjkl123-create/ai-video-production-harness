# 镜头任务、FOV 与可读性矩阵

本文件用于解决“参数看起来专业，但镜头任务根本读不出来”的问题。先决定观众必须看清什么，再决定画框占比、机位距离和焦段感；FOV 数字不能单独决定景别或成功率。

## 1. 先锁一个主要任务

每个 Shot 只选一个主要 `shotJob`。内置任务包括：

- `geography`：读清空间、方向、人数和行动路径；
- `relationship`：读清人物距离、站位、权力和互相反应；
- `microacting`：读清眼神、呼吸、吞咽、下颌或嘴角等微变化；
- `product_detail`：读清产品结构、材质、接触点或功能证据；
- `action_impact`：读清起力、接触、位移、后果和恢复；
- `reveal`：控制观众何时得到关键信息；
- `camera_device`：镜头装置本身承担叙事变化；
- `atmosphere`：读清光、天气、材质、空旷/拥挤和环境节奏形成的感受；
- `suspense`：读清被遮住的信息、威胁方向、等待与注意力落点；
- `transformation`：读清变化前状态、触发、阶段、环境反馈和稳定终态；
- `hook`：在结尾读清一个不可误解的新信息、视觉反差或未完动作。

无法归入内置任务时可用 `custom`，但必须另写自定义任务名和最低可读证据；不得为了通过枚举把氛围、悬念、变形或钩子硬塞成 geography/action。一个镜头可以完成次要工作，但只允许一个主要任务决定景别、画框和摄影资源。两个主要任务都不可删时，应切镜、分阶段或明确先后，不用同一瞬间平均满足。

## 2. 可读性优先于焦段名

| 主要任务 | 最低可读证据 | 常见画面尺度 | 高风险冲突 |
|---|---|---|---|
| geography | 全身、相对位置、入口出口、动作路径 | 大全景/全景 | 人物过小却要求眼神或口型成为剧情核心 |
| relationship | 双方身体朝向、距离、视线与反馈 | 双人中景/中近景 | 背景信息过多挤压人物反应 |
| microacting | 面部主要区域与呼吸/下颌/眼睑变化可辨 | 中近景/近景/特写 | 超远画框、强运动模糊、遮挡或极端畸变 |
| product_detail | 结构边缘、材质高光、接触点可辨 | 中近景/特写/微距感 | 产品占比过小、手部遮挡、景深丢失关键结构 |
| action_impact | 起点、接触、方向、终点和环境后果 | 中景/全景，按动作幅度 | 过紧构图截断接触或后果；过宽导致冲击不可读 |
| reveal | 信息遮挡与出现时点清楚 | 由揭示对象决定 | 默认首帧可见规则提前泄底 |
| camera_device | 前景/背景/主体关系能证明装置 | 由装置决定 | 只有术语，没有可见参照物或变化峰值 |
| atmosphere | 光源、天气、材质与环境运动共同形成可辨感受 | 常偏宽，但由氛围载体决定 | 只有形容词，没有画内来源或环境证据 |
| suspense | 威胁方向、遮挡、等待、注意力与信息缺口 | 由隐藏/揭示对象决定 | 首帧泄底、随机黑边、人物无持续任务 |
| transformation | 初态、触发、阶段、反馈、稳定终态 | 由变化范围决定 | 只写结果、主体结构漂移、变化不进入环境 |
| hook | 结尾新信息、反差或未完动作清楚可读 | 通常收紧到钩子证据 | 最后一秒堆太多信息、钩子没有停留或末态 |
| custom | 在合同中明确声明的最低可读证据 | 由证据决定 | 自定义名称替代了可见验收条件 |

表演尺度跟随画面尺度：远景用重心、步幅、肩背和人与人距离；中景用上身、手部和视线；近景才用呼吸、吞咽、眼睑和嘴角。焦段改变但主体画框占比不变时，表演可读性未必改变；机位距离、遮挡、运动模糊和输出分辨率同样重要。合同不接受裸 `faceReadable=true`：微表演必须记录脸部画面高度占比或脸部像素高度、可见部位、遮挡和运动模糊。验证器的最低阈值只是筛除明显不可读构图的内部启发式，不是平台成功保证。

## 3. FOV 只是一层启发式

来源文件给出全画幅对角 FOV 近似值：`16mm≈107°`、`24mm≈84°`、`35mm≈63°`、`50mm≈47°`、`85mm≈29°`、`135mm≈18°`。这些值可用于摄影预演和矛盾检查，但须遵守：

- 它们是全画幅几何近似和 Higgsfield 写法经验，不是 Seedance 通用硬语法；
- 传感器/裁切、镜头畸变、机位距离和主体画框会改变观感；
- 精确 FOV 只有在用户明确指定或当前 surface 经当次验证时才进入正文；
- 没有证据时写“广角带出环境关系”“较窄视野压缩背景”“靠近人物但避免面部夸张”等可见结果。
- 同时写精确焦距与对角 FOV 时，必须声明传感器对角线与投影口径；rectilinear 镜头按 `FOV = 2 × atan(sensorDiagonal / (2 × focalLength))` 复算。缺口径、计算不一致或 fisheye/equirectangular 未绑定专用关系模型时，只保留一个精确值，另一项降为可见光学意图。

保守的内部起点，不是交付参数：

- geography 往往需要较宽视野，但先确保人物和路径仍可读；
- relationship 常用中等视野兼顾身体和表情；
- microacting 通常需要较高主体占比，不等于必须长焦；广角近拍若有意制造亲密或不安可以保留；
- product_detail 先按产品结构、工作距离和景深选择，不因“商业感”自动长焦；
- action_impact 先保住完整接触链，再决定宽或紧。

## 4. 空间净空检查

静态机位比较相机/稳定器包络、可用净空与安全余量：

```text
cameraEnvelope + safetyMargin <= availableClearance
```

运动机位还必须记录起点、终点、路径最小净空、稳定器/轨道扫掠包络和主体动态侵入余量：

```text
rigEnvelope + dynamicIntrusionMargin <= pathMinClearance
```

Dolly zoom、绕拍和移动窥视不能只用一个静态距离通过。净空不满足时依次考虑：缩短机位距离并调整视野、改变画框、改变主体站位、分镜、使用可验证的虚拟/重构空间。不能把相机放到墙后并假装“长焦会解决”。任何改变用户锁定景别或空间关系的方案属于实质变化，必须暴露。

## 5. 冲突裁决

- `wide + microacting`：先判断脸是否仍有足够画框占比；不够时用身体层证据、插入近景或声明取舍。
- `tight room + narrow FOV`：计算/估计所需距离；净空不足时不要保留伪物理机位。
- `close-up + large action`：若动作起点或终点出框，拆成建立动作与反应两个阶段。
- `product detail + hand action`：先锁可见结构和接触点，手只承担证明功能，不遮住结构。
- `wide lens + portrait beauty`：除非用户明确要夸张透视，避免让脸靠近画面边缘或过近机位。

## 6. 验收

- 不看焦段名，观众能否读到 shotJob 要求的证据？
- 主体画框占比、遮挡、运动模糊和景深是否支持该证据？
- 精确数字的证据级别是否允许进入正文？
- 相机在真实空间中是否有净空？
- 若有冲突，是否只调整最低优先级变量，并暴露实质变化？
