# UGC 真实感 · 介质缺陷与非完美事件（去 AI 感）

> 介质路由（SKILL §3 第0步）判定为"手机随拍 / 伪直播 / 幕后花絮 / 家庭录像 / 监控感"时加载本文件。核心：真实感不是写"真实"二字，是把介质的物理缺陷和非完美事件当正向画面写出来——**缺陷即真实**。电影化质感走 references/05，本文件只管"像素材，不像作品"的方向；表演层活人感仍用 references/02 §8。

---

## 0. 先定"素材来源身份"（UGC 的总开关）

写 UGC 提示词前先回答一个问题：**这段素材是谁、用什么设备、在什么年代、出于什么目的拍下来的？** 身份一旦确定，所有细节都能推导——2005 年朋友随手拍的 DV 会抖、会失焦、会突然关机；2024 年博主的手机竖屏有美颜感、会对镜头说话；监控没有声音、俯视角、低帧率。四要素缺一不可，信息不足先拦截补齐：

```text
① 拍摄者身份：朋友 / 家人 / 路人 / 博主 / 监控 / 纪录片摄制组 / 无人固定机位
② 设备与年代：手机 / DV / 监控 / GoPro / 专业机 / 网络摄像头；哪个年代
③ 主体与场景：拍谁、在哪、什么时间段
④ 情绪目标：温暖怀旧 / 孤独疏离 / 紧张不安 / 平静治愈
```

第二个关键认知：**AI 有强烈默认审美**（电影化平滑运镜、三脚架般稳定、完美居中构图、青橙商业调色、自动加商店人群、自动配 BGM、磨皮均匀布光）。想要真实感必须两手抓：①用介质缺陷包主动关闭默认行为；②在时间轴里植入非完美事件。**收尾锚点句**：全稿末尾用一句话锁定取舍依据——"捕捉__，仿佛一段[身份]用[设备]拍下的__素材"，模型在细节冲突时按它取舍。

> 与防污染体系（references/04）的协调：缺陷本身就是正向描述（"强烈手持抖动、构图偏离中心、自动对焦反复搜索"），正文全用正向写；"没有稳定 / 没有电影化运镜 / 没有现代调色 / 没有配乐"这类关闭三连放在摄影段末尾或 NEGATIVE 约束位，不散布正文。

## 1. 介质缺陷参数包（选一个贴进摄影句，按需增删）

原则：想要某种年代/介质质感，就完整描述那台设备的物理缺陷，每包写 6 个以上具体物理现象，别只写设备名。

**手机竖屏（2015 后）** —— 素人实测 / 伪直播 / 街拍 / 当代日常（千川 UGC 主力）
画面：9:16 竖构图、过度锐化与 HDR 处理感、电子防抖果冻效应、暗光涂抹感降噪、前置镜头轻微广角畸变。
操作：单手持机轻微倾斜、走路残留上下浮动、对镜头说话的自拍视角、手指偶尔擦过镜头边缘、突然抬起/放下手机开始与结束。
关闭三连：没有横屏。没有三脚架稳定。没有专业布光。

**消费级 DV（2000 年代）** —— 家庭录像 / 朋友随拍 / 千禧怀旧
画面：中等数字压缩伪影、褪色色彩柔和对比、轻微传感器噪点与滚动快门、高光易过曝暗部发灰、480p 至轻微高清之间的分辨率感。
操作：强烈手持抖动与不完美构图、频繁自动对焦搜索、镜头呼吸、明暗切换时曝光波动、变焦生硬速度不均、录制中途突然开始或结束。
关闭三连：没有稳定。没有电影化运镜。没有现代色彩分级。

**监控 / CCTV** —— 悬疑 / 客观记录感 / 伪纪录片（剧情钩子用，合规慎用）
画面：固定高位俯视角、每秒约 10-15 帧的顿挫感、低饱和或夜间红外灰白、角落时间戳持续跳动、低分辨率人脸模糊。
操作：完全静止或极缓慢预设巡航；无声；人物不知被拍、行为完全自然。
关闭三连：没有摄影师存在。没有构图意识。没有声音、没有变焦跟随。

**专业纪录片手持** —— 高质感纪实 / 测评口播 / 人物特稿
画面：浅景深主体清晰背景柔和、自然光为主宽容度高、克制调色接近肉眼。
操作：有经验的手持微晃不失控、跟焦偶尔慢半拍（保留这个不完美）、长镜头耐心观察不急切换、被摄者偶尔瞥向镜头又移开。
关闭三连：没有摆拍感。没有采访灯光。没有配乐驱动的剪辑节奏。

**GoPro / 运动相机** —— 第一人称 / 运动 / 旅行
画面：超广角鱼眼畸变边缘拉伸、高饱和默认色彩、强光镜头眩光、水滴灰尘沾镜头。
操作：胸挂/头戴第一人称、电子增稳压制后的剧烈震动残留、呼吸与身体晃动传导、视角随头部转动突然甩动。
关闭三连：没有第三人称跟拍。没有电影构图。

**网络摄像头 / 视频通话** —— 远程连线 / 低保真亲密感
画面：720p 以下低清、压缩块状伪影、屏幕光打脸的青白色、固定笔记本仰视机位。
操作：音画偶尔不同步、人物偶尔卡顿定格再恢复、背景是真实房间一角。
关闭三连：没有专业收音。没有补光灯质感。没有运镜。

**更久远年代（合并速查）**：VHS（磁带噪点扫描线、红色晕开、底部日期戳如 "JAN 14 1993"、逆光剪影化）；8mm 胶片（明显颗粒、暖黄偏色、边缘暗角、灰尘划痕闪过、每镜 3-5s 硬切、无同期声）。

## 2. 非完美事件库（每镜恰好 1 个，全片不重复）

时间轴每个镜头三层结构：**主体动作 + 环境呼应 + 一个非完美事件**。一镜塞两三个失误反而假；与 references/02 §8 的"环境因→动作果"因果链配合用。

```text
摄影师失误：自动对焦在主体与前/背景间反复搜索 · 构图偏离中心（操作者在追主体）·
  稍晚才捕捉到关键瞬间（人已转身才对准）· 变焦推过了又拉回 · 走动跟拍强烈晃动与运动模糊 ·
  手指/背带短暂遮挡镜头一角 · 对焦短暂失败画面呼吸
环境介入：微风吹动碎发衣角 · 云影掠过曝光随之波动 · 猫狗鸽子闯入画面主体自然回应 ·
  场外有人打招呼主体转头回应 · 阳光透过树叶在脸上明灭 · 路人从镜头前无意穿过
主体自然行为：注意到镜头露出小而真诚的微笑后移开视线 · 说话被环境音打断笑场 ·
  拨发到耳后等无意识小动作 · 动作做到一半改变主意（伸手拿杯又先擦了下桌子）
收束方式（结尾必选一，与拍摄者身份匹配）：录制中途突然切黑像关机 · 主体走出画面镜头停留空景两秒 ·
  镜头垂下拍到地面/脚再切断 · 有人喊拍摄者名字、镜头晃动转向声源时切断
```

> 收束是 UGC 最容易漏的一环：视频停在"正在进行"的动作上像被截断的素材，有收束才像一段完整的记录。

## 3. 氛围词 → 可拍现象翻译表

禁直接用左列抽象词（同 references/04 方法三），每种氛围选 3-5 个现象分配到环境句和时间轴各镜；听觉现象进声音句，**与画面元素一一对应**（有猫才有猫叫，有晾衣绳才有织物声）。同稿不混用冲突氛围（温暖+疏离），除非明确要情绪转折。

```text
温暖治愈：午后阳光透过树叶投下移动斑驳光影 · 晾衣绳织物微风中缓慢摇曳 · 杯口细微热气 ·
  猫狗慵懒靠近 · 窗台盆栽 ‖ 听：晨间鸟鸣 / 远处小孩嬉闹 / 勺子碰杯壁
怀旧千禧：褪色色彩柔和对比 · 电线杆架空电线切割天空 · 墙面斑驳低层住宅 · 巷口旧自行车 ·
  画面日期戳 ‖ 听：远处摩托驶过 / 老风扇转动 / 模拟信号底噪
孤独疏离：大面积负空间、人物偏居一角 · 空旷街道唯一移动的身影 · 荧光灯青白色调 ·
  深夜便利店灯光 · 人物长时间静止只有环境在动 ‖ 听：空调外机嗡鸣 / 脚步回声 / 雨点打遮阳棚
紧张不安：画面边缘偶尔闯入不明人影 · 灯管闪烁光源不稳 · 走廊尽头纵深阴影 ·
  手持呼吸感加重微颤 · 人物频繁回头停顿倾听 ‖ 听：环境音突然中断 / 远处金属碰撞 / 呼吸声被收进麦克风
平静冥想：云影极缓慢掠过整个画面 · 水面窗帘规律微动 · 机位几乎不动的长镜头 ·
  重复性动作（浇水/叠衣/剥豆）‖ 听：风穿树叶持续沙沙 / 水滴 / 若有若无生活声
热闹生活：前景不断有人车穿过 · 摊贩动作细节（翻炒/找零/擦桌）· 蒸汽油烟热浪扭曲空气 ·
  近景手部/中景人流/远景车流多层动态 ‖ 听：叫卖 / 锅铲碰撞 / 多人交谈混叠 / 自行车铃
梦境记忆：过曝窗户白成一片 · 胶片颗粒与光晕 · 镜头短硬切时间线跳跃 · 对镜头挥手大笑但无声 ·
  逆光轮廓面部细节丢失 ‖ 听：无声，或一层模糊环境底噪
```

表外氛围按同一逻辑自行翻译：**这种感觉在现实中由哪些可拍摄的物理现象构成？**

## 4. UGC 成稿组织与自检

成稿仍走八要素 / 头部块体系：介质缺陷包写进 风格+画质+镜头 位；非完美事件进时间轴每镜；素材来源身份句作全稿收尾锚点；角色跨镜必带一致性锁定句（"在整个视频中保持一致的身份、服装、发型和外貌"）；环境句排除模型爱加的商业元素（商店/广告/人群/咖啡馆——写成正向替代场景，见 references/04 方法二）。

```text
□ 素材来源身份四要素定了吗？收尾锚点句与身份/设备/年代自洽吗？
□ 摄影句有 ≥6 个物理缺陷现象？关闭三连放在约束位？
□ 每镜恰好 1 个非完美事件、全片不重复？结尾有收束方式？
□ 声音元素与画面一一对应？无配乐/无音效设计/无旁白按需声明？
□ 年代穿帮检查：DV 年代画面里没有智能手机 / 共享单车 / 现代广告屏？
□ 负面约束与正面描述打架吗（前面"没有电影化运镜"、时间轴又写"缓慢推轨"）？
□ 抽象形容词清零（美丽/电影感/高级/唯美）？
```

**千川内衣塑身落地**：素人实测 / 开箱 / 伪直播 → 手机竖屏包；闺蜜随拍 / 家庭场景 → DV 或手机包；测评口播 → 专业纪录片手持包；监控包涉隐私联想，带货场景默认不用。硬约束与合规降噪见 references/08。

**交付时附一句旋钮说明**：告诉用户这条稿的"素材来源身份"设定是什么，想调整改哪几个旋钮——介质包、时间段、情绪词、收束方式——别让用户从头改稿。
