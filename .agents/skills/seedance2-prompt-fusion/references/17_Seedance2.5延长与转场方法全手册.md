## 1. 延长的任务边界

视频延长 = 保留底片，在尾部（或当前入口支持时向前）新增一段。提示词只描述新增区间，不能要求模型重做原片。

适合：

- 续写人物动作、对白或剧情；
- 接力复杂动作；
- 在原片结尾后设计时空/景别/情绪变化；
- 逐步把短片扩成较长连续成片。

不适合：

- 修改原片中已有物体或人物：走编辑；
- 把两段固定视频连接并以“尽量保持两端”为目标：走无缝转场；生成后仍须逐帧验收两端是否被修改；
- 一次性新建 31–180 秒：走超长视频；
- 原片末尾已有严重身份/物理错误却想靠延长修复：先编辑或重做底片。

## 2. 末尾状态采样

延长前至少观察底片最后 1–2 秒和独立末帧，不只看封面。记录：

```text
人物：身份、画面位置、朝向、姿态、表情、视线、正在做的动作及惯性。
道具：谁持有、哪只手、接触点、开合/破损/湿润状态。
场景：地点、出入口、前中后景、光源方向、天气/粒子运动。
摄影：景别、camera 位置、焦段、正在运动的方向和速度。
声音：刚结束的台词、环境声、动作声、BGM 状态和声场远近。
```

延长提示词要把这些可见状态重述出来。“延续原视频”只是目标，不是状态描述。

## 3. 一镜到底延长

### 3.1 适用

原片结尾没有切镜动机，动作、camera 和空间能自然继续。官方建议用“延长自然、动作衔接流畅/自然、禁止生硬切镜、禁止物体凭空出现”等强约束。

### 3.2 完整公式

```text
向后延长 N 秒。
原片末尾状态：人物……；道具……；场景……；camera 正在……；声音……。
新增触发：……
新增动作链：起点 → 过程 → 结果；对方/环境/道具如何被影响。
camera：继承原片的机位、运动方向与速度，只允许……的自然变化。
声音：继续……，新增……，不新增……。
结束状态：人物/道具/camera/声音最终……。
强约束：延长自然、动作连续；禁止切镜、动作复位、凭空出现、身份/服装/场景漂移。
```

短原创例子：

```text
向后延长 6 秒。原片末尾女人在雨夜站台画面左侧，右手握伞，正转头看向驶近的公交车；camera 从她右后方缓慢横移，雨声连续。她看见车牌后向前迈两步，伞沿被风吹起又压下，公交车灯光扫过她的脸；camera 保持原方向横移并轻微后退。结束时她停在车门前，左手抬起准备刷卡。禁止切镜、脚步复位、伞凭空换手、雨势和光向突变。
```

## 4. 带切镜/转场延长

### 4.1 什么时候该切

- 新增段进入另一个地点/时间；
- 需要从动作细节切到结果或反应；
- 原片动作已完整结束，继续同机位会拖沓；
- 遮挡、视线、形状、动作或光线提供了自然桥梁。

为了“有电影感”而随意加转场不是动机。一个转场只保留一个主载体。

### 4.2 通用公式

```text
转场设定 = 转场类型指引 + 基础约束 + 切镜逻辑

转场类型：……
基础约束：镜头呼吸和时长协调，A 动作完成后再进入过渡，禁止生硬切镜和凭空出现。
切镜逻辑：A 镜结束动作/构图……；过渡载体……如何运动或变化；B 镜起始构图/动作……；景别由……变为……。
```

## 5. 11 类转场逐项合同

### 5.1 自然镜头切换

**适用**：绝大多数常规叙事；最依赖前后动作和信息连续。

**公式**：`A 镜动作/台词完成 + 留出呼吸 + 自然切到 B 镜对应反应/结果 + 重锚新景别和站位`。

**风险**：动作没做完就切、人物换位、B 镜凭空开始。修复是写清 A 的完成状态和 B 的进入状态，不靠转场特效遮错。

### 5.2 淡入淡出

**适用**：开头/结尾、明显时间流逝、一段剧情结束。

**公式**：`A 逐渐变暗至全黑或变亮至全白 → 短暂停留 → B 从同一纯色中逐渐显现`。

**风险**：误用于紧张动作导致泄气；人物半透明拖影。声明淡出的对象是完整画面，不是主体局部溶解。

### 5.3 叠化

**适用**：回忆、梦境、柔和时间推移、情绪联想。

**公式**：`A 透明度下降 + B 同时浮现 + 1–2 秒短暂重叠 + B 完全接管`。

**风险**：双脸、双主体、重影过久。重叠只用于过渡，不让两位同一人物同时执行动作。

### 5.4 白闪 / 黑闪

**适用**：爆闪、摄影闪光、撞击、强节拍或意识断片等有触发的重音。

**公式**：`可见触发 → 全屏瞬间白/黑 → B 在同一节拍出现`。

**风险**：当万能遮羞布，频繁使用；无触发的闪烁。写出闪光来源或动作触发，并限制次数。

### 5.5 擦除

**适用**：复古语法、明确地点切换、图形化叙事。

**公式**：`A 被边界从某方向推走，B 紧随该边界显现；擦除方向与主体/镜头运动一致`。

**风险**：方向混乱、像 PPT。指定从左到右/上到下，并让方向服务人物移动或画面构图。

### 5.6 遮挡 / 遮罩转场

**适用**：跨空间穿越、自然隐藏切点、人物/物体经过镜头前。

**公式**：`A 中指定遮挡物按方向接近 → 在明确时点完全覆盖画面 → 覆盖期间空间变化 → 同一物体/同方向移开，揭示 B`。

短例：前景路人深色外套从右向左完全挡住镜头，黑色布料在遮挡中变成剧院幕布，继续左移揭示舞台。

**风险**：没有完全遮满、遮挡物凭空出现、揭开方向相反。必须写进入、满屏、离开三阶段。

### 5.7 相似物转场

**适用**：蒙太奇、时空联想、形状/颜色/构图匹配。

**公式**：`A 的核心物体居中并固定形状/大小/颜色 → 过渡中材质或环境连续变化 → 变成 B 的对应物，中心位置和运动方向一致`。

**风险**：只说“相似”但形状/尺度不对应。明确匹配维度：轮廓、圆心、颜色、旋转方向或画面占比。

### 5.8 动作转场 / 甩镜衔接

**适用**：动作片、旅行、换装、快速场景切换。

**公式**：`A 的动作或 camera 甩向某方向并产生运动模糊 → 切点位于速度峰值 → B 以同方向、相近速度和姿态接上`。

**风险**：前后方向相反、人物姿势不接、模糊过长。锁方向、速度和身体姿态。

### 5.9 动态接力转场

**适用**：不同角色/物体接续同一动作，跳跃、跑动、抛接、换装挑战。

**公式**：`A 发起动作并在中间状态离画/遮挡 → B 以同一中间状态进入 → 完成动作`。

**风险**：动作在 A 已完成又在 B 重做；道具克隆。明确“接力点”及道具归属。

### 5.10 拉近 / 拉远转场

**适用**：微观到宏观、画中画、嵌套世界、从细节揭示全貌。

**公式**：`camera 向 A 的指定细节推进直到填满画面 → 纹理/颜色连续变化 → 继续同向运动后成为 B 的全景或另一对象细节`；拉远反向。

**风险**：焦点漂移、细节变成随机物。指定中心点、画面占比和 A/B 的形状对应。

### 5.11 水墨等风格化转场

**适用**：古风、人文、回忆、插画/动画；材质必须服从全片风格。

**公式**：`A 的可见元素化为墨迹/颜料/粒子 → 沿指定方向铺展并覆盖画面 → 墨迹重新聚合或晕开形成 B`。

**风险**：转场风格与真人写实片冲突、主体无因溶解、墨迹残留。说明由什么触发、持续多久、B 完成后转场材质完全退场。

## 6. 套娃式延长

官方页面当时的操作逻辑：只要最新生成的成片仍不超过可作为底片的时长上限，就能再次延长；每次新增 4–30 秒。制作纪律：

1. 每轮保存底片和新成片，不覆盖上一版；
2. 重新检查最新尾部 1–2 秒，不沿用上一次计划中的假想终态；
3. 记录身份、道具、场景、camera、声音的累积漂移；
4. 新一轮只描述新的新增段；
5. 一旦上一轮出现严重身份/结构错误，停止继续放大错误。

## 7. 失败模式与验收

### 7.1 常见失败

| 失败 | 原因 | 修复 |
|---|---|---|
| 新增第一帧跳变 | 未写末尾状态，只写“继续” | 重述位置、朝向、惯性、道具、光线、camera |
| 动作从头重做 | 提示词重复原片动作，没有写新增触发 | 从原片动作的“正在进行状态”续写下一阶段 |
| 人/物凭空出现 | 没写进入路径、遮挡或转场 | 给可见来源、路线、接触点或切镜逻辑 |
| 生硬切镜 | 既要求一镜到底又写了新场景 | 二选一；需要换场时选择单一转场载体 |
| 转场很花但故事断 | 为效果选转场，无叙事动机 | 回到 A 结果与 B 原因，选能承载因果的转场 |
| 原片被修改 | 把延长写成整片重制 | 明确提示词只作用新增区间，验收原片逐帧 |
| 多轮漂移放大 | 把生成尾帧当身份/材质权威 | 每轮仍绑定 canonical 身份/产品/场景锚；尾帧只负责状态 |
| 声场断裂 | 未交接 BGM/环境声/台词尾音 | 写声音末态和新增段去留，检查切点波形/听感 |

### 7.2 验收清单

```text
□ 被保留的底片区间是否逐帧未改？
□ 新增第一帧是否继承位置、朝向、姿态、惯性、道具、光线和 camera？
□ 新动作是否有触发、过程、结果和结束状态？
□ 一镜到底是否完全无切镜；带转场是否只有一个主载体？
□ A 末构图/动作与 B 初构图/动作是否明确对应？
□ 新增段是否在所选 4–30 秒内完成？
□ 人物身份、服装、道具、场景与声音是否无漂移？
□ 多轮延长是否在继续前审查最新真实尾部？
```
