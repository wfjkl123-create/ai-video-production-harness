- 权威来源：<https://bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e>
- 白模插件来源：<https://bytedance.larkoffice.com/wiki/Jwg8wRW1Fig7CxkOMfScitsvnub>
- 本地来源快照：已脱敏的官方手册导出；二进制原件不随本仓库分发。
- 检查日期：2026-07-31
- 本目录只沉淀官方手册可支持的能力、提示词结构、限制和失败模式。作者对案例的文字评价不自动等于 Harness 实测 PASS。

证据标签：

- `OFFICIAL_HARD_LIMIT`：官方正文明确给出的输入或时长上限。
- `OFFICIAL_GUIDANCE`：官方推荐的稳定区间，不是硬上限。
- `OFFICIAL_CLAIM`：官方描述的能力，仍需当前模型档案或付费小样验证。
- `CASE_OBSERVATION`：从案例视频或图片观察到的结果。
- `HARNESS_DECISION`：为了成本、可追溯性和安全做出的本地流程决定。
- `UNRESOLVED`：手册、当前 UI、LibTV 目录或真实输出之间尚未闭环。

## 能力总表

| 能力 | 官方信息 | Harness 状态 |
|---|---|---|
| 标准生成 | 4–30 秒 | 可规划；当前 LibTV 别名未解析，禁止提交 |
| 视频延长 | 原视频不超过 30 秒；单次延长 4–30 秒；结果最长 60 秒 | `native_extend` 规划能力 |
| 超长视频 | 30–180 秒 | `ultralong` 规划能力；高失败爆炸半径 |
| 时间戳 | 按秒指定动作、台词、声音与转场 | 视为秒级软约束；生成后反向验收 |
| 多语言台词 | 手册展示多语种台词与口型案例 | 逐句绑定说话人、语言、原文和时间；仍需 ASR/人工验收 |
| 无关字幕/BGM 抑制 | 官方宣称减少无关字幕和 BGM | 继续使用文字/音频 keep-list 与负向约束，不当作绝对保证 |
| 多模态参考 | 最多 30 图、10 视频、10 音频；音视频各自合计约 30.2 秒 | 硬上限与稳定警告分开 |
| 纯音频参考 | 支持 | 必须声明音频只控制什么、不得控制什么 |
| 智能编辑 | 用文字增加、删除、替换或修改视频 | 门 5 局部返修候选 |
| 高级编辑 | 框、线、箭头、文字、地标点与时间轴标注 | 必须绑定标注 SHA、区域、时间和 keep-list |
| 视频编辑 | 对生成视频继续修改 | 新付费任务、新指纹、新审核 |
| BGM 分离 | 去音乐、保留说话与画面 | 先与确定性音频工具比较成本和损伤 |
| 创意迁移 | 迁移动作、镜头语言、氛围和网感 | 参考视频职责必须收窄，防止画面污染 |
| 局部消除 | 删除或替换局部物体 | 必须检查标注区外像素和音频是否被误伤 |
| 空间视角修改 | 改机位并补画未出现空间 | 视为生成式外推，不得称为真实空间恢复 |
| 音色参考 | 多音色、角色声线参考 | ASR、说话人和音色一致性需独立验收 |

| 绿幕编辑 | 背景替换与绿幕输出 | 检查绿边、溢色、发丝、半透明材质 |
| 粗白模 | 白模只提供动作、动线、机位、站位与节奏 | 先登记 `spatial_control_model`；获准作为生成输入时使用 `spatial_control_animatic`。旧文档中的 `white_model_video` 语义归并到该路线 |
| 细白模 | 完整模型的材质、光影和风格渲染 | 去除轨迹线、坐标线和 camera cone |
| 两视频补间 | 自动生成两个视频之间的桥段 | `transition_bridge`；两端视频保持性复核 |
| 多宫格分镜 | 简笔画/火柴人宫格控制构图、景别、运镜和动作 | 与 Shotlist、假模宫格结合使用 |

## 参数与稳定区间

### 官方硬上限

- 图片：30。
- 视频：10；单条约 1.8–30.2 秒；总计约 30.2 秒。
- 音频：10；单条约 1.8–30.2 秒；总计约 30.2 秒。
- 标准输出时长：4–30 秒。
- 超长输出时长：30–180 秒。
- 当前手册正文明确的输出分辨率：480p、720p。

### 官方稳定建议

- 人物/主体图片 1–8 张更稳；9–12 张开始降低稳定性。
- 主体视频或音频 1–5 个更稳；6–10 个更依赖抽样结果。
- 主体视频或音频 5–10 秒更稳。
- 多于 5 个主体时，独立单视图通常比一张多视图大宫格更稳。
- 多张独立多视图图片优先于把多视图塞进一张图。
- 视频编辑源不超过 20 秒更稳。
- 编辑参考图 1–5 张更稳；6–8 张开始降低稳定性。

这些建议必须编译为警告，不得伪装成平台硬限制。

## 已知文档与案例风险

- 时间戳可以控制秒级顺序，但案例并不能证明逐帧准确。
- 手册示例存在 10–11 秒、17–18 秒、23–24 秒等时间轴空档；Harness 必须补成无缝 `[0,T]`。
- 官方示例使用 `@图1`、`@图片2345` 等自由编号；Harness 源提示词继续使用 `@素材[exact-id]`，由编译器映射。
- 官方示例含“上述、前面、沿用”等依赖页面上下文的表达；生产提示词必须改为零上下文合同。
- 局部编辑可能误伤未指定物体、服装、帽子、声音或背景。
- 官方案例存在“目标窗口替换成功，但 30.02 秒输入被截到 21.73 秒”的整体失败；编辑输出必须先过时长与头尾完整性硬门。
- 案例中有关键实体错物（要求沉船，实际更像鲸/海兽）；产品与剧情道具需独立结构验收。
- 绿幕案例可能残留绿色溢色。
- 场景参考、多人身份和长视频后半程仍可能漂移。
- 文档含品牌、动漫 IP、水印处理和商品承诺案例；这些不能自动进入正向生产模板。
- 正文只明确 480p/720p 输出；宣传截图出现的更高分辨率在真实模型档案验证前保持 `UNRESOLVED`。
- 当前 `libtv model search -t video "Seedance 2.5"` 返回 `matchKind=none`。禁止猜测模型别名或把 2.0 的批准复用到 2.5。
