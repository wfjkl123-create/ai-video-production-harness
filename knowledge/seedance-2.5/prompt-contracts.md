# Seedance 2.5 提示词合同

本文件把官方手册的提示词思路改写为可被 Harness 编译、审查和复现的生产合同。不得直接复制官方示例中的自由编号、隐含指代或有空档时间轴。

## 1. 通用四段式

```text
【素材职责】
@素材[id]：媒体类型；只控制……；不得控制……。

【一句话总览】
主体 + 地点 + 核心事件 + 题材/风格 + 主要运镜。

【完整时间轴或故事线】
[00.0-04.0s] 画面；运镜；动作；表演；台词；音效；结束状态。
[04.0-08.0s] ……

【全局约束】
机位和空间规则；身份/服装/产品结构；光影；声音；允许文字；禁止项；最终状态。
```

硬规则：

- 所有素材必须以 `@素材[exact-asset-id]` 声明职责。
- 时间轴无空档、无重叠，完整覆盖 `[0,T]`。
- “不要字幕”要改成“除明确允许的文字外，不生成其他文字”。
- 每段写可见动作、动作原因、对方反应和结束状态，不用“自然一点”“更有电影感”代替。
- 时间戳是秒级控制目标，不承诺帧级命中。

## 2. 真人角色七维结构

官方结构可归纳为：

```text
人物身份 = 具体年龄与文化背景
皮肤 = 冷暖色调 + 具体肤色 + 毛孔/纹理/真实瑕疵
辨识度 = 眼型 + 眉骨 + 鼻梁 + 唇形 + 下颌/骨相中的至少三项
眼神 = 目光目标 + 可见眼部状态 + 底层情绪
头发 = 具体发色 + 发丝状态 + 发型 + 环境互动
服装 = 剪裁 + 颜色 + 服装名词 + 材质/新旧 + 穿着细节
体态与表演 = 骨架/肩部 + 构图 + 动作/视线 + 气质与情绪
```

Harness 修正：

- 身份与服装已有 locked 参考图时，正文只写必须发生的状态变化，不重复创造新外观。
- “灵魂、压迫感、温柔”等抽象词必须落成眼睑、眉心、嘴角、呼吸、喉头、重心和视线目标。
- 多人物分别写角色 ID、身份图、服装图、声线、站位、注视目标和不得互换项。

## 3. 多参 30 秒合同

```text
【任务】30 秒标准生成；项目/段落/用途。

【多模态参考层】
逐项声明每张图、每段视频、每段音频的唯一职责和污染禁止项。

【全局设定】
环境与物理质感；视觉风格；镜头语言；主体造型；表演核心；禁止项。

【秒级时间轴】
把 30 秒拆成连续时间片。每片包含：
1. 景别、构图、机位与镜头运动；
2. 主体动作链和物理反馈；
3. 表演触发、潜台词、注视对象和对手反应；
4. 台词、说话人、停顿与音效；
5. 转场触发和下一片起始状态。

【全局收束】
角色/服装/产品/空间/声音/字幕/分辨率/最终定格。
```

成本与稳定规则：

- 不为凑满 30/10/10 而上传无职责素材。
- 超过官方优选区间时发出稳定警告并显示一次失败的最大积分损失。
- 多人物优先独立原子身份图；角色板继续用于人工审核。

## 4. 超长视频合同

超长模式仍使用“素材职责 + 总览 + 故事段落 + 全局收束”，但增加：

- 30–180 秒章节表；每章有目标、冲突、视觉状态、人物状态、开始和结束状态。
- 每章内部再拆连续时间片。
- 每 15–30 秒设置可机器检查的里程碑。
- 标记不允许回滚或重新出现的状态，例如已脱下服装、已离场人物、已损坏道具。
- 先评估失败爆炸半径；精确复刻默认不走 180 秒单任务。

## 5. 视频延长合同

```text
【源视频绑定】
@素材[source-video]：只提供前段画面、人物状态、动作速度、镜头惯性、声音时钟和最终状态。

【延长范围】
源视频时长；向后延长秒数；最终预计时长。

【继承状态】
人物身份、服装、产品、空间、光线、相机位置、运动方向、动作速度、音频状态。

【新增时间轴】
[source-end - new-end] 只描述新增内容；第一动作必须承接源视频最后动作。

【保持与禁止】
不得重写原视频；不得回放已有动作；不得新增未声明人物/字幕/BGM；不得生硬切镜或物体凭空出现。
```

每一次延长都是新的付费任务、新媒体 SHA、新编译包和新批准。原视频是否被改动必须通过帧、音频和 SHA 派生证据检查。

## 6. 智能编辑与高级编辑合同

基础编辑公式：

```text
具体对象 + 从 A 到 B 的变化 + 生效时间 + 必须保持不变的内容
```

高级编辑公式：

```text
标注类型与方位 + 标注内/外 + 具体对象 + 变化 + 生效时间 + keep-list
```

完整合同：

```text
源视频 SHA：……
标注 SHA：……
目标区域：红框内/红线左侧/箭头终点/地标点处……
目标对象：……
变化：从……改成……
生效时间：[05.0-08.0s]
渐变方式：瞬时/逐渐/随动作触发
必须保持：人物脸、服装其他区域、镜头、背景、原台词、音效……
禁止：标注区外变化、身份漂移、音频噪声、额外文字、边缘闪烁……
```

生成后必须比较标注区外像素、角色身份、服装、音轨和时间边界。局部修改成功不等于整条视频通过。

## 7. 粗白模与细白模

### 粗白模

用途：白模只提供动作、动线、运镜、站位、光影变化和节奏。

```text
参考声明 + 模型到角色映射 + 完整剧情/动作序列 + 场景处理 + 全局收束
```

- 每个颜色/形状模型必须对应唯一角色或道具。
- 有四肢或翅膀时写完整动作链；官方提示粗白模对复杂肢体的稳定性较弱。
- 禁止把白模材质、脸、颜色和简化结构迁移到成片。

### 细白模

用途：模型结构已经完整，主要替换材质、光影、环境和风格。

```text
渲染指令 + 分段渲染描述 + 转场触发 + 场景处理 + 全局收束
```

- 上传前清除轨迹线、坐标线、控制器和 camera cone。
- 明确人物材质在转场前后保持还是变化。
- 白模视频必须登记 SHA 和其唯一控制职责。

## 8. 转场词库

每次只选一种主要转场，并写清触发物、遮挡/运动方向、A 端状态和 B 端状态：

- 自然镜头切换：留足呼吸时间，不生硬跳切。
- 淡入淡出：用于开头、结尾、时间跨越和章节结束。
- 叠化：A 逐渐透明、B 逐渐显现，允许短暂重叠。
- 白闪/黑闪：绑定明确重音、枪声或撞击声。
- 擦除：B 从明确方向推进覆盖 A。
- 遮挡转场：物体完全遮挡镜头后进入 B。
- 相似物转场：A 末帧与 B 首帧形状、轮廓或颜色匹配。
- 动作转场：A、B 使用同方向、同力度的甩动或动作模糊。
- 动态接力：人物动作跨场景连续，例如跳出后从新场景落入。
- 拉近/拉远：A 的局部细节扩展为 B 的全景或反向变化。
- 水墨转场：仅在东方美学明确命中时使用，写墨迹触发和完成状态。

## 9. 专项功能合同

### 多语言台词

每句写明角色 ID、语言、台词原文、开始/结束时间、停顿、情绪和目光对象。不用拼音、谐音或中文释义替代目标语言原文。生成后分别验收语种、原文准确性、口型、说话人和语速。

### 无关字幕/BGM 抑制

用白名单写法：“画面只允许出现……文字；音轨只允许说话人……、环境音……和音效……”。若白名单为空，明确写“不生成任何字幕、标题、水印、logo 或 BGM”。官方的“减少”不是绝对保证，仍要 OCR 和音轨验收。

### 增加、删除、替换、属性修改

四类操作都使用同一最小合同：目标对象 + A→B 变化 + 生效时间 + keep-list + 边缘与遮挡处理。“删除”还必须声明被遮挡背景如何补全；“增加”必须声明尺度参照、接触阴影和进场方式；“替换”必须保持原运动、遮挡和接触关系；“属性修改”必须列出不得改变的其他属性。

### BGM 分离

写清：删除哪些音乐/背景声、保留哪些说话人、台词、环境音和画面文字。生成后比较人声可懂度、音色、相位、噪声和字幕保持性。

### 绿幕

写清绿幕颜色、覆盖时间、必须保留的主体和透明/半透明边缘。检查绿边、溢色、发丝、薄纱、运动模糊和阴影。

### 创意迁移

把参考拆成动作、节奏、镜头语言、情绪、构图和声音六种职责，只声明需要迁移的维度；人物脸、服装、字幕、水印、品牌和背景默认禁止迁移。

### 空间视角修改

明确原机位、新机位、旋转/平移方向、焦距变化、必须保持的几何锚点和允许外推的区域。输出属于生成式补画，不得称为真实场景恢复。

### 两视频补间

分别绑定 A 末端和 B 开端的角色、位置、速度、镜头方向、光线和音频；中间段只负责消除状态差。不得改写 A、B 已锁定内容。

### 多宫格分镜

每格声明固定编号、时间范围、景别、构图、镜头运动、人物动作和进入/离开状态。宫格图只控制可见构图和动作节点，不承担角色身份、产品结构或声音。
