# Accepted asset-prompt recipes

Only generic, zero-context prompt structures belong here. Do not add real
project IDs, people, products, reference media, provider run IDs, screenshots,
or paths from a local workspace. A recipe becomes a positive example only after
its asset has passed the intended Gate and its source material is cleared for
public reuse.

The canonical image-prompt structure still comes from the configured image
Skill. These recipes are Harness-level acceptance constraints, not a second
prompt author.
