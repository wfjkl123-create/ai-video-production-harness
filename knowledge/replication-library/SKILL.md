# 视频复刻库 · 使用入口

这是一个**备选库**，不是自动流程。按需取用，不要一次性加载全部卡片。

## 路由（先判断意图，再只读需要的卡）

1. **要整套复刻一条视频** → 读 `workflows/00-replication-backbone.md`（通用骨架），再按类型读对应 `workflows/0x`（TVC/UGC/穿搭/舞蹈/短剧/日系/复杂动作/大师镜头）。
2. **进入“复刻视频”** → 先读 `workflows/09-remake-control-router.md`，向用户提供“分镜图 / 深度视频 / 原视频 / KOC 复刻”四种方式。前三种可组合；KOC 复刻是独立端到端流程。选中分镜图或深度视频时，再读 `reverse-and-diagnose.md`（A 部分）并调用 `prompt-templates/09-reverse-storyboard-engineer.md`；只选原视频时跳过逆向；选择 KOC 时改读 `../../.agents/skills/koc-remake-orchestrator/SKILL.md`。
3. **人物假 / 要真人感诊断** → 读 `reverse-and-diagnose.md`（B 部分）+ `performance/` 对应卡。
4. **某一维度提示词**（打光/角度/站位/故事板/打斗/调色/优化）→ 读 `prompt-templates/` 对应卡。
5. **画面跳戏/衔接/越轴** → 读 `continuity/` 对应卡。
6. **做资产/图片质量** → 读 `image-assets/` 对应卡。
7. **带货文案/卖点痛点** → 读 `copywriting/`（不进视频生成流程）。
8. **不确定当前段该用白模、尾帧、分镜还是动作参考** → 读 `workflows/08-shot-strategy-router.md`，只加载命中的能力。
9. **爆款复刻假模宫格** → 读 `mannequin-grid-spec.md`（硬规则：逐秒宫格、假模置身原场景、多人颜色区分、纸片人禁止、局部重做）。
10. **段间尾帧交接** → 读 `tail-frame-handoff-spec.md`（硬规则：高清重建→曝光检查→细节检查→派生假模/高清图→独立登记）。
11. **资产图生成提示词模板**（人物四视图/妆造替换/表情九宫格/动作16宫格/场景九宫格/道具三视图/色板7色）→ 读 `../asset-prompt-templates.md`（含完整可复用提示词、工具路由、标注规范）。
12. **Seedance 2.5 / 多参 30 秒 / 超长 / 视频延长 / 智能或高级编辑 / BGM 分离 / 绿幕 / 白模 / 两视频补间 / 多宫格分镜** → 先读 `../seedance-2.5/README.md`，再按任务读 `../seedance-2.5/prompt-contracts.md` 与 `../seedance-2.5/harness-routing.md`。当前仅允许免费规划，模型别名未验证前禁止付费提交。
13. **原创剧情（约 1–2 分钟）** → 不调用复刻逆向模板；从原创需求访谈、概念提案、故事结构和脚本开始，再接入共用的资产账本、分段、提示词编译、审计、付费边界、最终剪辑与 Gate 5。

## 硬约束（取用任何模板都遵守）

- 当前已验证默认路线为竖屏 9:16、单段 ≤15 秒；只有命中 Seedance 2.5 专项路由并绑定独立 operation profile 时，才允许规划 16–30 秒、延长或超长模式。模型别名未验证前不得提交。
- 一致性靠**参考图绑定**，提示词**只写动**，不重复描述外观。
- 每个喂给模型的输入都要**显式声明职责**（图1场景、图2人物、视频1只参考动作）。

## 与 harness 衔接

- 倒推产物先形成源事实底稿与逆向提示词编译合同；经新商品/人物/场景权威资产对接和编译审核后，才能形成 `shot_narration` / `seedance_prompt`（见 `docs/superpowers/specs/2026-07-21-shot-narration-director-gate-design.md`）。
- 反复命中的避坑解法 → `rules` candidate（见 `harness-rules-candidates.md`）。
