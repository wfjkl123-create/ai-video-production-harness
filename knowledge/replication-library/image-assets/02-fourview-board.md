# 人物四视图定妆板（黄金母模板）

来源：《50万赞穿搭视频》《AI舞蹈复刻》等反复复用的四视图指令。
适用场景：稳定人物身份+服装的核心资产。只出一张正面全身图，脸占比小，视频里易脸崩/油亮/五官变，所以做四视图。

## 核心方法

一张定妆板 = 上1/3放正脸+侧脸特写（锁脸），下2/3放「正面放大服装图（裁掉头部）」+「背面完整全身图」（锁服装与身形）。皮肤保留毛孔/细纹/绒毛/碎发，不磨皮不塑料。表情平静自然。

## 可复用模板（完整）

```
生成图中人物的真人形象设定四视图，灰色摄影棚背景，专业真人角色定妆参考板，规整排版，干净简洁，
不是海报/杂志大片，不要剧情动作，不要复杂场景。
版式上下两部分：上1/3、下2/3。
上方：左=正面面部特写，右=侧面面部特写，均以头肩为主，清晰展示五官/骨骼/妆容/发型/头饰/神态。
  面部特征/发型/妆造/头饰必须与参考形象严格一致。皮肤真实自然，保留毛孔/细纹/绒毛/眉睫/碎发，
  不磨皮、不过度锐化、不做人像美容，高解析真人摄影棚定妆照质感。
下方：左=放大后的正面服装展示图，标准A-pose，人物尺度明显放大，从肩颈下方入画到鞋子，头部因放大被完整裁切出画面；
  完整保留双肩/双臂/双手/躯干/腰部/腿/鞋，只允许裁掉头部。禁止做成普通比例小全身图，禁止头部留在画面内。
右=背面完整全身图，标准A-pose，从头到鞋完整入镜，正常比例。
下方两张必须同一人物/同一服装/同一配饰/同一身体比例，超模修长但不夸张变形。
材质真实（布料褶皱垂坠、金属反光、皮革丝绸纱质）。若为开叉长裙，正面放大图可一条腿前迈半步展示开叉，但保持定妆姿态不走秀。
光线：摄影棚三点式（正左主光、正右辅助光、后右轮廓光），纯净灰背景，无彩色灯无强特效。
禁止：AI油腻感/塑料皮肤/过度美颜/廉价CG感/左右服装不一致/人物比例漂移。
```

双图分工版（人物图+服装图分别控制身份与穿着）见 `workflows/02-outfit-change-replication.md`。

用途标签：生成人物资产图（核心母模板）。

## 避坑点

- 左下正面放大图最易出错：模型爱做成普通小全身照或留半个头；提示词里反复强制「放大 + 完整裁掉头部」。

## 什么时候不该用

- 非人物资产。
