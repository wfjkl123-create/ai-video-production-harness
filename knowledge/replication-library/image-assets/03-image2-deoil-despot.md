# Image 2.0 去斑去油腻（画面变干净）

来源：《Image 2.0画面优化指南：解决斑点、油腻与纹理失控》。
适用场景：Image 2.0 构图空间强，但皮肤/服装/墙面/树叶易出细小斑点和油腻感。

## 核心方法（三处下手）

1. **提示词源头减斑**：加真实摄影/自然皮肤纹理类正向词，加斑点/油腻类负面词。
2. **参考图源头控斑**：选干净、低噪、纹理真实的参考图（垃圾参考带进斑点）。
3. **生成后二次优化**：用 Nano Banana Pro 对成图二次清理。
4. 组合成一套更稳定的 Image 2.0 生成流程。

## 可复用模板

```
正向：真实相机拍摄质感，自然皮肤纹理，保留真实毛孔与细腻纹理，干净通透，柔和均匀光。
负面：斑点，细小杂色颗粒，油腻感，塑料皮肤，蜡像感，过度锐化，纹理失控，脏污色块，过度磨皮。
二次优化：把成图交 Nano Banana Pro 做去斑去油腻二次生成。
```

用途标签：反推图片提示词 / 图片质量修复 / 真人感诊断。

## 避坑点

- 斑点常来自参考图本身；先换干净参考再谈提示词。
- 油腻=过曝高光+过度磨皮；负面词要点名。

## 什么时候不该用

- 非 Image 2.0 或本就要颗粒胶片质感时。
