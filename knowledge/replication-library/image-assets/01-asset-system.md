# AI 资产体系（画面稳定的地基，一图一责）

来源：《AI资产怎么做，画面才稳定？》。
适用场景：人物变脸、场景变乱、色彩不统一——根因常是没做资产，而非提示词不够。

## 核心方法（各资产只负责一件事）

| 资产 | 只负责 | 要点 |
|---|---|---|
| 人物资产（四视图/三视图） | 身份：脸/五官/骨骼/肤色/发型/身形/妆造 | 先让 AI 认清这个人是谁 |
| 妆造资产 | 同一角色的造型库（不是一套衣服） | 每套稳定复用的妆造单独建板 |
| 表情/动作资产 | 剧本需要的表情状态 | 只生成需要的 |
| 场景资产 | 空间结构/锚点/光源方向 | 不要只给一张好看空间图，要多视图 |
| 道具资产 | 重要道具外观/结构/材质 | 别让 AI 临时猜 |
| 色板资产 | 颜色角色与使用范围 | 不只是几块色，要说明颜色怎么用 |

最后一步：**把资产标注清楚交给视频模型**（图1人物、图2场景、图3道具，各自职责写明）。这与 harness 的 `responsibilityMap` / 一图一责完全同构。

## 可复用模板

```
喂视频模型前，为每个输入写职责：
图1=人物四视图（只锁身份，不控场景/动作）；
图2=场景图（只锁空间/光源，不控人物外观）；
图3=道具图（只锁道具外观）；
文字=只写时间顺序/动作/镜头/情绪（不重复描述外观）。
```

用途标签：生成人物/场景/道具资产 / 反推视频提示词。

## 避坑点

- 一张图同时控身份+调度+风格+构图=互相打架；一图一责。
- 一致性靠资产绑定，不靠提示词反复描述长相。

## 什么时候不该用

- 一次性单图，无复用需求。
