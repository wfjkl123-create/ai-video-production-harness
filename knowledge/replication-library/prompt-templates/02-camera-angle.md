# 镜头角度（电影感的真正开关）

来源：《镜头角度，才是AI画面的电影感开关》。
适用场景：写了一堆风格词还是一股 AI 味——因为没告诉 AI「镜头站在哪里看」。

## 核心方法

镜头角度决定观众与人物的关系：

- **平视**：观众与人物同高，真实亲近（最考验构图/光线/焦段，不能靠机位取巧）。
- **俯视**：人物被观察、被压住，表现处境/困境/紧张。
- **仰视**：放大气场，出场有压迫感和仪式感。

一个完整镜头角度提示词至少含**五个信息**：镜头角度 + 景别距离 + 焦段感 + 空间关系(前中后景) + 人物状态(在做什么/看向哪/情绪)。角度不能单独写，要和焦段一起写。

## 可复用模板

```
{平视/俯视/仰视}镜头，{远景/中景/近景/特写}，{广角/标准/长焦}，
前景{...}、中景{...}、背景{...}，
人物{正在做什么}，视线{看向哪}，情绪{...}。
```

用途标签：反推图片提示词 / 反推视频提示词 / 镜头语言。

## 避坑点

- 只写「电影感」→ AI 用默认审美补画面；写清机位位置/高度/与人物关系，AI 才按导演意图组织。

## 什么时候不该用

- 已用参考视频锁死运镜时，不必再文字硬写角度（会打架）。
