# 打光五法（画面真实感的第一开关）

来源：《AI画面想要真实，先学会这5种打光》《AI光影重构大师课》。
适用场景：画面「假、平、像生成图」时，多半不是人物问题，是没有光线逻辑。

## 核心方法

AI 画面假的常见根因是**光太平均**（脸、衣服、背景都一样亮，没重点没空间）。写光不要只写「电影感」，要写：光从哪来、照到哪、哪亮哪暗、边缘软硬、颜色冷暖。五种导演级光：

| 光型 | 光源位置 | 适用 |
|---|---|---|
| 侧逆光 | 人物侧后方 | 古风/情绪/出场，勾发丝金边、分离主体、出层次 |
| 轮廓光 | 人物正后方 | 暗背景里让人物跳出来 |
| 侧光 | 侧前方，一半亮一半暗 | 用明暗对比塑造人物情绪 |
| 硬光 | 定向强光（如穿百叶窗） | 商业广告、产品，出设计感 |
| 低位光 | 低于人物向上打 | 特殊氛围/戏剧感 |

## 可复用模板

完整打光逻辑（不是只写光效）：
```
【光线布置】{光型，如侧逆硬光}为主，光源在人物{方位}，打亮{头发边缘发丝光/侧脸轮廓}，
光比{大/中/小}，边缘{柔和/清晰}，色温{偏暖/偏冷}；
面部补光：正面漫反射补光提亮暗部，打出眼神光；
{可选：烟雾机营造体积光/神明光，让逆光在空气中形成可见光束，增加纵深}。
```

用途标签：反推图片提示词 / 反推视频提示词 / 镜头语言。

## 避坑点

- 只写「电影感/高级感/真实感」= 让 AI 用默认审美补光 = 一股 AI 味。
- 光要有方向/强弱/颜色/明暗过渡，人物是「被光塑造」不是「被照亮」。

## 什么时候不该用

- 需要均匀无阴影的纯电商白底产品图时，不上戏剧光。
