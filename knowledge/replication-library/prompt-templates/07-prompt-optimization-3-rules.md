# 提示词优化三大法则（告别无效指令）

来源：《告别无效指令：AI视频提示词优化的三大核心法则》。
适用场景：图生视频时提示词写了很多却不听话。

## 核心方法（三个错误 = 三条法则）

1. **别堆无用词、忽视首帧权重**：图生视频里首帧/视觉参照权重很高。提示词要服从首帧，别写一堆和首帧冲突的描述。
2. **别写冲突内容**：提示词内部自相矛盾会让 AI 逻辑摇摆（如又要「静止站立」又要「快速奔跑」）。
3. **别一次下太多指令**：同时塞太多动作，运动权重被无限稀释，每个都做不好。→ 一条提示词聚焦少量核心动作。

对应正向原则：**聚焦 > 完整**（followability > completeness），短而可跟随好过长而稀释。这条与 harness「提示词只写动、外观交参考图」一致。

## 可复用模板

```
首帧：{首帧画面描述，作为唯一起点}
核心动作（≤3个，按时间顺序）：1.{} 2.{} 3.{}
运镜：{一句}
负面：{与首帧/核心动作冲突的都写进负面}
```

用途标签：反推视频提示词 / 提示词优化。

## 避坑点

- 提示词越长≠越好；堆太长模型取平均、丢细节。
- 时间线要清晰，一次别下太多并列指令。

## 什么时候不该用

- 无（这是通用底层法则）。
