# 空间控制：视觉锚点标注法（画框+箭头锁站位）

来源：《玩转AI空间控制：告别人物乱放》《画几根线，也能让 AI 看懂你的画面》《用俯视调度图写 AI 视频提示词》。
适用场景：写满位置描述 AI 还是把人乱放；多人站位、走位、追逐、打斗、一镜到底。

## 核心方法

扩散模型对「空间绝对坐标」的文字信号很弱（注意力在特征匹配上），所以**用图像信号压过文字**：

1. **先造空镜**：不加人物，单生一张纯场景底图。
2. **人工标记**：在底图上用箭头/选框粗暴标出站位或轨迹。
3. **带图生成**：标记图 + 人物图一起喂，生成后要求去掉标记。

多人用**不同颜色**框区分身份（色彩隔离法）。三种参考图分清层级：**场景图**(这地方长啥样) < **站位图**(谁在哪) < **调度图**(怎么动+镜头怎么拍，含路线/方向/时间节点/机位)。静态画面用场景图够；追逐/打斗/长镜头必须上调度图。

## 可复用模板

单人锚点：
```
让图一的人物在图二标注位置{动作}，光影融合自然，与背景融合，随后去掉红框。
```
多人色彩隔离：
```
将图2角色坐在图1红框的沙发上，图3角色坐在图1绿框的椅子上，图4角色自然站在蓝框处，光影重构，最后去掉框。
```
俯视调度图组合视频提示词：场景资产(九宫格) + 俯视图标站位 + 画移动轨迹 + 标镜头路径 → 文字负责解释规则，图像负责提供空间依据。

用途标签：反推图片提示词 / 反推视频提示词 / 生成场景图 / 镜头语言。

## 避坑点

- 单靠文字写「从左往右跑」很容易被 AI 丢失/覆盖，图像锚点精准得多。
- 多人同色框会混淆，必须异色并在提示词里指明「哪个颜色代表谁」。

## 什么时候不该用

- 单人单点静态图，画框反而多余。
