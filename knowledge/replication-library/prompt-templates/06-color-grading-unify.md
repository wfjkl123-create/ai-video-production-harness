# 多段视频统一调色（色卡+全局摄影提示词+后期）

来源：《从参考图到统一调色：稳定多段 AI 视频的视觉风格》。
适用场景：十几个镜头连起来明显跳色（第一段偏暖、第二段发青、肤色忽明忽暗）。

## 核心方法

统一感来自**三道约束**，不能只在最后套滤镜：

1. **色彩基准（色卡）**：规定画面主要用哪些颜色、各颜色的角色和使用范围。
2. **摄影语言（全局提示词）**：规定光线/镜头/景深/质感/运动，所有镜头共用。
3. **后期校正**：把生成中不可避免的偏差拉回同一方向。

参考图不能只凭「好看」选：先读剧本判断情绪/场景/光线时间/品牌气质，再找接近的电影/广告静帧（ShotDeck、FilmGrab、Eyecandy 等按技法/影片查参考）。色卡不是滤镜，摄影提示词也不是万能参数，它们是「所有镜头共同遵守的视觉说明书」。

## 可复用模板

```
【色卡】主色：{}；辅色：{}；点缀色：{}；各色使用范围：{}。
【全局摄影提示词】光线：{方向/软硬/色温}；镜头：{焦段}；景深：{}；质感：{胶片颗粒/光学畸变}；运动：{}。
每个镜头生成时都粘贴以上两段，末尾再补该镜头独有的动作/情绪。
【后期】剪映里按色卡做统一校正，把各段拉回同一方向。
```

用途标签：反推视频提示词 / 镜头语言 / 后期。

## 避坑点

- 只靠最后一个滤镜救不了跳色，必须「生成前建基准、生成中复用、生成后校正」。

## 什么时候不该用

- 单段视频不涉及跨段统一。
