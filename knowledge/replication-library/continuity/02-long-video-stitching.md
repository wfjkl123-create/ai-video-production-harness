# 长视频衔接：别用首尾帧硬接（4 种方法）

来源：《别再用首尾帧硬接视频了，AI长视频其实要这样做》。
适用场景：≤15s 分段后，段与段拼接卡顿、变假、不连贯。

## 核心方法

首尾帧只解决**静态一致性**，没解决**运动连续性**——一张图记不住「人物刚怎么动、速度多少、重心在哪、下一秒往哪走」。四种更好的接法：

1. **用视频延续视频**：拿上一段的实际视频（末尾运动）当参考，而非只用一张末帧图。
2. **故事板拆段**：把长剧本用故事板拆成可生成片段，段间逻辑连贯。
3. **下一段开头重复上一段结尾情节**：制造重叠，剪辑时叠化过渡。
4. **剪辑藏问题**：实在接不上，用切镜/插入镜头把接缝藏掉。

> 与 harness 衔接：这正是 harness「交接图（handoff）」思路——读实际视频末几秒重建人物+机位空间关系，而非机械取末帧。

## 可复用模板

```
下一段起点 = 上一段的实际结尾运动（用上段视频当参考，不只用末帧图）。
提示词开头重述上段结尾状态：人物位置{}、朝向{}、正在进行的动作{}、运动趋势{}，
然后接本段新动作。
```

用途标签：反推视频提示词 / 段落衔接 / 后期。

## 避坑点

- 别只靠首尾帧硬接；运动连续性要靠「视频延续视频」+ 结尾状态重述。

## 什么时候不该用

- 单段 ≤15s 无需拼接。
