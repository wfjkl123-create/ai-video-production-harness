# 对话戏不越轴：一张图稳住正反打

来源：《AI对话戏老越轴？一张图稳住正反打》。
适用场景：对话戏人物左右乱跳（越轴/跳轴）。

## 核心方法

正反打=两人对话时在 A、B 之间来回切镜。越轴=镜头跨过两人连线（180 度轴线），导致人物左右关系翻转、观众错乱。解法是先用**站位图/正反打分镜草稿**固定 180 度轴线，让所有镜头都在轴线同一侧拍。流程：剧本 → 人物场景资产 → 人物站位图 → 正反打分镜草稿图 → 导演分镜+视频提示词 → 剪辑拼接时修正越轴。

## 可复用模板

```
建立站位图：A 在画面左、面朝右；B 在画面右、面朝左；标出 180 度轴线。
所有正反打镜头都从轴线同一侧拍：
- 拍A（过肩）：A 在画面{固定侧}，视线朝{固定方向}；
- 拍B（过肩）：B 在画面{相反固定侧}，视线朝{相反方向}；
两人的左右关系与视线方向在所有镜头中保持一致，不跨轴。
```

用途标签：反推视频提示词 / 生成分镜图 / 对话戏一致性。

## 避坑点

- 不固定轴线，AI 会随机把人物左右对调；先用站位图锁死再生成。

## 什么时候不该用

- 单人镜头、无对话。
