# 场景不穿帮 4 种方法（先锁空间再生成镜头）

来源：《AI 视频场景不穿帮：4 种保持环境一致的方法》。
适用场景：镜头一切场景就变。

## 核心方法（4 法）

1. **360 度环绕视频截图法**：让空间转一圈，截多角度帧当场景参考。
2. **俯视图 + 场景九宫格**：一张俯视空间地图 + 九宫格多视角，锁住结构。
3. **场景九宫格/俯视图 + 全能参考模式**：把空间参考喂进支持多参考的模型。
4. **720 度全景图法**：整屋全景，任意镜头都从同一空间取。

共性：**先锁定空间，再生成镜头**，让不同镜头看起来发生在同一个地方。

## 可复用模板

```
场景参考：{九宫格/俯视图/全景图}。
所有镜头都以此为唯一空间来源，保持门窗/家具/固定锚点/光源方向一致，
镜头切换时{人物移动路线}，不改变空间结构与背景元素。
```

用途标签：生成场景图 / 反推视频提示词 / 场景一致性。

## 避坑点

- 每镜单独生成场景 = 必跳戏；先建一份空间真相源再复用。

## 什么时候不该用

- 单镜头，无跨镜一致需求。
