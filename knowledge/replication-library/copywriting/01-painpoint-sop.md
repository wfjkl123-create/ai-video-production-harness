# 戳痛点 SOP（带货文案）

来源：《痛点戳不好，文案不扎心，用户不掏钱？》《痛点戳不好…一次性讲透》。
适用场景：收腹裤等带货脚本的卖点/痛点文案。**不进视频生成流程**，只作文案备选。

## 核心方法

底层逻辑：**无痛点，不成交**。痛点不痛→用户不想改变→无购买动机→不掏钱。SOP 骨架（去掉原文卖课引流后）：

1. **戳谁的痛点**：先锁定精准人群画像（谁买、谁用、谁做决定）。
2. **怎么戳（仅 2 个方向）**：① 放大「现状之苦」（不解决会怎样）② 放大「理想与现状的落差」（别人已经怎样）。
3. **深挖扎心痛点的管道**：从具体使用场景/身份/时间线里挖真痛点，告别泛泛的「伪痛点」。
4. **痛点挖掘模型**：围绕一个产品，穷举目标人群在「生理/情绪/社交/经济/时间」各维度的具体难受瞬间。

## 可复用模板

```
产品：{收腹裤}
人群画像：{年龄/身份/身材焦虑点/使用场景}
现状之苦（方向1）：{具体难受瞬间，如：产后小腹松弛，穿裙子显怀、被问是不是二胎}
理想落差（方向2）：{别人已达成的状态 vs 我现在}
真痛点（非伪痛点）：{绑定具体场景/时间/身份，不写"不好看"这种泛词}
一句扎心文案：{把真痛点写成用户自己心里那句话}
```

用途标签：带货文案 / 卖点提炼。

## 避坑点

- 「不好看/不方便」是伪痛点；真痛点要绑具体场景和身份。
- 原文大量卖课引流（万元私房课、看3遍就会）已剔除，只留方法。

## 什么时候不该用

- 视频镜头/画面提示词环节（这是文案层，不混入生成）。
