# 控制角色语气/语速/音色（声音结构化）

来源：《如何控制 AI 角色的语气、语速和音色？》。
适用场景：画面真实，人物一开口就假——语气平、音色不分、每个角色像同一个人。

## 核心方法

把「情绪词」改成「声音结构」。AI 对「愤怒地说」约束很弱（只描述了情绪结果），它更懂结构/节奏/停顿/发声方式：

- **音色**：不写身份，写声音特征（沙哑/清亮/低沉胸腔共鸣/鼻音）。
- **语气**：情绪是结果，写过程（气声起句、句尾上扬、咬字加重）。
- **多句台词**：按时间顺序写声音变化。
- **语速**：用标点当节奏器（逗号短停、省略号拖长、感叹加速）。

## 可复用模板

```
角色{身份}：音色{沙哑/清亮/低沉…}，发声{胸腔共鸣/气声…}；
这句台词：起句{气声/加重}，中段{语速}，句尾{上扬/下沉}；
用标点控制节奏：短停"，"、拖长"……"、加速"！"。
```

用途标签：反推视频提示词 / 声音设计 / 真人感诊断。

## 避坑点

- 只写「愤怒地说/悲伤地讲」约束太弱；写声音结构。

## 什么时候不该用

- 无台词/纯音效镜头（走 sound-design 铺底）。
