# 活人感三法则（告别塑料感/一眼假）

来源：《赋予AI角色"活人感"的3个核心提示词法则》。
适用场景：人物油腻、眼神空洞、表情僵硬，在恐怖谷边缘。

## 核心方法（三招）

1. **微表情 + 潜动作注入灵魂**：不写「一个男人在思考」，写具体生理细节与情绪流动/切换（不对称表情、手托下巴、眼神变化）。
2. **环境对抗打破摆拍感**：让动作和环境发生对抗（风吹乱头发、光尘飞舞、手扶栏杆），人物就「活」在一个真实瞬间里。
3. **局部光源 + 冷暖对比拒绝油腻**：不用平均光，用局部光源和冷暖对比塑造体积。

现在的「假」多是**状态的假**（不再是皮囊油腻），要靠状态细节救。

## 可复用模板

```
人物{身份}，{具体微表情，如：眉头轻蹙后又松开，视线从远处慢慢收回}，
{潜动作，如：手指无意识摩挲杯沿}，{环境对抗，如：穿堂风掀起衣角、光尘在逆光里浮动}，
局部光从{方位}打在{部位}，冷暖对比，皮肤保留真实毛孔与纹理，不磨皮不油腻。
```

用途标签：反推图片提示词 / 反推视频提示词 / 真人感诊断。

## 避坑点

- 别写「思考/开心」这种结果词，写生理细节与情绪流动。

## 什么时候不该用

- 纯产品图无人物。
