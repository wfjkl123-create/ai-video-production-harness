# 告别 NPC 感：三步重塑角色演技

来源：《告别"NPC感"：三步重塑AI视频角色演技》。
适用场景：角色像 NPC，情绪「用力过猛」或「面无表情流眼泪」。

## 核心方法（三位一体）

1. **微表情代替模板大表情**：写「happy/angry」会触发刻板印象权重（标准微笑/皱眉模板）。改写具体生理本能反应：
   - 紧张/恐惧 → 眨眼加快、瞳孔微缩、吞咽喉结微动。
   - 强忍情绪 → 眼神闪躲、眼眶微红但无泪、下颌肌肉瞬间紧绷。
   - 害羞/内敛 → 视线向右下游离、睫毛轻颤。
   并抓「情绪切换」的黄金瞬间（从A情绪切到B情绪）。
2. **肢体与小动作建立情绪因果**：情绪要有下意识动作支撑。
3. **环境音与细节声打破 MV 式静音感**：用环境音引导情绪代入。

## 可复用模板

```
{情绪}不要直写，改成：{生理本能反应，如眼眶微红但没有眼泪、下颌肌肉紧绷}，
伴随{下意识小动作}，从{情绪A}克制地切换到{情绪B}；
声音层：{环境音/细节声，如远处雨声、纸张摩擦声}。
```

用途标签：反推视频提示词 / 真人感诊断。

## 避坑点

- 情绪写成标签 = 触发模板 = NPC 感；写成微表情+切换。

## 什么时候不该用

- 无表演的静物/产品镜头。
