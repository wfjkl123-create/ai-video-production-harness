# 让人物「有事可做」（真人感的关键不是脸）

来源：《让AI人物更像真人的关键，不是脸，而是"有事可做"》《让AI短剧真正"活起来"》。
适用场景：脸做得很真，一做成视频还是一眼假——因为人物站太稳、没动机。

## 核心方法

图片只要一瞬间好看，视频要人物在几秒里持续真实。真人不会像雕塑停着：等车看手机、咖啡店转杯子、电梯看楼层、走路被风吹乱头发。核心：**不要只写人物长什么样，要写人物正在做什么、为什么这样做、动作如何自然持续**——动作要有**行为动机**。

让一个动作写出**三层动态**：主动作 + 身体联动（重心/手臂/裙摆/头发）+ 生命反应（呼吸/眼神）。多人戏：一个人行动，另一个人**反应**（用调度代替站桩念台词）。

## 可复用模板

单人公式：
```
人物{身份}正在{具体动作}，因为{动机}；
主动作：{}；身体联动：{重心前倾/手臂摆动/裙摆滞后/发丝晃动}；生命反应：{呼吸起伏/眼神移动/被风吹}。
```
多人：
```
A{行动，如推门进来走向B}；B{对A的反应，如抬头、身体后仰、视线跟随}；两人有距离变化和视线交流。
```

用途标签：反推视频提示词 / 真人感诊断。

## 避坑点

- 只堆脸部细节救不了视频假；动作没动机=僵硬。
- 对手戏别让两人站着念台词，用调度和反应。

## 什么时候不该用

- 纯静态定妆图。
