# 假模宫格制作规格（全局）

适用于所有爆款复刻项目（1:1 翻拍、一镜到底）。本规格是硬规则，不是建议。

## 1. 目的

将原视频逐秒切分为宫格图，把其中所有人物替换为体积化 3D 关节假模，作为视频生成的构图控制源。原视频帧永远只是分析证据，不得直接进入生成。

## 2. 宫格数量

按实际秒数决定：12 秒 = 12 格，15 秒 = 15 格。不固定 12 也不固定 15。每格对应原片 1 秒。

## 3. 假模外观

- 白灰色黏土/石膏质感的 3D 雕塑体，表面光滑连续，无可见关节分段。
- 像 ZBrush/Blender 的 clay render 效果，均匀浅灰白哑光，有柔和明暗过渡。
- 头部光滑椭圆形，完全无五官。头发简化为基础几何形状，同材质。
- 服装形状完整保留（轮廓、褶皱、垂坠），但渲染为同一种白灰黏土材质。
- **例外：被展示的产品本体保留真实外观。** 当宫格用于产品带货复刻时，产品（如收腹裤、内衣）必须按产品图保留真实颜色、纹理、结构与缝线，不转为黏土材质；产品以外的原片衣物一律替换为连续假模表面。
- 手部必须有清晰五指结构，不可简化为球体或连指手套。
- 身形比例参照目标人物，不做理想化拉长。
- 单人场景：统一白灰色黏土。
- 多人场景：每个人物用不同低饱和灰调区分（浅灰白/浅蓝灰/浅粉灰等），颜色绑定角色 ID。
- **必须完全看不出是真人，是完整的黏土雕塑假人。**
- 背景保留原场景但转为灰度/黑白版本，与假模色调统一。

## 4. 假模必须置身于原场景

- 保留原片的真实背景、光线方向、空间关系。
- 禁止使用中性灰底、纯白底或任何"抠图贴上去"的效果。
- 假模必须有环境光交互（接触阴影、环境反射），不得与背景分层。

## 5. 必须保留的信息（逐格核对）

| 维度 | 保留内容 |
|---|---|
| 摄影机 | 机位、角度、画幅、主体位置 |
| 景别 | 与该秒原帧一致 |
| 体态 | 重心、骨盆与肩线角度、脊柱倾斜 |
| 姿势 | 每个关节角度：肩、肘、腕、髋、膝、踝 |
| 手势 | 手指开合、捏握、指向方向、双手相对距离 |
| 接触关系 | 手与产品、手与身体、手与道具的接触点 |
| 遮挡 | 谁挡住谁、衣摆遮住产品多少、手臂遮住躯干多少 |
| 空间锚点 | 背景中家具、道具的位置关系 |
| 运镜 | 宫格整体必须与原视频的运镜大致相同 |

## 6. 必须清除的信息（逐格核对）

- 人物面部、发型、肤色、真实身份特征
- 原片服装的颜色与款式（交给人物图控制）
- 原片产品的偏色与低清纹理（产品外观以产品图为准；产品本体在格内保留，不清除）
- 原片人物身上除产品以外的一切衣物（吊带、开衫、镶边、肩带等），必须替换为与四肢同材质的连续假模表面
- 平台字幕、口播字幕、水印、账号名
- 原片场景的具体装修材质（交给场景图控制，但空间结构和光线方向保留）

## 7. 纸片人禁止（硬红线）

以下任何一种情况 = 废片，必须重做：

- 假模与背景明显分层，像"贴上去的"
- 没有体积感，看起来是平面剪影
- 没有环境光交互（无接触阴影、无环境反射）
- 边缘有白边、光晕或抠图痕迹
- 假模材质颜色在后续成片中被传递到真实人物或产品上

## 8. 局部重做规则

验收时逐格检查。合格的格保留，不合格的格单独拎出来重新生成，再拼回原图。不需要整张宫格重做。

局部重做流程：
1. 标记不合格格的编号和具体问题
2. 只重新生成该格（保持相同机位、景别、姿势要求）
3. 将新格拼回原宫格对应位置
4. 重新验收拼接后的完整宫格

### 逐格生成与拼接的执行约束

- **禁止整张宫格一次性编辑。** 把已拼好的宫格喂给图片模型做整体替换，模型会重排布局与姿势。必须逐格单图编辑，再用 ffmpeg 拼回。
- 无 ImageMagick 环境下用 ffmpeg `xstack` 拼 4×3：以 12 路输入配 `layout=0_0|w0_0|w0+w1_0|...`，末尾接 `scale` 控制审核图尺寸。
- 单格返修时，把**同批已通过的格**作为外观参照一并输入（原帧 + 已通过格 + 产品图），比只给原帧加文字描述更容易一次通过。
- 去衣物类返修禁止写「remove clothing / 去掉衣服」，会触发平台安全拦截并返回占位图。改为正向描述：「该区域替换为与手臂腿部相同的哑光灰白假模表面材质」。
- 失败格不得删除，改名保留为证据（如 `frame-04-failed-clothing-evidence.png`）。

## 9. 验收红线

任意一条不通过即该格 FAIL（触发局部重做）：

- 格数与源帧数不一致，或顺序错乱
- 某格姿势、手势或接触关系与源帧明显不符
- 假模手部缺指、粘连或呈球状
- 宫格中残留原片字幕、水印或产品痕迹
- 假模与背景分层（纸片人）
- 假模不在原场景中（灰底/白底）
- 多人场景未用颜色区分
- 运镜与原视频明显不一致
