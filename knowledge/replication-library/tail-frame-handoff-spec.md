# 尾帧交接规格（全局）

适用于所有爆款复刻项目（1:1 翻拍、一镜到底）中 `continuous_proxy_handoff` 策略的段间交接。本规格是硬规则。

## 1. 为什么禁止直接用尾帧

生成视频分辨率有限（480p / 720p）。截取尾帧 = 同等低清图片。拿低清图片当下一段首帧参考 → 模型生成更糊的画面 → 再截尾帧更糊 → 逐段退化循环。480p 项目退化更快，必须走完整派生流程。

此外，生成视频的尾帧可能携带：脸部漂移、服装错误、压缩噪点、生成伪影、曝光异常。这些污染会传递给下一段。

## 2. 尾帧交接必须经过的流程（缺一不可）

### 步骤 1：高清重建

将低清尾帧重建为规范高清（不低于原片分辨率），消除压缩噪点和生成伪影。

提示词必须同时写两件事：①锁死构图、机位、镜头角度、景别、透视、站位、朝向、手指与腿脚位置、服装、产品位置、背景结构逐像素不变，不改身份/发型/五官/表情；②只提升清晰度（皮肤质感、发丝、织物纤维、叶脉、景深），消除压缩块噪点与色带，禁止美颜磨皮、锐化光晕和明暗关系改动。

### 步骤 2：曝光检查

检查直方图：
- 不得有死黑（纯黑 clipping，RGB 0,0,0 大面积出现）
- 不得有死白（纯白 clipping，RGB 255,255,255 大面积出现）
- 曝光异常必须修复后才能进入下一步

### 步骤 3：细节完整性检查

逐区域检查以下细节是否因截帧/重建丢失：
- 发丝（边缘是否糊成一片）
- 面部纹理（皮肤质感、毛孔、细纹）
- 服装细节（布料纹理、缝线、褶皱）
- 产品细节（材质、光泽、结构）

丢失的细节必须补回。未补回不得进入下一步。

### 步骤 3b：字幕与水印清除（成片尾帧必做）

如果第一段成片带有原片字幕、平台水印或 AI 标记，尾帧派生图必须彻底清除，否则拼接后会出现「有字幕 → 无字幕」的落差。

- **禁止用 ffmpeg `delogo` 作为交付手段。** 实测会留下条纹涂抹痕迹，放大即可见。它只能用于快速定位问题区域。
- 用图片模型做局部无缝补全：明确指出待清除标记的位置，要求用周围同类内容（同一片叶脉走向、同一块石砖、同一片织物）补全，并显式禁止残影、色块、模糊斑与重复纹理。
- 大面积字幕/水印与角落小标记建议分两次处理：第一次随高清修复一起去主字幕与主水印，第二次单独清残留角标，避免一次改动过多导致画面漂移。
- 每次清除后必须裁切该区域放大复检，不得凭整图缩略图判定通过。

### 步骤 4：派生为交接图（二选一）

**方法 A（规范高清重建图）**：当身份、服装、产品状态都正确时，直接用修复后的高清图作为交接图。

**方法 B（假模替换图）**：将修复后的高清图中所有人物替换为体积化 3D 关节假模。
- 保留：机位、构图、站位、姿态、光影、遮挡、道具位置、空间关系
- 替换：人物完全变成假人（看不出是真人）
- 多人场景：不同人物用不同颜色区分
- 假模必须置身于原场景中（有环境光交互、接触阴影），禁止纸片人效果
- 假模外观遵循 `mannequin-grid-spec.md` 第 3 节

**首帧形态必须与前一段成片一致。** 方法 A 与方法 B 不可混用：若前一段成片是真人画面，交接图必须走方法 A（真人高清重建），下一段成片也是真人，假模宫格此时只作姿态时间表；若前一段成片是假模画面，交接图走方法 B。形态不一致会在拼接点第 0 帧产生跳变。

### 步骤 4b：放大到交付分辨率

清除完标记后按需放大（例如 `ffmpeg -vf "scale=2160:3840:flags=lanczos"` 得到 4K 竖幅首帧）。放大是最后一步，先修复清除再放大，顺序颠倒会把瑕疵一起放大。

### 步骤 5：独立登记与锁定

派生图必须有：
- 独立 SHA-256
- 单一职责声明（只传递机位/构图/姿态/空间，不传递身份/服装/产品外观）
- 污染审查（确认未继承原尾帧的模糊、漂移、错误、噪点、伪影）
- 锁定审核

## 3. 禁止事项

- 禁止把生成视频的原始尾帧直接作为下一段首帧
- 禁止跳过曝光检查或细节检查
- 禁止使用未修复的模糊/曝光异常图片
- 禁止假模与背景分层（纸片人）
- 禁止继承原尾帧的压缩噪点、脸部漂移、服装错误、生成伪影
- 禁止把尾帧交接图当作身份/服装/产品的控制源（它只传递空间信息）

## 4. 验收红线

任何一条不通过 = 该交接图不得进入下游，必须重做：

- 分辨率低于原片
- 直方图存在死黑或死白
- 发丝/面部/服装/产品细节明显丢失且未修复
- 假模与背景分层（纸片人）
- 假模不在原场景中
- 多人场景未用颜色区分
- 污染审查发现继承了原尾帧的错误
- 缺少独立 SHA 或职责声明
