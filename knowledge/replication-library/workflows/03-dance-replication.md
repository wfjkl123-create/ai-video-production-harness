# 舞蹈复刻流程（动作+镜头保留，人物场景全换）

来源：《AI舞蹈复刻教程：从参考视频到原创角色成片》。
适用场景：保留原视频的舞蹈动作、走位、卡点、运镜，把人物和场景换成原创。

## 核心方法（5 步）

1. **准备参考视频**：含可识别真人先用剪映跟踪打码。
2. **拆解结构**：丢给 ChatGPT/Gemini，明确要几个角色、分几段、每段谁在 C 位、几个配角、走位重点。
3. **设计原创角色**：为规避版权用原创角色（付费/商用尤其）；给整组角色一个统一主题（如「民国夜宴系列」）保证美术统一。
4. **角色定妆照 → Shot 覆盖身份包**：每个角色先定妆照，再按其实际舞蹈镜头中的脸向、身体方向、景别与遮挡补足最小身份视图；只有多方向、全身与近景均出现时才升级为四视图。
5. **场景图 + Seedance 生成**：参考视频(动作/运镜/卡点) + 已锁定的 Shot 覆盖人物身份包 + 场景图(环境) 一起喂，显式标注职责。

## 可复用模板

角色规划：
```
这是原视频，我要制作复刻教程。把人物场景全部替换，保持人物动作不变。
我需要{数量与构成，如：1个男主+4个女配作为第一段，6个男配作为第二段}。帮我想一下什么角色。
```

群舞生成（Seedance，注意资产编号）：
```
参考视频1的运镜、景别、镜头节奏、音乐卡点和舞蹈编排，使用图片2作为C位主角，完全替换原视频主角，
完全参考原视频的运镜与走位，{进出场描述}。高度还原原主角的全部舞蹈动作与节奏，但必须替换成图片2。
使用图片3/4/5...作为伴舞，匹配原视频伴舞的站位、队形变化和同步动作。
场景替换为图片1，空间真实有纵深。整体超写实影视质感，好莱坞歌舞大片镜头语言，动作丝滑，运镜稳定，精准卡点。
```

用途标签：复刻流程 / 反推视频提示词 / 生成人物资产图。

## 避坑点

- 多人时资产编号必须与提示词里的「图片N」严丝合缝，编号乱=人物串。
- 一个统一主题串起全组角色，避免每个角色美术风格打架。

## 什么时候不该用

- 单人无复杂走位的展示视频，不需要这么多角色资产。
