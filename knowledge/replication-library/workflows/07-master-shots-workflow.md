# 复刻大师镜头工作流（同一模特跑五种经典镜头）

来源：《用AI复刻大师镜头：从角色创建到电影感视频生成》。
适用场景：想要电影感的镜头语言（希区柯克变焦/迈克尔贝英雄镜头/库布里克对称/斯皮尔伯格跟拍/昆汀后备箱）。

## 核心方法（5 步）

1. **先建稳定主角**（不急着生视频）：一句气质描述 → 让 AI 扩成人物提示词 → Image2.0 出图 → NanoBanana Pro 出三视图。
2. **按人物气质设计环境**：让 AI 分析「这个模特适合什么环境氛围」，给一个统一色调方向（如雨后香港夜/青绿阴影+琥珀钠灯+少量红霓虹+湿地反光+35mm颗粒），五个镜头场景不同但色调统一。
3. **让 AI 理解镜头语言**（最关键）：不是只让它写提示词，而是把每种大师镜头的运镜逻辑讲清楚（希区柯克=纵深监控感、库布里克=对称压迫封闭）。
4. **整理成 Seedance 提示词**。
5. **人物+场景喂 Seedance 生成**。

## 可复用模板

电影感人物（Image2.0）核心结构：
```
纯白无缝背景，{年龄气质}亚洲年轻女性主角，超写实电影质感，Sony A7M4 + 85mm人像镜头质感，
精致鹅蛋脸/清晰柔和下颌线/挺直鼻梁/明亮有秘密感眼神，皮肤有真实毛孔与轻微纹理，
黑色中长发自然蓬松不遮五官，轻微电影感妆容，冷静神秘坚韧，三分之二侧身，头微转向镜头，
穿{服装}，电影级柔光+柔和眼神光+轻微轮廓光，真实光学质感，无文字无logo。
不要油腻/廉价性感/网红脸/过度磨皮/塑料皮肤/夸张浓妆。
```

统一色调环境（每个镜头场景变、色调不变）：
```
{场景}，港风电影写实质感，实景拍摄感。统一色调：青绿色阴影、琥珀色钠灯暖光、少量红色霓虹点缀，
低照度高反差，35mm胶片颗粒，轻微高光晕染，真实镜头光学质感。环境优先，不要人物特写，不要人群。
```

用途标签：原创流程 / 反推图片提示词 / 镜头语言。

## 避坑点

- 电影感不是堆风格词，是「讲清角色+场景+运镜」。
- 同一模特+统一色调，才能让不同镜头像同一部片。

## 什么时候不该用

- 带货UGC不需要大师镜头语言，反而会显得端着。
