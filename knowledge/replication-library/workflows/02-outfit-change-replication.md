# 穿搭 / 变装视频复刻流程

来源：《50万赞穿搭视频，如何用AI完整复刻？》《一键复刻爆款服装视频》。
适用场景：把一条穿搭/变装带货视频，用自己的人物+服装+场景重做。收腹裤带货可直接套。

## 核心方法（7 步）

1. **统一模特资产**：即梦灵感库搜「网感美女图」→做同款→图片5.0Pro；避开皮肤过滑/五官夸张/浓妆/明显AI感的形象。
2. **按 Shot 覆盖制作人物身份包**：先列出本片实际出现的脸部方向、景别、身体方向和服装展示面，再补足对应视图。只有当镜头同时需要正脸、侧脸、正面服装和背面全身时，才使用四宫格定妆板；单一正面全身图通常缺少近景身份信息，但也不应为了凑四格加入镜头不会用到的角度。
3. **提取开场服装**：截取能看清的画面 → 提取到白底图（开场紧身睡衣是钩子，反差越大越留人）。
4. **生成固定场景**：图生图出俯拍中景场景（不放整个客厅，人物活动区+部分沙发+少量背景即可，太大人物会显小）。
5. **提取多套服装**：每套提取到白底图（`提取画面中的一整套服装鞋子配饰至白底图上，只保留服装，不要人物`）。
6. **反推动作与快切结构**：参考视频丢给 Gemini/ChatGPT，逆向 Shot 表。
7. **Seedance 生成 + 剪映后期**：空场景图 + 已锁定的 Shot 覆盖人物身份包 + 参考视频 → 生成。

## 可复用模板

人物+服装合成定妆板（Image 2.0，双图严格分工）：
```
第一张参考图=人物参考图，只控制身份与外貌（脸型/三庭五眼/五官/骨骼/肤色/发型/发色/妆容/头饰/身材比例/气质）。
第二张参考图=服装参考图，控制最终穿着（款式/颜色/版型/领口/袖型/腰线/衣摆/开叉/布料层次/纹样/配饰/鞋子）。
最终人物保留第一张的身份，完整换穿第二张的服装。不保留人物参考图的原始服装，不混搭、不重新设计、不改服装颜色结构。
灰色摄影棚背景，上1/3放正脸+侧脸特写，下2/3放"正面放大服装图（完整裁掉头部）"+"背面完整全身图"。
皮肤保留毛孔/细纹/绒毛/碎发，不磨皮、不塑料感、不油腻。表情平静自然。
```
（完整长模板见 `image-assets/02-fourview-board.md`）

场景提取（图生图）：
```
以原图作为唯一空间与家具参考，保持装修风格/家具/材质/色调/灯光一致，不重新设计空间。
镜头{机位与角度，如：沙发正前方中央上方，约60度俯拍}，中景构图，聚焦{主体}，
画面不放下整个{空间}，允许两端自然出画，前景不要{杂物}，突出体积感与质感。
真实室内摄影，暖色自然光，35mm或50mm，无广角畸变，无人物，无文字。
```

穿搭展示视频（Seedance）：
```
你现在是一名专业AI视频导演。图1是场景，图2是依据本段 Shot 覆盖生成并锁定的人物身份包，视频1是动作参考。
请生成一条穿搭展示视频：人物脸型/五官/骨骼/肤色/发型/身材/气质严格锁定图2，不得混入视频1人物特征；
场景用图1；视频1只参考动作顺序/姿态/步伐/转身/手部/停顿节奏/运镜。
动作自然连贯，脚底真实落地，服装摆动自然，不穿模、不漂浮、不贴图感、不要一直看镜头。
禁止参考视频1人物脸部，禁止变脸/换装/换景/多人/肢体畸形/多余手指/脚底悬空/背景跳变/文字水印。
```

用途标签：复刻流程 / 生成人物资产图 / 生成场景图 / 反推视频提示词。

## 避坑点

- 只给正面全身图且本段包含脸部近景/转身 → 身份信息不足 → 视频里易脸崩、油亮或五官漂移。解决办法是补足缺失的近景与方向覆盖；是否形成四视图由 Shot 决定。
- 场景生太大 → 后期裁切放大人物区域。
- 即梦图片5.0Pro 更还原原图，NanoBanana Pro 更有自己想法；密集自然细节(树叶草地)用 NanoBanana 更稳，建筑门面/室内用 Image2.0。

## 什么时候不该用

- 无固定场景、纯产品特写的 TVC，用 `01-tvc-ugc-replication` 更省。
