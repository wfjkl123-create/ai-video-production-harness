# 日系预告短片工作流（先定影调再写剧本）

来源：《用AI做一支30秒日系预告短片，我是这样完成的》。
适用场景：有明确影调追求的短片/预告（治愈系、日系、某摄影师风格）。

## 核心方法（7 步）

1. **确定视觉风格**：选一个参考摄影师（如濱田英明），让大模型分三步提炼——① 总结共性 ② 分析「不可变条件」 ③ 整合成「空间与构图 / 光线与氛围 / 色彩与质感 / 限制与规则」四板块。
2. **生成剧本**：用编剧 skill，把四板块喂进去生成 30 秒剧本。
3. **先生成场景（不是人物）**：剧本拆场景，每场用 Image2.0 出四宫格，挑最接近气质的一张。
4. **制作男女主角**：脸部三视图 + 服装三视图 + 服装设计图。
5. **合成分镜图**：人物+场景+道具合成。
6. **生成视频**。
7. **剪辑拼接**。

## 可复用模板

影调三步提炼：
```
① 帮我总结这几张图的风格与影调的共性。
② 帮我分析这几张图的风格，告诉我生成时有哪些不可变的条件。
③ 帮我把上面内容整合成四个板块：空间与构图、光线与氛围、色彩与质感、限制与规则。
```

场景四宫格（Image2.0，把四板块规则塞进提示词）：
```
你是专业摄影师，依据指南设计四个{场景}，超写实，电影感日系胶片风格，纯净画面，氛围感拉满，逆光，2x2网格，不要人物，不要字幕。
{粘贴：空间与构图 / 光线与氛围 / 色彩与质感 / 限制与规则 四板块全文}
```
挑图标准：构图干净 / 光线自然 / 颜色统一 / 适合放人物 / 无杂乱元素 / 符合目标气质。

用途标签：复刻流程 / 反推图片提示词 / 生成场景图。

## 避坑点

- 「不可变条件」这一步是关键：把风格拆成硬约束（高明度/低饱和/纯自然光/大留白/禁止纯黑），后面每张图都遵守才不跳。

## 什么时候不该用

- 无风格追求的普通带货，不需要这么重的影调前置。
