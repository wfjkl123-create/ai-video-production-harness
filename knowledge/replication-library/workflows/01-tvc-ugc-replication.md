# TVC / UGC 复刻流程

来源：《AI视频复刻全攻略：轻松搞定TVC与UGC》《一键复刻爆款服装视频》。
适用场景：把一条带货爆款（美妆TVC / 宠物UGC / 产品口播）换成自家产品重做。

## 核心方法（两条路线）

**TVC 型（整版产品替换，靠分镜长图）：**

1. 参考视频导入剪映，用「智能镜头分割」切分镜，导出每段**首帧**。
2. 首帧按播放顺序拼成一张「分镜长图」。
3. 分镜长图 + 新产品图 → GPT Image 2.0，整版替换产品并标镜号。
4. 提取原视频背景音频（控制在 15s 内）。
5. 分镜图 + 新产品图 + 音频 → Seedance，按分镜顺序生成、卡原节奏。

**UGC 型（主体+产品替换，靠逆向脚本）：**

1. 同样分镜、替换产品与主体（人/宠物），瑕疵用局部重绘圈选修。
2. 用「短视频裂变前置逆向工程师」指令逆向出结构化 Shot 表（见 `prompt-templates/09-reverse-storyboard-engineer.md`）。
3. 把 Shot 表按 ≤15s 拆两段，分别喂 Seedance。

## 可复用模板

整版产品替换（GPT Image 2.0）：
```
将图1（分镜图）中所有分镜里的{原产品}，替换成图2（新产品）的{品类}。
请务必还原图2{瓶身/包装}的特征，并调整图1的整体环境氛围和色彩，使其与图2的产品色调相匹配。
最后按顺序在每个分镜左上角标上镜号，例如"分镜1、分镜2、分镜3..."。
```

局部瑕疵图生图：
```
将分镜{N}中红圈的{物体}{要做的修改，如：反过来，液体从白色盖子口倒出}。
```

Seedance 生成前置：
```
图1是视频分镜，按照分镜顺序生成视频。图2是产品。
```

用途标签：反推视频提示词 / 反推图片提示词。

## 避坑点

- Seedance 只出 ≤15s，音频与分镜都要先按 15s 切好再喂。
- 产品替换要「还原新产品的结构特征 + 把环境色调也往新产品调」，否则产品浮在旧色调里很假。

## 什么时候不该用

- 需要人物连续表演/多镜头对手戏时，TVC 的「分镜长图整版替换」不够，改用穿搭/短剧流程的资产体系。
