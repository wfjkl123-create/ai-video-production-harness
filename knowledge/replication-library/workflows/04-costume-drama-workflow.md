# 女频古风短剧工作流（人物/场景/光效/声音全统一）

来源：《我用 AI 做了一部女频古风短剧，关键不是提示词，而是这套工作流》。
适用场景：多镜头连续叙事短剧，最怕「单张好看、一剪就散」。

## 核心方法（7 步）

1. **先拆画面质感（不是抄剧情）**：截参考短剧 2 帧，让大模型从摄影师+后期师角度拆成「光线/风格/参数/负面词/画面处理」，产出全片统一视觉基准。
2. **先做人物系统（不是一张图）**：分步搭——服装三视图 → 服装细节图 → 发型发饰 → 面部三视图 → 合成完整人物参考图 → 胸像三视图 + 全身三视图。
3. **场景九宫格**：让环境不要每镜都变。
4. **生成剧本**：女频开头先抓情绪。
5. **拆分镜**：每 15 秒一个段落。
6. **正式生成**：把光效+人物+场景+分镜合在一起，控制声音一致性。
7. **后期**：顺序拼接 + 统一梦幻辉光。

## 可复用模板

画面质感逆向（拆参考帧）：
```
请从专业摄影师和后期师的角度，分析这张图片是如何拍摄和处理的，重点分析：
1.拍摄设备与参数（相机/焦段/光圈/快门/ISO/白平衡/景深/透视）
2.光线与布光（主光/补光/轮廓光/环境光的位置方向强弱软硬，柔光箱/反光板/自然光）
3.人物与场景（妆容/发型/服装/姿势/角度/机位高度/构图/背景/天气）
4.色彩与后期（色彩风格/冷暖/对比度/肤色/调色/磨皮/锐化/颗粒/暗角）
5.复刻方案（可执行的设备/参数/灯光/妆造/构图/后期调色方向）
```
然后把结果压成可复用基准：
```
从以下角度分析并提取核心：【光线布置】【风格】【拍摄参数】【负面提示词】【画面处理】【人物妆容+服饰】
```

人物系统合成（分步，NanoBanana Pro）：
```
服装三视图：生成这套衣服/袜子/鞋子的三视图，干净的黑色无头全身人体模特，黑底电商风，光影感超强，超写实，1x3网格。
发型发饰：提取这张画面的人物发型以及头饰，人物用假人代替。
面部三视图：生成脸部的三视图，规划3个不同角度的脸部特写（正/侧/半侧），白底电商风，超写实。
合成：图3是服装，图1是发饰发型，图2是面部三视图（只参考面部不参考发型），把元素自然融合成一张45度人物面部特写，白底图。
```

用途标签：复刻流程 / 生成人物资产图 / 反推图片提示词。

## 避坑点

- 短剧崩的不是单图，是「视觉体系不统一」；第一步就把光/色/后期锁死。
- 人物系统分步搭比一张图稳得多——服装/发饰/脸各自锁定后再合成。

## 什么时候不该用

- 单镜头/单段展示，不需要九宫格与人物系统这么重。
