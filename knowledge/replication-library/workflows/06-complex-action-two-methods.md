# 复杂动作视频（两种方法：原创分镜法 / 视频参考法）

来源：《用 AI 做复杂动作视频：从分镜到成片的两种方法》。
适用场景：篮球、打斗、舞蹈等复杂连贯动作。

## 核心方法

**方法一 · 原创分镜法（原创度高，前期重）：**
1. 建人物形象 + 场景（可指定电影/动漫视觉风格）。
2. 用提示词生成一套 **12 宫格黑白分镜图**（每格含镜头/动作步骤/动作轨迹线/中文说明）。
3. 把分镜图交 AI 转成 Seedance 视频提示词（逐镜动作流程 + 关键控制）。
4. 人物+场景+提示词喂 Seedance，多次生成挑片拼接。

**方法二 · 视频参考法（更直接）：**
把参考视频+人物图+场景图一起喂 Seedance，提示词强调「替换人物/场景 + 锁死视觉风格」。

## 可复用模板

12宫格分镜扩写：
```
我想做一组【{动作}】的故事板/分镜图，用于视频分镜，风格参考【{风格}】，主角是【图1】，场景是【{场景}】，
采用【12宫格】布局，动作包括【{动作要点}】，希望有动作轨迹和步骤说明。
请帮我自动扩写成专业AI绘图提示词，补全镜头/光影/构图/动作衔接/材质/色调/信息图元素，画面是黑白素描手稿。
```
关键：给出**明确动作路线**（如「从三分线启动→推进→变向突破→两步上篮→擦板→入网→落地」），并逐格写景别+动作。

分镜转视频提示词：
```
根据这张《{动作}分镜图》，帮我生成适合 Seedance 2.0 的视频提示词。要求动感十足、动作连贯、符合逻辑。
风格严格参考：{视觉风格与细节，如 Spider-Verse：网点/Ben-Day dots/色散/Step-printing/Squash and Stretch}。
```

视频参考法一句话替换：
```
将视频1中的人物替换成图1人物，场景替换成图2，参考图2的强烈视觉风格{风格全文}。
```

用途标签：原创流程 / 反推视频提示词 / 生成分镜图。

## 避坑点

- 复杂动作必须给「动作路线」硬约束，否则人物绕场乱跑、跳投变上篮。
- 分镜图与视频提示词要一一对应（镜头一对镜头一），别只丢分镜图配两句剧情。
- 两方法取舍：原创分镜法原创度高但慢；视频参考法快但受参考视频约束。

## 什么时候不该用

- 简单静态展示，用不上 12 宫格分镜。
