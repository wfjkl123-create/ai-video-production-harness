# 假模宫格生成提示词（完整工作流）

> 触发条件：爆款复刻项目，需要从原视频提取宫格并替换人物为假模时。
> 与 mannequin-grid-spec.md 配合使用：那个管验收标准，这个管怎么生成。

## 完整工作流

```
原视频 → 逐秒截帧 → 排列成宫格 → 用提示词替换人物为假模 → 验收 → 局部重做
```

## 步骤 1：截帧

用 ffmpeg 从原视频每秒截取 1 帧：
```bash
ffmpeg -i input.mp4 -vf "fps=1" -q:v 2 frame_%03d.jpg
```
15 秒视频 = 15 帧。按时间顺序编号。

## 步骤 2：排列宫格

将截帧按顺序排列为宫格图（如 3×4、3×5、4×4 取决于帧数）。
可用 Python PIL 或让 image2.0 直接处理。

## 步骤 3：生成假模宫格（核心提示词）

### 单人场景提示词

**工具**：image2.0（输入原宫格图）

```
将图中所有人物（包括其穿着的服装和配饰）全部替换为白灰色黏土雕塑质感的3D假模。
背景保留原场景，但转为灰度/黑白版本。整体画面呈现统一的灰白色调黏土渲染风格。

假模规格：
- 表面光滑连续的白灰色黏土/石膏材质，像ZBrush或Blender的clay render效果
- 表面无可见关节分段、无球状关节连接，整体是一个连续光滑的雕塑体
- 材质为均匀的浅灰白色哑光，有柔和的明暗过渡和体积感，不是纯白也不是深灰
- 头部为光滑椭圆形，完全无五官（无眼睛、无嘴巴、无鼻子、无眉毛）
- 头发简化为基础几何形状（丸子头=球形、短发=贴合头部的弧形块），同材质同色调
- 服装形状完整保留（衣服的轮廓、褶皱、垂坠、层次都保留），但服装也渲染为同一种白灰黏土材质，不保留原服装的颜色、花纹、图案
- 手部必须有清晰的五指结构，每根手指形态自然，不可简化为球体或连指手套
- 身形比例与原图中人物一致，不做理想化拉长或缩短
- 鞋子/脚部也渲染为同材质，保留鞋型轮廓

姿势保留（逐格严格执行）：
- 每格假模的姿势必须与该格原图中人物的姿势完全一致
- 保留：重心位置、骨盆与肩线角度、脊柱倾斜方向
- 保留：每个关节角度（肩、肘、腕、髋、膝、踝）
- 保留：手指开合状态、捏握动作、指向方向、双手相对距离
- 保留：手与产品、手与身体、手与道具的接触关系
- 保留：人物之间的遮挡关系

背景处理：
- 背景保留原场景的空间结构、家具、道具、墙面、地面
- 背景转为灰度/去色版本，与假模的白灰色调统一
- 保留原场景的光线方向和明暗关系（不是平光，要有光影层次）
- 假模必须有环境光交互：接触阴影（脚底、手与物体接触处）、柔和投影
- 假模表面必须受到场景光源影响，有自然的明暗变化

禁止：
- 禁止：纯白底、纯灰底、任何脱离原场景的背景
- 禁止：假模与背景分层、边缘白边、光晕、抠图痕迹
- 禁止：纸片人效果（无体积感、平面剪影感）
- 禁止：假模表面出现彩色（单人场景下全部为白灰色）
- 禁止：保留原片人物的任何面部特征、肤色、真实发型细节
- 禁止：保留原片服装的颜色、花纹、品牌logo
- 禁止：保留平台字幕、水印、账号名

运镜一致性：
- 宫格整体的机位变化、景别变化必须与原视频一致
- 如果原视频有推拉摇移，宫格中每格的视角必须体现这个变化

画面质量：
- 整体像一张3D黏土渲染图（clay render），不是照片也不是插画
- 光线柔和均匀，像摄影棚柔光箱打光
- 假模有真实的体积感和重量感，不是轻飘飘的
```

### 多人场景提示词（在单人基础上追加）

> **编译顺序硬规则（2026-07-30 实证修正）**：多人格必须把本节的身份色规则写在提示词**最前面**，并冠以「最高优先级规则」，再接单人基础模板。
> 若沿用「基础模板在前、身份色追加在后」的顺序，模型会让开头连续三句「白灰色黏土 / 统一灰白色调」覆盖身份色，实测饱和度均值仅 1.67/255，等于全灰。
> 同时必须把否定项改写为「禁止把多个人物渲染成相同颜色」，不要只依赖基础模板第 65 行括号里的「单人场景下」限定词——该限定词在实际调用中会被忽略。
> 实证证据：`projects/white-mens-underwear-remake-001/preproduction/assets-v1/generated/mannequin-frames/segment-001/`，失败三版为 `frame-0.000-failed-color-evidence-v1~v3.png`，成功版为 `frame-0.000-v1.png`（女性区 #7A7F85 蓝调、男性区 #C1B7B0 暖灰）。

```
多人颜色区分规则：
- 每个人物用不同色调的黏土假模区分
- 人物1：浅灰白色黏土（默认色）
- 人物2：浅蓝灰色黏土
- 人物3：浅粉灰色黏土
- 人物4：浅绿灰色黏土
- （按实际人数递增，色调不重复，但都保持低饱和灰调，不要鲜艳颜色）
- 每格中同一人物的颜色必须一致（人物1在所有格中都是浅灰白色）
- 颜色只改变假模表面材质色调，不改变光滑质感、比例和光照逻辑
```

## 步骤 4：验收

按 mannequin-grid-spec.md 第 9 节逐格检查。

## 步骤 5：局部重做（只重做不合格的格）

如果某几格有问题，不要整张重做。单独拎出来重新生成：

```
将图中人物替换为体积化3D关节假模。[同上述完整规格]

本格特别要求：
- 本格对应原视频第[X]秒
- 上一格假模姿势为[描述]，本格需要承接其运动趋势
- 本格重点修正：[具体问题，如"右手应与产品接触""假模应有接触阴影"]
```

生成后将合格格拼回原宫格对应位置。

## 禁止事项（生成时）

- 禁止自己编写假模提示词，必须使用本文件模板
- 禁止把原视频帧直接喂给视频模型（原帧只是分析证据）
- 禁止整张宫格重做（只重做不合格的格）
- 禁止使用"mannequin""dummy"等英文词（模型可能理解为服装店展示人偶），用"白灰色黏土假模"
- 禁止在提示词中描述原片人物的外观（面部/服装/肤色），这些是要清除的信息
- 禁止假模出现可见关节球或分段结构（参考图是光滑连续的）
- 禁止背景保留彩色（必须转灰度，与假模色调统一）
