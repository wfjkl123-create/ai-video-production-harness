# 俯视调度图（复杂镜头分支）

> 触发条件：镜头涉及多人走位、追逐、打斗、一镜到底、复杂转场时自动启用。
> 简单对话、静态特写、单人动作不需要。

## 三种图的层级

| 类型 | 回答的问题 | 何时用 |
|------|-----------|--------|
| 场景参考图 | 这个地方长什么样 | 所有项目（已有） |
| 站位图 | 谁在哪里 | 多人镜头 |
| 调度图 | 接下来怎么动、镜头怎么拍 | 复杂动作/一镜到底/追逐/打斗 |

## 调度图包含什么

从天花板往下看的空间地图：
1. 场景结构（墙、门、窗、家具、障碍物）
2. 人物初始位置（编号标注）
3. 移动轨迹（箭头 + 时间节点）
4. 道具/障碍位置
5. 摄影机路径（机位、运动方向、起止点）

## 生成方法

用已验证的图片模型生成。以下两个模板必须先按 `knowledge/asset-prompt-templates.md` 的“生成式 AI 首轮上下文合同”完整填充；不得把方括号、前文指代或未绑定的参考媒体交给生成模型。

### 模板 A：站位图（只回答“谁在哪里”）

```text
【任务】为《[项目名称]》的[场景名称/时间段]生成一张 16:9 横版、严格垂直俯视的电影站位图。本图只记录一个明确时刻的静态位置，不表现后续移动。

【输入绑定】
[无输入媒体时：本任务不使用任何图片作为输入，空间和人物位置完全由以下文字定义。]
[有输入媒体时：逐项写 Image1、Image2 的角色、允许提取内容和禁止迁移内容。]

【空间结构】
[用可复算的相对位置完整描述墙、入口、出口、门、窗、泳池边线、长椅、桌椅、关键道具和障碍物。必须说明画面上/下/左/右分别对应空间的哪个方向。]

【人物静态位置】
- P1 = [角色身份]；位于[相对哪个固定物、距离/朝向]；身体朝向[方向]。
- P2 = [角色身份]；位于[相对哪个固定物、距离/朝向]；身体朝向[方向]。
[按实际人数继续，不增加未定义人物。]

【摄影机静态机位】
- C1 = [机位相对位置]；镜头朝向[方向]；对应[景别]。

【视觉规范】建筑平面图与电影预演图结合，浅灰底，深灰空间线，人物使用高对比圆形编号 P1/P2，摄影机使用蓝色 C1 图标；线条简洁、比例关系清楚、图例放在右下角。只允许简短的拉丁字母和数字编号，禁止长段文字。

【严格禁止】移动箭头、人物路径、摄影机路径、起止点、透视图、斜俯视、人物写实渲染、脸、手、产品广告、装饰性插画、中文乱码、logo、水印、字幕、未定义人物或物体。

【验收条件】必须为严格 90 度垂直俯视；全部固定物和 P/C 编号位置与定义一致；没有任何运动箭头；图例能唯一对应每个编号；空间关系一眼可读。
```

### 模板 B：调度图（回答“怎么动、镜头怎么拍”）

```
【任务】为《[项目名称]》的[场景名称/精确时间段]生成一张 16:9 横版、严格垂直俯视的电影调度图，用于固定人物移动和摄影机运动。

【输入绑定】
[无输入媒体时：本任务不使用任何图片作为输入，空间、动作和机位完全由以下文字定义。]
[有输入媒体时：逐项写 Image1、Image2 的角色、允许提取内容和禁止迁移内容。]

【空间结构】
[完整描述固定空间，说明画面方向；必须与同场景站位图使用同一套固定物和编号。]

【人物与时间节点】
- P1 = [角色身份]；T0 位于[位置/朝向]；沿红色实线箭头经过 T1 [位置/动作]，到 T2 [终点/朝向]。
- P2 = [角色身份]；T0 位于……
[每位有运动的人物逐项写清；静止人物明确写“全程停留在……”]

【摄影机路径】
- C1 = [起始机位和朝向]；沿蓝色虚线箭头移动到 C2 [结束机位和朝向]；对应镜头运动为[推/拉/横移/跟拍/环绕]。

【视觉规范】建筑平面图与电影预演图结合，浅灰底，深灰空间线；人物用高对比圆形 P 编号；人物轨迹只用红色实线箭头，摄影机轨迹只用蓝色虚线箭头；T0/T1/T2 与 C1/C2 标记清楚；图例放在右下角。只允许简短的拉丁字母和数字编号，禁止长段文字。

【严格禁止】透视图、斜俯视、写实人物、脸、手、运动残影、未定义路径、方向含糊、轨迹互相覆盖到无法辨认、中文乱码、logo、水印、字幕、未定义人物或物体。

【验收条件】必须为严格 90 度垂直俯视；固定物与同场景站位图一致；每个人物的起点、节点、终点和箭头连续可读；摄影机路径与人物路径用不同颜色和线型；所有编号唯一且图例可复核。
```

### 站位图与调度图不得合并偷懒

- 站位图是某一时刻的静态事实，禁止出现运动箭头。
- 调度图是在同一空间底图上增加时间节点与轨迹，必须能回溯到站位图的 T0。
- 同一场景需要两种图时，空间固定物、方向约定、人物编号和摄影机编号必须完全一致。

## 与提示词的组合

调度图作为参考图喂给模型时，标注为：
"这张图是本镜头的空间调度参考，用来确定人物位置、移动方向和摄影机路径。画面中的人物位置和运动轨迹必须与调度图一致。"

## 判断阈值

以下任一条件命中 → 必须生成调度图：
- 画面内同时有 3 个以上人物且有相对运动
- 一镜到底超过 8 秒且涉及空间位移
- 追逐/打斗/围攻/逃跑
- 镜头运动与人物运动方向相反或交叉
- 用户明确要求"一镜到底"或"长镜头"
