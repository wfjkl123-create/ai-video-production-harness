# DLC：日系/氛围短片

> 触发条件：项目类型为"日系短片""氛围向""预告片""MV风格""重美术轻剧情"

## 与主流程的差异

日系/氛围短片**重美术、重情绪、轻剧情**。镜头节奏偏慢，大量空镜、特写、慢动作。不需要复杂分镜，但需要极强的视觉统一感。

## 全局视觉基准偏移

日系风格的全局视觉基准与默认不同，门1 时确认：

```
画面风格：日系电影 / 岩井俊二 / 是枝裕和 / 新海诚（选一）
色彩方向：低对比、微过曝、偏青绿或偏暖黄、肤色通透
光线逻辑：自然光为主、逆光/侧逆光、光斑溢出、空气感
画质锚点：轻微过曝、柔焦边缘、胶片颗粒、浅景深
节奏：慢，单镜头 3-5 秒，大量留白
禁止项：高对比、硬光、HDR、锐利数码感、快切
```

## 额外步骤

### 资产阶段

- 场景资产比重 > 人物资产（空镜多）
- 色板必须从 3-5 张同风格电影截图提取（不能用单张）
- 额外生成"氛围参考板"：3-4 张目标情绪的画面（不是分镜，是情绪锚定）

### 提示词阶段

- 大量使用环境描写（风、光、声音、温度感）
- 人物动作极简（"她转头看向窗外"而不是复杂动作序列）
- 镜头以固定/缓慢推拉为主
- 每段提示词开头嵌入氛围关键词（"安静的""透明的""呼吸感"）

### 生成阶段

- 每段生成后重点检查：色调是否统一、有没有突然变锐/变硬、光斑是否自然
- 空镜和人物镜头交替生成，避免连续多段同类型
