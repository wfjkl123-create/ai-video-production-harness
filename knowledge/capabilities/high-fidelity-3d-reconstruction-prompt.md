# 高精度三维还原提示词合同

## 0. 目的与真实边界

本合同用于把一个已绑定的源视频重建成可审查的高精度三维预演（`.blend` + 渲染 animatic），而不是把原片逐帧套成低精度白灰假模。

它的目标是：**人物和核心产品的可见几何、轮廓、材质与接触细节优先；场景只保留支撑摄影机、透视、遮挡、接触阴影所需的精度；镜头、构图、光向与运镜逐 Shot 对齐。**

一条文字提示词不能从单一低清视频凭空恢复被遮挡的身体、背面、纹理或产品结构。源片中不可观察的信息必须标为 `inferred`，不允许把猜测写成“严格还原”。源片分辨率、运动模糊、遮挡、镜外部分和剪辑断点决定可验证精度上限。

本文件是给**可读取绑定媒体、可运行 Blender 或等价三维运行时的建模 Agent**的构造提示词包；它不是 Seedance/即梦最终成片提示词。最终视频提示词仍必须由唯一授权的 `seedance2-prompt-skill` 编写，并重新绑定 canonical 人物、产品、服装和场景资产。

## 1. 启用条件与产物

当用户要求“高精度 3D 建模视频”“人物手指、发型、衣褶都要看清”“核心产品和道具必须精细”“高精度还原原视频”时，在 `modeling_strong_control` 内加载本合同。

每个生成单元必须输出：

1. 一个 `.blend` 工程：包含按 Shot 切换的摄影机、角色高精度可见区域、核心产品、接触与运动；
2. 一个完整渲染 animatic：不是截帧拼接，不允许只有静态姿势；
3. 至少五张同机位派生关键帧：起始、触发、接触/关键动作、对方反应、结束；
4. `source-to-model` 对照表：每项列出源视频时码、可观察证据、建模结果和 `observed | inferred`；
5. 一份独立的自检报告。报告不得混入实际执行提示词。

## 2. 精度预算（必须先锁定）

| 层级 | 必须重建 | 可以简化 | 绝对禁止 |
|---|---|---|---|
| 人物 | 头部与发型轮廓、脸部中性几何、颈肩比例、手掌与五指、每段关节姿态、可见皮肤褶皱、服装剪裁/缝线/褶皱/可见织纹 | 不在镜头内的背面细节，只能标 `inferred` | 球形关节、手套手、合并手指、无脸椭圆头、塑料光滑衣服、低多边形躯干 |
| 核心产品/道具 | 整体轮廓、比例、开合/接口/缝线、材料分区、可见表面纹理、与手或身体的接触变形 | 画面外、被完全遮挡的内部结构 | 用立方体代替产品、擅自编造可读文字/Logo、用原片压缩纹理糊弄细节 |
| 场景 | 地面、墙面、门窗、桌椅等影响透视/接触/遮挡/反射的几何和光源方向 | 远景小物、不可见纹理、非叙事装饰 | 让简化场景破坏人物比例、产品尺度、接触阴影或摄影机透视 |
| 镜头/光线 | 画幅、焦段感、摄影机高度/朝向/路径、切点、主光方向、阴影方向、曝光层次 | 非主体区域的灯具建模 | 让模型自选机位、跨轴、随机切镜、为“好看”改变原镜头关系 |

“人物可以没有表情”只表示允许保持中性、静止表情；**不表示允许没有脸部结构、发型轮廓、手指或服装细节。**

## 3. 执行顺序：四条提示词，不是一条巨型咒语

一条巨型提示词会同时要求分析、建模、绑定、渲染与审查，模型通常只做到“像”。高精度路线必须按以下顺序编译。模板中的 `{{...}}` 只存在于模板文件；提交前必须由实际项目数据全部替换，不能把占位符交给模型。

### A. 源片测量提示词（输出建模清单，不生成画面）

```text
【任务】你是影视三维重建总监。根据本次绑定的 SourceVideo 与 SourceFrameSet，输出一个可以在 Blender 中执行的逐 Shot 三维重建清单；不要生成图片、不要写散文、不要自行补剧情。

【输入绑定】
- SourceVideo = {{source_video_file}}。只负责时码、剪辑点、动作阶段、摄影机运动、人物/产品屏幕位置、遮挡和接触顺序；禁止把源片字幕、水印、品牌 UI、压缩噪声当成三维细节。
- SourceFrameSet = {{frame_manifest}}。每一帧都带时码；只负责静态可观察的轮廓、可见纹理、手指、衣褶、产品结构和光向。
- CharacterEvidence = {{character_evidence_or_none}}。只负责对应人物可见的脸部几何、发型轮廓、身形比例和服装结构；不得将一个角色的外观迁移给另一个角色。
- ProductEvidence = {{product_evidence_or_none}}。只负责指定核心产品的外形、结构、材质和可见纹理；如果此项目是产品替换，源片产品只负责位置、尺度、接触和遮挡，目标产品证据负责最终外观。

【硬输出】按时间顺序输出 JSON：shots、camera、subjects、heroProducts、contacts、lightDirections、observedDetails、inferredDetails、uncertainties、mustSeeFrames。每一个 `inferredDetails` 必须说明为什么源片不可见；不可把猜测伪装为 observed。

【逐 Shot 最低字段】开始/结束时码；景别；画面左/中/右与前/中/后景；主体画面占比；身体/头部/视线朝向；每根参与动作的手指或手掌接触点；服装受力位置；核心产品占比与遮挡；摄影机高度、透视、主运镜、切点；主光与阴影方向；结束状态。

【禁止项】不要输出笼统词如“电影感”“高精度”“自然一点”；不要遗漏低清、运动模糊、遮挡或镜外信息；不要生成未在本次输入中可证实的文字、Logo、花纹或五官特征。
```

### B. Blender 建模与动画执行提示词（构建 `.blend`）

```text
【任务】根据本次绑定并已审核的 ReconstructionManifest，在一个 Blender 工程中构建并渲染 {{project_id}} 的高精度三维还原 animatic。输出 `.blend`、完整 MP4、指定时码的 PNG 关键帧和 source-to-model 对照表。

【输入绑定】
- ReconstructionManifest = {{reconstruction_manifest_json}}。只负责时码、摄影机、站位、遮挡、接触、光向、MustSeeFrame 与 observed/inferred 边界。
- CharacterEvidence = {{character_evidence_or_none}}。每个文件必须对应一个明确的角色 ID；只负责该角色已观察到的脸部几何、发型轮廓、身形比例、服装结构与可见表面细节。
- ProductEvidence = {{product_evidence_or_none}}。每个文件必须对应一个明确的产品 ID；只负责该产品的外形、结构、材质和可见纹理。
- SceneEvidence = {{scene_evidence_or_none}}。只负责空间几何、地面/支撑面、透视锚、遮挡和光源方向。

【权威顺序】ReconstructionManifest 的时码/摄影机/站位/接触是空间权威；CharacterEvidence 只负责指定角色的可见外观；ProductEvidence 只负责指定核心产品的外观；SceneEvidence 只负责空间几何与光向。任何冲突必须记录为 uncertainty，禁止静默选择。

【人物高精度要求】
{{for_each_visible_character}}
- 人物 {{character_id}}：保持源片可见的头部比例和发型外轮廓；头发按可见分缝、长度、体积、发束走向与碎发轮廓建模。表情允许中性，但脸部必须有真实的眼眶、鼻梁、嘴唇、下颌、耳廓和皮肤受光结构，不得使用无脸椭圆头。
- 双手必须有独立拇指和四根手指、可辨别指节、掌心朝向、指甲片与关节弯曲；声明接触的手指必须在完整动画中看见接近、接触、受力、离开或保持，不能穿模、合并、悬空或变成手套。
- 可见服装必须重建版型轮廓、拼接线、包边、腰头、褶皱来源、布料厚薄和可见纹理。褶皱必须随髋、膝、肩、肘、手部接触或重力变化，不得画成静态贴图。
{{end_each_visible_character}}

【核心产品/道具高精度要求】
{{for_each_hero_product}}
- 产品 {{product_id}}：严格重建可见轮廓、分件、开口、边缘厚度、缝线/接口、材料分区、可见织纹或表面粗糙度；用镜内的人手、身体或固定物证明尺度。不可读的文字保持为空白或非文字纹理，禁止猜造 Logo、标签、型号或图案。
- 产品与手、衣物、桌面或身体接触时，完整表现靠近、接触阴影、受力、遮挡和离开；不得漂浮或穿透。
{{end_each_hero_product}}

【场景、镜头与光线】
- 场景只建影响透视、遮挡、脚底接触、产品放置、反射和阴影的空间体块；远景非关键装饰可以简化。
- 每个 Shot 先建立摄影机：画幅 {{aspect_ratio}}、机位高度、镜头透视、目标点、主体左右/纵深层级和唯一主运镜，再放置人物与道具。切镜使用独立 camera 并锁定切换帧，不得跨轴或自动改机位。
- 主光方向、软硬、色温和接触阴影必须与 source-to-model 对照表一致；高细节服务于可读轮廓、手指、衣褶和产品材质，不用炫光、景深或过曝掩盖细节。

【渲染与交付】真实高细节三维渲染，不是低多边形、关节人、玩具、纸片人、卡通、插画或模糊 clay render。人物与核心产品在焦平面内应可读到本合同所列细节；场景可低复杂度。导出完整连续动画，不允许以静态图重复替代动作。输出每个 MustSeeFrame 的原尺寸 PNG。

【严格禁止】额外人物；人物身份混合；手指合并；球形关节；错误肢体数量；衣物无褶皱；产品立方体化；产品结构改变；无依据文字/Logo；摄影机漂移；随机切镜；穿模；悬空接触；骨骼、坐标轴、控制器、辅助线、标签或 UI 出现在渲染画面中。

【验收】只有当每个 MustSeeFrame 同时满足人物、核心产品、构图、接触、镜头和光线六项对照时，状态才可标记 PASS；否则输出 FAIL 与精确重修任务，不得以“整体类似”通过。
```

### C. 高精度渲染补强提示词（只修一个失败类别）

不允许在整段动画已经正确时用一条泛化提示词重新做掉全部内容。对失败项使用原子修复：

```text
【任务】只修复 {{shot_id}} 在 {{timecode}} 的 {{failure_class}}。其余已通过的摄影机、角色 ID、站位、动作时间轴、产品位置、场景与光线必须保持合同不变；若使用确定性渲染器，应同时保持非目标区域的像素哈希不变。

【本次允许修改】{{allowed_changes}}。
【本次必须保持】{{locked_invariants}}。
【可观察证据】{{bound_source_evidence}}。
【修复目标】{{specific_observable_fix}}。
【禁止】重新选择机位、替换人物、改变服装/产品结构、改动其他肢体、添加文字或 Logo、用景深/高光遮住问题。
【验收】{{single_failure_acceptance_test}}。
```

失败类别只能选一个：`hair_silhouette`、`finger_anatomy`、`garment_construction`、`garment_fold_physics`、`hero_product_geometry`、`hero_product_material`、`contact_or_occlusion`、`camera_match`、`lighting_match`、`motion_timing`。

### D. 对抗性审查提示词（不参与生成）

```text
【任务】你是独立三维审片师。对照绑定的 SourceVideo、SourceFrameSet、ReconstructionManifest、.blend 导出帧和 animatic，对每个 MustSeeFrame 给出 PASS 或 FAIL。

逐项检查：人物发型轮廓；中性脸部结构；五指与关节；衣服剪裁、缝线、褶皱与纹理；核心产品轮廓、分件、材料和尺度；接触、受力、遮挡；构图、镜头、运镜、切点；主光和阴影方向；未观察信息是否被错误标记为 observed；是否出现低多边形、球关节、手套手、塑料布料、产品方盒化、穿模、漂浮、文字/Logo 幻觉或控制器污染。

每一个 FAIL 输出：source timecode、render timecode、失败类别、可见证据、最小修复范围。不得给“整体不错”“更高精度”等没有可执行含义的结论。
```

## 4. 运行纪律

1. 先执行 A，审核 `ReconstructionManifest`，再执行 B；不得跳过源片测量直接叫模型“高精度还原”。
2. 每个 Shot 先锁摄影机和空间，再建人物和产品；动作一定写为触发→接近→接触/受力→反应→结束状态。
3. 人物、核心产品、场景不使用同一精度预算。算力优先给人物手/头发/衣物与核心产品，禁止把精度浪费在无关背景。
4. 只有实际绑定的媒体才能写入输入绑定；无视频输入时，必须用实际抽取并绑定的时码帧代替 SourceVideo。原视频作为建模分析证据，不自动成为最终视频模型输入。
5. 如需把 animatic 输入视频生成模型，仍须通过模型能力验证和用户对视频输入成本的明确授权；否则只走 `keyframes_only`，并显示降级警告。
6. 最终 Seedance 提示词不得复制本文件的审计段、模型指令、占位符或元数据；它只接收经锁定的可见约束和真实绑定媒体。

## 5. 预审清单

- [ ] 每个源视频切点、动作峰值、接触起止和产品特写均有至少一张带时码证据帧；
- [ ] 所有重要人物都有独立角色 ID，发型轮廓、手指、服装结构与可见纹理进入合同；
- [ ] 所有核心产品都有独立产品 ID，源片产品与替换产品的职责没有混淆；
- [ ] 每个 Shot 都有机位、景别、主体画面位置、前中后景、透视锚、主运镜和结束状态；
- [ ] `observed` 与 `inferred` 已分开，未观察区域没有被承诺为精确还原；
- [ ] 整段 animatic 连续可播放，未用静止帧冒充动作；
- [ ] 提示词实际文本没有任何未替换 `{{...}}`、前文指代或未绑定媒体；
- [ ] 已用提示词 A–D 做 Agent 自检、机器/独立审查，再进入门 3。
