# 全局视觉风格基准（色卡 + 摄影提示词）

> 触发条件：所有多段项目。在门1（项目审核）时确定，贯穿全片。

## 三道约束

统一感不是靠后期套滤镜，而是三道约束叠加：

1. **生成前**：色卡基准（已有，见 asset-prompt-templates.md 第七节）
2. **生成中**：全局摄影提示词（本文件新增）
3. **生成后**：统一调色校正（剪映/达芬奇，人工操作）

## 全局摄影提示词

项目级确定一次，所有镜头的提示词都嵌入同一段。结构：

```
【全局视觉基准】
画面风格：[如：生活流电影 / 商业广告 / 纪录片质感 / 日系清新]
色彩方向：[如：Kodak Portra 400，微偏暖，低饱和]
光线逻辑：[如：自然光为主，柔光箱补光，避免硬阴影]
画质锚点：[如：35mm 胶片颗粒，浅景深，轻微暗角]
禁止项：[如：高饱和霓虹、HDR 感、过度锐化、AI 塑料感]
```

## 使用规则

- 门1 审核时，用户确认全局视觉基准
- compile-seedance 编译每段提示词时，自动在"氛围与画质"部分嵌入这段基准
- 任何镜头不得偏离基准；如需特殊处理（如回忆段落偏冷），在讲戏稿中标注例外
- 色卡资产图 + 全局摄影提示词 = 视觉一致性的双重锚定

## 参考图选择原则

- 不要只用一张参考图定风格（偶然性太大）
- 找 3-5 张同一风格的电影画面，提取共同色彩规律
- 参考图只定方向，不直接喂模型（避免模型复制画面内容）
