# 最终摄影机视角彩模导演代理图

来源与边界：本 Profile 落实 `knowledge/replication-library/workflows/08-shot-strategy-router.md` 的 `director_view_proxy` 职责，并继承 `knowledge/asset-prompt-templates.md` 第零节的生成式 AI 首轮上下文合同。它借用 `knowledge/capabilities/overhead-blocking-diagram.md` 对人物编号、固定空间关系和接触点的消歧方法，但输出不是俯视图，而是最终摄影机真正看到的单帧透视图。

## director_view_proxy_v1

### 任务与用途

为一个已经锁定的 Shot 生成恰好一张彩模导演预演图。画面必须采用该 Shot 的最终摄影机位置、方向、景别、镜头透视和画幅，只用于审查：

- 主体在画面内的左右顺序与位置；
- 各主体占画面大小和彼此比例；
- 前景、中景、后景层级；
- 姿态、身体朝向和可见部分；
- 谁遮挡谁、遮挡到哪里；
- 手、身体、道具、家具或地面的明确接触点。

它不负责真人身份、脸、发型、服装设计、产品外观、场景最终材质、皮肤或织物纹理、最终灯光和最终调色。正式视频中的这些内容只能由已锁定的 canonical 人物、服装、产品和场景资产控制。

### 输入绑定

无输入媒体时，必须明确写出本任务不使用任何图片输入，并在当前 IR 中完整定义机位、空间、主体和接触关系。

有输入媒体时，每个 `ImageN` 只能转移以下一种或多种职责：摄影机位置与透视、构图、站位、屏幕尺度、前中后景、姿态、朝向、遮挡、接触点、场景几何或空间锚点。每个绑定都必须明确禁止迁移：

- 真人身份、脸和发型；
- 服装或妆造；
- 产品外观和结构；
- 最终材质与纹理；
- 最终颜色与调色。

不得把任何输入绑定成“整体参考”，不得从分镜、原片帧或角色板迁移身份、服装、材质、产品或最终色彩。

### 主体合同

每个可见主体必须独立声明：

- `subjectId`：当前项目内唯一 ID；
- `tag`：当前图中稳定使用的主体标签；
- `kind`：`person`、`prop`、`product` 或 `environment`；
- `proxyColor`：只在这张预演图中区分主体的唯一低饱和纯色；
- `position`：相对画面边缘或固定空间锚点的可见位置；
- `screenScale`：以画面高度、宽度或另一个可见主体为参照的屏幕尺度；
- `depthLayer`：foreground、midground 或 background；
- `pose`：当前单帧可见姿态；
- `orientation`：身体、头部或道具的明确朝向。

有人物时必须应用 `seedance-camera` 与 `seedance-characters`。人物只渲染为无脸、无身份细节、无服装细节的平滑实体彩模；每名人物使用唯一低饱和纯色。彩模颜色只是当前代理图的 ID，不得进入正式视频的皮肤、头发或服装。

### 最终机位与画面结构

- 输出恰好一张完整画面，不得输出俯视图、侧视图、反打、备选机位、宫格或画中画；
- 摄影机合同必须写明画幅、位置、朝向、景别、镜头透视、主体关系和画面终点；
- `subjectLayout` 必须逐项复写每个主体的 ID、标签、位置、屏幕尺度、景深层级、姿态和朝向；
- 遮挡合同必须明确谁位于谁前方、遮住何处，以及哪些脸、手、产品或空间锚点必须保持可见；
- 接触合同必须逐项写明接触双方、左右肢体或道具部位和接触位置；没有接触时也要明确写“无接触并保持可见间隙”；
- 场景只保留确认站位所需的简化体块、地面、墙、门窗、家具和支撑面，不生成最终美术材质。

### 摄影与美术

使用电影预演式的最终机位彩模画面：简化中性空间体块、平滑无脸实体代理人、低饱和纯色区分主体、足以读清遮挡和接触的中性光线、真实接触阴影。对这张诊断代理图，Profile 的彩模渲染与职责边界优先于全局视觉合同中的皮肤、服装、产品、场景材质、纹理或最终色彩措辞；全局视觉合同不得把代理图变成最终剧照。不得把彩模画面制作成写实演员定妆照、服装广告、产品广告、最终剧照或风格海报。

### 严格禁止

真人相貌、可识别五官、皮肤与头发细节、服装设计与面料、产品重绘、最终场景材质、最终调色、代理颜色迁移、额外人物、错误前后景、错误比例、接触点被遮住、肢体融合、俯视图、备选机位、拼贴、文字、编号、箭头、logo、水印、字幕、UI、边框。

### 验收条件

1. 只有一张与锁定 Shot 完全相同的最终摄影机视角；
2. 每个主体恰好出现一次，唯一标签与唯一彩模颜色一一对应；
3. 位置、屏幕尺度、前中后景、姿态、朝向和遮挡顺序逐项符合合同；
4. 每个声明的接触点都清楚可见且肢体可分辨；
5. 不出现任何真人身份、服装、产品、最终材质、纹理或调色控制；
6. 不出现额外视角、俯视图、宫格、文字、logo、水印、字幕、UI 或边框。
