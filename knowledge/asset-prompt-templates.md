# AI 资产生成提示词模板库

> 来源：【提示词创作第六十七节】AI资产怎么做，画面才稳定？（super-i.cn / 西瓜）
> 整理日期：2026-07-29
> 用途：每次生成资产图时直接调用对应模板，无需重新编写提示词

> 默认生成路由：Codex `image_gen`。只有用户当前明确指定其他图片平台时才切换；模板内容与零上下文合同不因平台变化而省略。

> 已接受通用配方：`knowledge/accepted-asset-prompt-recipes/asset-contract-v1.md`。后续制作人物板、场景九宫格、产品视图、站位图和调度图时，先使用本文件的基础模板，再加载该配方中的 Gate 2/3 验收约束；不得引用任何真实项目案例作为隐藏上下文。

## 零、生成式 AI 首轮上下文合同（所有模板强制前置）

模板不是可以直接丢给生成模型的半成品。每一次生成都必须先把模板中的全部项目参数编译成一条**无需读取任何前文即可执行**的完整提示词，再提交给模型。

### 0.1 生成模型的知识边界

始终假定本次是与生成式 AI 的第一次沟通。它不知道：

- 当前聊天内容、项目背景、镜头表、审批页和项目状态；
- 上一条提示词、其他任务的提示词或“已经列明”的规则；
- 没有随本次任务实际绑定的本地文件、参考帧和历史产物；
- 操作者心里默认的年龄、人物关系、场景结构、产品结构和色彩规律。

因此禁止出现无法从本次输入解析的表达：`已列明`、`上述`、`前述`、`沿用此前`、`参考前面`、`同上`、`结合现有素材`、`按之前的设定`。模板内的方括号和“填写”字段必须全部替换，禁止原样提交。

### 0.2 每条最终提示词的固定结构

```text
【任务】资产类型、项目名称、具体用途。
【输入绑定】
- 无输入媒体：明确写“本任务不使用任何图片作为输入，主体完全由以下文字定义”。
- 有输入媒体：逐项写“Image1 = 文件/内容；只负责……；禁止迁移……”。未实际绑定的媒体不得写入。
【主体/空间/产品完整定义】年龄、身份、形态、结构、颜色、材质、识别点。
【输出结构】画幅、视图/宫格数量、每格固定位置和内容。
【摄影与美术】镜头、光线、背景、真实度、统一性。
【禁止项】人物/文字/水印/logo/结构错误/输入污染等。
【验收条件】可逐条目视确认的硬指标。
```

### 0.3 参考媒体绑定规则

- 只有媒体已经连接到当前生成任务时，才能使用“参考图”这个词。
- 每个媒体输入必须使用稳定编号 `Image1`、`Image2`……；提示词内不得使用“这张图”“那几张图”。
- 每个输入必须同时写明正向角色与污染边界。例如：`Image1 只负责泳池空间几何和池砖材质；禁止迁移人物、脸、身体、服装、产品、字幕、水印、logo、构图和压缩噪声。`
- 多张输入不得笼统写“提取共同规律”；必须先在提示词中把需要的规律明确写成可见属性，输入只作为证据约束，不承担隐含推理。

### 0.4 提交前追溯字段

每个任务清单必须包含：

```json
{
  "templateSource": "模板文件与章节",
  "skillsApplied": ["实际使用的 skill 名称"],
  "selfContainedContextVersion": "1.0",
  "inputBindings": [],
  "model": "实际模型",
  "count": 1,
  "autoRetry": false,
  "modelFallbackPlan": []
}
```

门 2 审核通过后，才可把用户接受的资产、完整提示词、输入绑定与审核结论沉淀为模板候选；失败或被否决的内容只能作为反例。

### 0.5 执行提示词与审核说明必须分文件

- 发给生成模型的文件只能包含模型需要执行的文字，不得在文件末尾附加“Skill 自检”“审核说明”“机审结论”“给审核人的说明”或审批状态。
- 自检、审计、输入清单与 SHA 绑定必须写入独立审核文件；即使说明本身正确，也不能混入模型实际接收的提示词。
- 每次机审都必须读取模型实际接收的完整文本，而不是只审代码块或其中一段；同时读取实际输入清单，逐一核对 `ImageN`、`@图N`、`@视频N`、`@音频N` 是否存在。
- 没有实际上传视频时，执行提示词不得出现“原视频”“原片”“参考视频”等表达；需要复刻的动作、构图和节奏必须改写为本次输入可解析的具体时间、姿态、机位与声音指令。
- 每个分段视频提示词都是独立任务。上一段的设定只有在对应首帧、角色板、场景板或其他媒体真实绑定后，才能通过明确编号引用；不得写“承接上一段”“保持之前一致”代替输入绑定。

## 一、人物身份资产（按 Shot 可见覆盖反推）

> **默认规则（realism-contract-v2）**：先读取 Gate 2 已锁定 Shotlist，再只生产镜头里真正可见的人物身份维度。正脸/3⁄4 脸、纯侧脸、正面全身、背面全身分别是独立原子资产；没有镜头使用的角度不得为了“资料齐全”付费生成。下面的四视图模板只在 Shot 覆盖同时要求这些维度时使用，不是固定起步资产，也不是每套造型的默认动作。

> 旧项目未带 `character_shot_coverage_v1` 时可继续按原四视图合同兼容；新项目必须记录覆盖计划、每个角度对应的 Shot ID，以及明确不需要的角度和原因。

### 覆盖选择速查

| Shot 中能看见什么 | 最小身份资产 |
|---|---|
| 近景/中近景正脸或 3⁄4 脸 | 正脸身份特写 |
| 近景/中近景纯侧脸 | 侧脸身份特写 |
| 中全景/全景正面身体、完整妆造或高风险动作 | 正面完整全身 |
| 背影、背面发型或背面服装结构 | 背面完整全身 |

以下模板 A/B 是上述维度需要合并审核时的条件模板。

### 模板 A：横版四视图（标准建档版）

**结构**：左侧正脸大图 + 右侧正面/侧面/背面全身三视图

**适用场景**：快速建档、角色初步资料页

**工具**：nanobanan pro（输入人物基础图）

```
生成图中人物的真人形象四视图，白底图，左侧部分展示了角色的精细真人特写肖像。其面部特征、骨骼结构、神态表情、发型及头部配饰必须与参考图严格一致，呈现自然的皮肤纹理、毛孔和发丝细节，高解析保留毛孔、细纹、绒毛、眉睫、发际线碎发与皮肤受光后的微小起伏，不磨皮、不锐化过头、不做人像美容，摄影棚质感，需要完全正脸，无动作，真人定妆照。右侧部分展示了该角色完全相同的全身真人照片，呈标准 A-pose 站姿，并以精确的三视图排列：正视图、侧视图和背面图。超模的身体比例、完整的服装设计、布料层次、鞋子及整体穿搭风格必须严格遵循。所有服装和配饰均呈现真实的物理材质质感。
```

**优点**：结构标准，AI 容易理解
**缺点**：只有一张正脸大图，侧脸镜头时一致性会下降；纯侧视图利用率不高

---

### 模板 B：双头像 + 服装正背面（视频生成优化版）⭐推荐

**结构**：上方 1/3 正脸+侧脸大头像，下方 2/3 放大正面服装图+完整背面全身图

**适用场景**：多镜头、多景别、包含近景和侧脸的视频项目

**工具**：nanobanan pro（输入人物基础图）或已验证能稳定输出写实角色板的图片模型

**使用前必须二选一并展开**：

- 有人物基础图：在提示词开头声明 `Image1` 的确切角色，以及允许保留和禁止迁移的内容；
- 无人物基础图：删除所有“图中人物/参考形象/原图”措辞，完整写出人物的年龄、性别、地域外观、脸型、五官、肤质、发型、体型、服装、鞋子、配饰和气质。

**四区版式防错补丁（强制）**：

- 整张图必须**恰好四个区域**：左上正脸、右上侧脸、左下正面服装、右下背面全身；不得增加第五格、中央正面全身图、额外服装细节图或重复人物。
- 下方只允许左右两列，各占下方区域宽度的 50%。左下“放大”只表示头部完全移出画面且肩颈到鞋底尽量填满该列，不允许通过裁掉膝盖、小腿、脚或鞋子实现放大。
- 左下必须在**同一张图**里同时满足“头部完全裁出”和“肩颈到鞋底完整”；如果模型另加一张完整正面全身图来补足被裁身体，整张资产仍判 FAIL，不能把两个错误区域拼成合格结果。
- 视觉审核必须数区域并检查边界：区域数不是 4、左下裁到膝部、缺脚/鞋、或出现重复正面身体图，均判 FAIL，不得锁定或作为下游身份输入。

**已知模型失败模式（2026-07-30）**：`nebula-ultra` 在 16:9 版本中曾生成上 2 + 下 3 共 5 区，在改为 4:3、明确“恰好四区/禁止第五格/禁止重复人物”后仍生成上 2 + 下 4 共 6 区。两次结果均不得作为合格角色板。相同模型不得继续付费重试；若用户另行批准恢复，优先把正脸、侧脸、正面服装、背面全身拆成四张原子图分别生成，再用确定性排版工具合成，而不是继续要求同一生成任务同时解决身份、全身完整性和复杂版式。

```
生成图中人物的真人形象设定四视图，灰色摄影棚背景，整体为专业真人角色定妆参考板，规整排版，干净简洁，不是海报，不是杂志大片，不要剧情动作，不要复杂场景。

整体版式严格分为上下两部分：上半部分占画面高度三分之一，下半部分占画面高度三分之二。
上方区域展示两张精细真人面部特写，左侧为正面面部特写，右侧为侧面面部特写。两张特写都以头部与肩颈为主，构图紧凑，清晰展示人物五官、骨骼结构、妆容、发型、头饰与神态。人物面部特征、发型、妆造、头部配饰必须与参考形象严格一致。皮肤质感真实自然，保留毛孔、细纹、绒毛、眉睫、碎发与皮肤受光后的细微起伏，不磨皮，不过度锐化，不做人像美容，呈现高解析真人摄影棚定妆照质感。

下方区域展示两张身体与服装参考图，左右排列。

左侧图片必须是放大后的正面服装展示图，人物采用标准 A-pose 站姿。
这一张图的重点不是完整全身入镜，而是"人物尺度明显放大"，让角色在画面中占据更大比例。
左侧图片必须使用更近距离的正面取景，人物从肩颈下方开始入画，到鞋子结束，头部因画面放大而被完整裁切到画面之外。
请注意，这张图不是普通远距离全身照，而是近距离放大的正面服装图：人物身体在画面中的占比要明显更大，上半身与下半身都要被放大展示，整体视觉效果像时装定妆板中的服装主体展示图。
人物双肩、双臂、双手、躯干、腰部、腿部、鞋子必须完整保留，画面边缘只允许裁掉头部，不能裁掉手、脚或身体主体。
左侧这张图必须比右侧背面图看起来更"近"、更"满"、更"放大"，让服装细节和身体比例更突出。
禁止把左侧图做成普通小比例全身图，禁止人物在左侧图中显得太小，禁止头部仍然留在画面内，禁止只裁掉半个头或留出下巴、嘴巴、鼻子、头发边缘。

右侧图片为背面全身图，标准 A-pose，完整展示从头部到鞋子的背面全身。人物背对镜头，完整保留背面头部、发型背部、服装背面结构、鞋子与整体轮廓，用于展示角色背面造型。右侧这张图为常规完整背面全身展示，人物比例正常，不需要像左图那样放大裁切。

下方两张图必须为同一个人物、同一套服装、同一组配饰、同一身体比例。整体保持超模感修长比例，但不要夸张变形。服装设计、布料层次、鞋子、穿搭风格、服装结构与配饰样式必须严格遵循原图。所有服装与配饰都要呈现真实物理材质质感，布料有自然褶皱、垂坠和厚薄变化，金属有真实反光，皮革、丝绸、纱质等材质表现真实自然。若原图服装为开叉长裙，则左侧正面放大图中人物可自然一条腿向前迈出半步，以展示开叉结构和露腿效果，但整体仍需保持定妆照式稳定姿态，不要做走秀动作。

光线只使用干净统一的摄影棚三点式打光：正左侧主光，正右侧辅助光，后右侧轮廓光。不要杂乱光效，不要彩色灯光，不要强氛围特效。背景为纯净灰色无缝影棚背景。

严格要求：
上方两张脸部特写占画面上三分之一。
下方两张身体图占画面下三分之二。
左下图必须是"放大后的正面服装展示图"，人物在画面中的占比明显更大，头部因近距离取景被完整裁切出画面。
右下图必须是完整背面全身图。
禁止左下图做成普通比例全身小图。
禁止左下图出现任何头部信息。
禁止左右服装不一致。
禁止人物比例漂移。
禁止 AI 油腻感、塑料皮肤感、过度美颜感、廉价 CG 感。
```

**优点**：正脸+侧脸双固定，服装放大展示信息利用率高，背面完整保留
**缺点**：提示词较长，生成时偶尔需要重试

## 二、妆造资产（服装替换）

### 步骤 1：生成全身图

**工具**：nanobanan pro（输入人物四视图或基础图）

```
生成这个人物的全身图。并且保持超模的身材比例
```

### 步骤 2：替换服装

**工具**：nanobanan pro（输入全身图 + 目标服装图）

```
将图1的妆造替换成图2的一整套妆造，保持超模的身材比例
```

### 步骤 3：按每套造型实际出镜范围补齐身份资产

先根据已锁定 Shotlist 判断这套服装会以哪些角度、景别和动作出现，只补齐实际可见的原子身份资产。只有正脸、侧脸、正面全身、背面全身都会被镜头读到时，才使用模板 A 或 B 组成四视图；未出镜角度不得作为默认任务。

## 四、动作资产（16 宫格动作图鉴）

### 步骤 1：让 AI 拆分动作方案

先输入你的剧情想法，例如：

```
女特工在雨夜地下停车场被一名壮汉伏击，她没有武器，只能利用闪避、反关节、膝击、摔投和现场杂物反击。整体要像现代动作电影，黑暗、冷峻、真实，不要血腥。请帮我生成16宫格动作招式图鉴的提示词。
```

### 步骤 2：接上系统提示词

```
你是一名电影动作分镜设计师和视觉提示词工程师。用户会输入一个剧本、片段或简单想法。你的任务是把它转化为一套"动作招式图鉴海报"的图像生成方案。

要求：
1 根据剧本提取核心冲突、人物关系、场景、情绪和动作风格。
2 将动作拆成16个连续分镜，每个分镜只表现一个清晰动作瞬间。
3 每个分镜需要包含：编号、招式名、画面描述、动作视觉重点、单图生成提示词。
4 提示词只描述电影画面，不写真实伤害教学步骤。
5 保持人物服装、场景、光线、镜头风格统一。
6 生成图片时不要要求模型生成中文文字，文字用于后期排版。
7 最后输出一个总海报排版提示词，以及标题、副标题、每格招式名和简短说明。

输出格式：
海报主题

## 五、场景资产（九宫格多角度）

## 七、色板资产（7 色系统）

### 方法 A：从电影参考图提取

**适用**：已有明确视觉方向（多张同风格电影截图）

```
你现在是一名电影调色师、视觉美术指导和AI视频色板设计师。

我会上传多张电影画面参考图。请你不要逐张分析，也不要从每张图里分别提取颜色，而是从所有参考图中提取共同的色彩规律，帮我生成一套适合AI视频创作使用的电影色板资产方案。

注意：
色板数量控制在7个颜色。
每个颜色必须输出标准HEX色值，格式必须为 #RRGGBB。
不要输出过多颜色，不要超过7个。
不要只输出5个颜色，色彩层次需要足够完整。
不要把单张图里偶然出现的小面积颜色当成核心色。
不要提取随机颜色，要提取多张参考图共同形成的色彩逻辑。
色板标注只需要包含：颜色类型、HEX色值、使用场景。
不要在色板标注里写长段解释，不要写复杂理论，不要写过多文字。

第一步：整体色彩分析
请分析这些参考图共同的视觉特征，包括：

## 九、核心原则

1. **资产负责稳定，标注负责调用，提示词负责镜头。**
2. 提示词决定方向，资产决定边界。
3. 提示词负责表达创意，资产负责控制结果。
4. 一张图只能告诉 AI 一个角度的信息，多角度资产才能防止变脸/变装/变场景。
5. 母图越清晰，后续资产越稳定。
6. 表情不要越多越好，要和剧情相关。
7. 实体道具用三视图，虚拟道具用 16 宫格动作图鉴。
8. 色板不是颜色拼贴，是色彩使用说明（颜色 + 属性 + 使用场景）。
